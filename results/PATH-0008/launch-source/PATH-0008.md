# PATH-0008: head-level mediation of a direct lookup

Registered before any PATH-0008 model outcomes. This is an adaptive **exploratory** successor to PATH-0006 on the same existing Qwen3-8B-4bit original model. PATH-0006's 28–31 attention-write window and all of its discovery bundles are exposed; this registration uses them to *select* candidate heads, never as fresh evidence. Eight new, disjoint direct-lookup bundles are reserved for confirmation. No Voynich manuscript scoring or semantic claim is involved.

## Question and basis

PATH-0006 found that reverting all final-query attention writes in blocks 28–31 after a post-block-23 value-position transplant removed the donor first token in 20/31 fresh upstream-success records; a matched random write edit removed it in 0/31. Is substantial causal leverage carried by **four query heads in one block**, or is the effect distributed over the window? PATH-0001's earlier one-block donor-head patch failed its all-head positive control, so a four-head result here is a new, narrower question and can fail even when PATH-0006's whole-window result holds.

The [QK/OV framework](https://transformer-circuits.pub/2021/framework/index.html) separates head addressing from value/output flow; [path patching](https://arxiv.org/abs/2304.05969), the [IOI circuit study](https://arxiv.org/abs/2211.00593), and [original-model circuit tracing](https://www.transformer-circuits.pub/2025/attribution-graphs/methods.html) motivate intervention-and-control tests rather than attention pictures or raw cosine. Their architectures/tasks do not establish that a Qwen head implements this lookup. PATH-0002/0006 establish a usable upstream edit and whole-window mediator for supplied English records. Prior Voynich co-occurrence/embedding work, documented in PATH-0004 and `SIMILARITY_THEORY.md`, offers no validated plaintext anchors; this known-answer task is method qualification only.

## Fixed task, splits and units

Discovery reuses the **eight PATH-0006 discovery bundles** and their two templates, orientations, two queried names, and unrelated copy words: 32 binding plus16 copy records. No PATH-0006 confirmation bundle is reused. `path8_tasks.py` freezes eight new confirmation bundles, likewise32 binding plus16 copy. The direct lookup and answer rules are exactly PATH-0006's renderer with greedy generation capped at12 tokens; source/donor swap only value fields. Tokenized source/donor lengths must match, changed positions must precede the unchanged query suffix, and expected source/donor answer words must differ. Count an eligible binding only when both clean full answers are correct and generated first tokens differ. Each split needs≥24/32 eligible bindings and≥14/16 correct source-copy baselines. The independent unit is the lexical bundle; orientation and queried-name variants are dependent. Confirmation words must not enter head selection, prompt revision or threshold tuning.

## Original-model intervention and screen

At zero-based **post-block23**, replace the changed value-position residual fields with donor-minus-source fields, as PATH-0006 did. In an otherwise identical source run, capture the **actual final-position pre-output-projection head outputs** at blocks 28–31 from (a) the clean source and (b) this edited run. Reconstruct native attention writes from those heads and require max error<0.002. Do not use heads from a clean donor prompt as a substitute for the edited run.

For every discovery binding that is clean-eligible and whose uncut upstream edit gives the full donor answer, screen all32 query heads at each of blocks28,29,30,31. If fewer than18 discovery bindings have that upstream success, stop uninformative. Revert one head's output from its edited-run value to its clean-source value, project through that block's native output projection, and **recompute the rest of the original model**. Score the decrease in the donor-first-token minus source-first-token logit margin relative to the uncut upstream edit. No generation or copy task enters this screening score. For each layer, rank heads by mean margin decrease (tie: lower head index), take its top four; choose the layer with the largest sum of those four means (tie: lower layer). This freezes one same-block four-head group. Record the full128-candidate screen and per-bundle scores, including negative or zero effects. A head selected by logit margin is not presumed to control the complete answer.

## Confirmation grid, gates and claims

On every confirmation task run clean baselines, the uncut upstream edit, and these fixed conditions: the **best single head** and the **selected four heads** reverted to clean source; an independent Gaussian write delta norm-matched to the selected-four projected delta; a structured **mismatched-bundle** selected-four delta, obtained from the next bundle cyclically with the same orientation, query slot and task family and rescaled to the target delta norm; clean-source restoration of **all32 heads in the selected block**; clean-source restoration of **all final-query attention writes in blocks28–31**; and the architectural all-block24–35 clean-write restoration. Also run an exploratory reverse test: insert the edited-run selected-four head outputs into a clean source run at the selected block with no upstream value edit. Recompute all later blocks in every case. The Gaussian and mismatched-bundle conditions are confound controls, not guaranteed semantic nulls. Freeze the cyclic mapping before scoring; if a mismatched delta has zero norm when the target is nonzero, stop as a control failure. Report full-answer source/donor rates, first-token donor removal, logit margins, copy preservation, and every bundle separately.

Run full-prefix donor-residual transport and zero-edit identity checks. The clean head reconstruction, clean write capture, edited head reconstruction versus uncut upstream logits, whole-donor transport, all-head projected-delta versus clean whole-block replacement, and all-block first-token source-restoration controls must each have max absolute logit/write error<0.002 and matching first-token argmax where applicable. All-head and four-block effects are context controls, not monotonic doses: nonlinear downstream computation may make a four-head cut stronger than an all-head cut. If a numerical check fails, stop as uninformative; do not reinterpret it as a mechanistic negative.

The selected-group mediation is **exploratory supported** only if both clean competence gates pass, at least75% of eligible confirmation bindings give the full donor answer after the upstream edit, at least90% of baseline-correct copy answers survive upstream and selected-four interventions, the selected-four reversion removes the donor first token on≥35% of confirmation upstream successes, and that removal rate beats **each** of Gaussian and mismatched-bundle controls by≥25 percentage points. In addition, the four-block whole-write control must remove the donor first token on≥35% of upstream successes; otherwise head localization is **uninformative positive-control failure**. The selected single head and reverse direction are separately reported diagnostics, not gate substitutes. All-block first-token restoration is a numerical/architectural gate. Failure of a behavioral threshold with all controls passing is a qualified negative. Use10,000 seed-fixed bundle resamples for descriptive selected-minus-control intervals. Never pool the exposed discovery records with confirmation for a claim.
