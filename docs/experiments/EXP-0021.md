## Question

On the **same frozen** EXP-0016 neural checkpoint, does a **rate-free** keep/delete rule—where each window’s deletion count is chosen from the model’s own keep-scores, not from a global rate crowned on these pages—produce a kept stream on ZL3b **validation CONFIRM** that is more predictable than the full text **and** beat matched-random deletions at the same per-window counts, without collapsing to the rejected 0.70-rate family?

## Bits-gain definition (same as EXP-0018)

Fit an 8-bucket rank bigram on ZL3b **train** pages only (`fit_rank_bigram`). For a window text \(T\) and keep-mask \(m\):

- `full_bits` = bigram bits of rank-bucket sequence of \(T\)
- `selected_bits` = bigram bits of the kept subsequence under \(m\)
- **bits-gain** = `full_bits − selected_bits`
- **Interpretation (frozen):** a **positive** gain means the kept stream is **more predictable** than the full text under the train rank-bigram. Negative neural gain is damage, not a null-component signal. Beating matched-random while remaining negative only means “less damage than random deletion.” Delete-nothing has gain **0**.
- A window **beats random** iff `gain > mean_random_gain + 0.05` (same +0.05 margin as EXP-0018)

## Frozen decode rule (ONE rule; no Voynich tuning)

**Threshold keep (rate-free):**

\[
\mathrm{keep}_i = \mathbf{1}\big[P(\mathrm{signal})_i \ge 0.5\big]
\]

- Threshold **0.5** is the natural decision boundary for a binary signal/null head.
- **Rationale (prespecified from training, without looking at Voynich bits):** the checkpoint was trained with synthetic filler rate **0.30** (`PRIMARY_FILLER_RATE`); this rule does **not** impose that global rate via exact-count. It lets each window imply its own \(n_{\mathrm{null}}\) from keep-scores.
- **Forbidden:** grid-searching thresholds or top-p on Voynich; crowning a global exact-count rate on these pages; refitting the encoder on Voynich; opening the test split.
- Implied null rate for a window of length \(L\): \(r = 1 - (\sum_i \mathrm{keep}_i)/L\).

## Matched-random control (prespecified)

## Pass rule (CONFIRM half only; ALL must hold)

**PASS** iff **all** of:

1. `mean_gain` **>** **0** (kept stream more predictable than full text; not merely less damaged than random)
2. `mean_gain` **>** `mean_random_gain` at the **same** per-window deletion counts the model actually used
3. `fraction_beats_random` **>** **0.50**
4. Implied null rates do **not** collapse to one global high rate:
   - across-window **standard deviation** of implied null rate **> 0.05**
   - **median** implied null rate **not** inside **[0.65, 0.75]** (rejected 0.70 family neighborhood)

Otherwise **FAIL**. A negative result stands. Do **not** start another architecture in this session.
