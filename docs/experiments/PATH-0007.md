# PATH-0007: controlled two-hop prompt-format qualification

Registered before PATH-0007 model outcomes. This is a **competence qualification**, not a mechanism or manuscript experiment. PATH-0004 stopped because only 10/24 confirmation two-hop source/donor pairs were both correctly answered. PATH-0005's retrospective diagnosis found most failures were explanatory preambles truncated at the 12-token cap and associated with the arrow/Lookup prompt, but template and lexical bundles were confounded. The present panel crosses two formats on the **same** fresh bundles with identical instructions and output prefix, isolating punctuation/line layout more cleanly. It does not use PATH-0004 words or reinterpret its result.

Prior basis: PATH-0003/0004/0005, the [ICLR 2024 controlled prompt-format study](https://openreview.net/forum?id=RIu5lyNXjT), and the original-model causal-circuit methods reviewed in PATH-0006. Those sources motivate measuring clean competence before a costly intervention and do not predict that either format will pass. Prior Voynich co-occurrence and mimicry studies cited in PATH-0006 show why supplied English-table success has no direct historical meaning.

Twelve disjoint seven-word lexical bundles, six discovery/six confirmation. Each bundle is crossed with `colon` and `arrow` table-line styles while holding all other text fixed; each style has two first-table orientations, two queried names and an unrelated copy task for each orientation. Thus each style has 24 composed and 12 copy records per split. Source/donor swap only first-table keys. The model is the existing local Qwen3-8B-4bit; greedy generation capped at 16 tokens, exact one-word `answer_correct` scorer frozen. Record source and donor text, complete correctness, first-token distinction, output-form classes, hashes and all bundle-level rates. No patches, training, model download, paid API or manuscript scoring.

On discovery, select the style with the most both-clean-correct composed records whose first tokens differ; tie-break by source-correct copy count, then `colon`. The selected style is **qualified** only if it reaches at least 18/24 eligible composed comparisons and 11/12 source-correct copy records on *both* discovery and the disjoint confirmation panel. Do not change the format or gate after seeing results. Score the unselected style on confirmation as a descriptive, prespecified format comparison; it cannot replace the selected one post hoc. Bundle is the statistical unit; paired style differences by bundle are descriptive, not a clean causal estimate of all prompt features.

Maximum 20 minutes elapsed, 45 GB MLX allocation, seed 51091 for deterministic order/metadata. Save compact results, exact source/task/rendered-input hashes and baseline arrays in `results/PATH-0007/` and ignored `outputs/PATH-0007/`. Stop and record a failed gate/resource cap without automatic rerun. Any later factorial key-transfer intervention requires a **different fresh** panel and new registration; PATH-0007 does not establish an intermediate key.
