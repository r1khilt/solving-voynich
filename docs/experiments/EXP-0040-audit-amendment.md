# EXP-0040 audit amendment — external Timm variant has an unstated hash seed

The original EXP-0040 source freeze `17c6c63228d33e79c707a6d9ba4736b255d93aa7` was pushed and remote-verified before the first five-family comparison. One frozen runner pass completed in 117.99 s. Its compact output is preserved **unqualified** as `results/EXP-0040/unqualified-first-run.json`, SHA-256 `d252f0666e6de5e78ddc01c1db8839882320be4aa261c0796c0cc425472ef978`. The generated streams remain locally ignored under `outputs/EXP-0040-unqualified/`. None of its family decisions is being promoted as an audited result.

The independent auditor replayed the first `stock_flow` and `stroke` families from the exact external revision, then stopped at the first `timm_faithful` stream: regenerated words did not equal the saved stream, despite matching the source corpus, profile, numeric seed and Python code. A diagnostic compared both independently parsed training texts byte-for-byte and found them identical (SHA-256 `3f282a0d98d91730c4e79cc5c52e632360e9c88a75c6f4f1b37b9c3978e68956`). The `stock_flow`, `stroke`, `cardan_grille` and iid seed-0 streams reproduced exactly. In the pinned external `generate_timm`, `_timm_subs()` builds a Python `set` of substitute pairs and then sorts only by source-glyph length; equal-length substitutions retain hash-dependent iteration order. Python's randomized hash seed is therefore a hidden generator seed. The original process had no `PYTHONHASHSEED` environment setting, so its Timm stream cannot be replayed exactly from the reported numeric seed alone. This is a source-generator reproducibility failure, **not** evidence for or against the manuscript mechanism.

**Amendment after seeing the first provisional output:** require `PYTHONHASHSEED=0` at the start of both runner and independent auditor, record it in the result, archive the original streams, and run the **whole five-family panel again** into a new output namespace. No external code, manuscript input, train/validation assignment, family configuration, seed numbers, scorer, 200-permutation rule, decision thresholds or reference interval changes. The rerun is transparently post-result, even though the fix addresses only generator determinism. The independent auditor must regenerate all 80 streams and recompute 16,000 shuffles before any EXP-0040 claim is admitted. Preserve the original first-run result and failure record. Freeze this amendment and code in Git, push and remote-verify before rerunning.
