# EXP-0028: distinguish local copying from global spelling and locus composition

Registered 2026-09-24 **after** reading EXP-0027, before any EXP-0028 score. This is an explicitly adaptive, exploratory manuscript analysis on the same exposed ZL3b validation leaves, not untouched confirmation. Final manuscript test stays unopened.

## Trigger, question, prior work

EXP-0027's local one-edit cache saved0.07681 bits/word beyond exact repetition, but its edit-specific gain did not exceed the page-permutation95th percentile; train-calibration chose its largest base smoothing `beta=1000`. Its permutations also mixed words across locus types. Thus the next decisive question is whether **local one-edit context** helps after a global edit-neighbor spelling prior has absorbed manuscript-wide word-shape relations, and whether that residual requires actual within-locus word order.

[Timm and Schinner's original self-citation materials](https://github.com/TorstenTimm/SelfCitationTextgenerator) motivate local edited-source selection, while [Lindemann and Bowern](https://arxiv.org/abs/2010.14697) and [Reddy and Knight](https://aclanthology.org/W11-1511/) establish strong word-form, section and transcription confounds. [Grave et al.'s continuous cache](https://arxiv.org/abs/1612.04426) makes ordinary-language recency a live rival. The global edit prior here is a proper convolution of the empirical training-word distribution with the same edit transducer, not a historical cipher. If it performs well, that may show spelling-family structure rather than copying. Prior EXP-0019 failed its IID sanity gate, so this test is predictive, not generator-simulation matching.

## Frozen data and fitting

Use the same source/derived hashes and certain-word `[a-z']+` eligibility as EXP-0027 (`train` `49618c7b…`, `validation` `9bee4149…`), identical 65 train-fit/16 train-calibration physical leaves, page reset and all locus types. No test access. Keep its character 4-gram and word-count base but extend `beta` candidates to {1000,10000,100000,1000000,1000000000000}. Add a normalized global edit density: sample a training word proportional to its count, then exact/substitute/insert/delete once with weights 0.75/0.125/0.0625/0.0625 and uniform valid character/position choices. Blend this density with the word/character base at `gamma` in {0,0.05,0.1,0.2,0.4,0.6,0.8}; select `(beta,gamma)` jointly by train-calibration log loss, then refit on all train leaves. All finite-string probabilities include the empty string, so the edit channel is properly normalized even when deleting a one-character source.

On this *same selected static base*, fit a separate exact local cache and one-edit local cache on train-calibration only. Local candidate windows {4,16,64}, half-lives {4,16,infinite}, mixture lambda {0,0.05,0.1,0.2,0.4,0.6,0.8}, and edited-cache exact weight {0.25,0.5,0.75} match EXP-0027. Refitting both from the same static base makes the local contrast interpretable as incremental bits, not the effect of different backbones. Refit train distributions before validation without selecting any parameter on validation.

## Readout and controls

Primary contrast: `local_exact bits - local_edit bits` per certain word on the24 validation pages/10 physical leaves, with the same2,000-draw paired leaf bootstrap seed270027. Also report static-base, exact-cache, edit-cache scores and per-leaf changes. Independently recompute page sums, bootstrap and decision from compact rows.

Freeze selected models and score100 within-page permutations **within each locus type** (seed280127+r), retaining every locus slot, page/type word multiset and noneligible event. Separately score100 **within-each-locus** permutations (seed280227+r), retaining each locus's own word multiset, length, type and page order. These nulls preserve progressively more layout and vocabulary structure but alter the observed order; they are not independent historical texts. Run a known one-edit insertion positive control (seed280327, 30% of eligible slots, source from previous16 generated eligible words), require positive edit-over-exact gain to establish sensitivity. Keep all100 values, not just a percentile.

Exploratory `local_edit_order_support` requires real edit-over-exact gain≥0.03 bits/word, paired leaf-bootstrap95% lower bound>0, the real gain above the 95th percentile of **both** permutation null distributions, and positive-control edit-over-exact>0. Otherwise label `not_supported_under_stronger_controls`. This threshold was fixed knowing EXP-0027's aggregate but before any EXP-0028 scores, so even a pass remains adaptive and needs genuinely new physical leaves or external corpus evidence for confirmation. Regardless of result, do not infer plaintext, meaningless production or literal copying. A future decoder requires explicit rules, alternatives, cost accounting and independent predictions.
