# EXP-0037 — boundary order after fixing line endpoints and position

Registered 2026-09-25 after seeing EXP-0036 and **before** EXP-0037 scores. This is an adaptive exploratory analysis of already-exposed ZL3b validation leaves; it cannot be promoted to independent historical confirmation. Linked HYP-004/HYP-005. No final test text or imagery.

## Trigger and prior work

EXP-0036 found a train-to-validation end-codepoint→next-start-codepoint signal relative to within-locus shuffles, but those shuffles move line-initial and line-final words. [Parisel's boundary analysis](https://arxiv.org/html/2604.19762v2) shows that positional structure is unusually strong in the manuscript, so an endpoint/position confound is serious. EXP-0028's stronger-spelling one-edit cache result remains negative; this test asks about a different conditional word-boundary dependency and does not infer copying. Normal language, formulae, stateful cipher and structured copying remain competing explanations. The new control holds more of the observed layout fixed, not a new target selected from the EXP-0036 leaves.

## Frozen data, model and controls

Use exactly EXP-0036's processed ZL3b train/validation hashes `49618c7be69cef573fe9ad8ae3627ad9f7b495601af1897aafb6082837fceca4` / `9bee4149f26fc49b49e4a826b73598dfb79a1e785731c15a1763489315a2efd3`, its certain `[a-z']+` contiguous within-locus runs and fixed alphabet. Restrict to runs of length at least **4** so two interior words can exchange positions; the same eligibility applies train and validation. Excluded uncertainty never bridges an edge. Fit on train only three Laplace-smoothed boundary models, one for the first pair, one for the last pair and one for all middle pairs. Each compares `P(next initial | prior final, edge role)` to the independently fitted `P(next initial | edge role)` using additive count 1. No validation parameter selection.

Primary control: **200** independent within-run permutations of interior words with first/last word fixed, seeds `370037 + replicate`. Secondary stricter control: divide the interior positions into first/second halves by index; independently permute within each half, seeds `370437 + replicate`. This preserves the exact endpoints and a coarse within-line position class. Runs whose bins each contain one word remain unchanged and dilute, rather than create, a positive contrast. Each permutation retains the same word multiset, length, locus/page/leaf/section and uncertainty exclusions. Use per-pair held-out log2 gain and physical-leaf bootstrap2,000 draws seed`370137`; report every leaf and both null distributions. A separate synthetic eight-symbol Markov-word positive control with the same endpoint-fixed shuffles must have real-minus-permutation gain≥**0.1 bits/pair**.

The exploratory `endpoint_robust_boundary_signal` label requires **both** real-minus-control means≥0.02 bits/pair, both leaf-bootstrap lower bounds>0, real gain above both 95th permutation percentiles, and the positive control≥0.1. If the toy gate fails, mark invalid; otherwise mark `not_supported` if any main clause fails. These thresholds were chosen after EXP-0036 and do not constitute independent confirmation. A positive label still cannot distinguish grammar, semantic associations, copying, cipher state or physical writing direction; it only constrains future generators.
