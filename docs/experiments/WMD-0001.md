# WMD-0001 — Integrated communication-system inference implementation qualification

Registered 2026-09-21 before any scored training run of this system. The user's latest instruction authorizes implementation of the world-model/diffusion/linguistics research program, ambitious local work, and thorough correctness checks. This supersedes the research-only boundary for this task. The original research dossier remains a historical proposal.

## Question and scope

Can an integrated system learn to propose global writing rules, aligned keep/word-boundary decisions and grammatical families from observations of unfamiliar generated communication systems, compile those proposals into executable hypotheses, and expose their uncertainty and causal behavior? A parallel learned action model predicts entity-state changes and action validity. An explicit evidence ledger and finite information-gain policy coordinate research decisions.

This registration qualifies software and measures synthetic transfer. It does not test a historical Voynich hypothesis, establish general language understanding, or claim frontier-scale foundation-model training. The implementation is broader than the measured initial training run.

## Source rationale and differences

Read `docs/research/world-models-diffusion-2026-09-21/README.md`, `SYNTHESIS.md`, the four topic chapters and source ledgers. Masked reconstruction and explicit remasking motivate the inference model; this implementation is a revisable denoising heuristic, not an exact diffusion posterior or a new ELBO. World/action work motivates persistent entities, role binding, transition prediction and explicit consequences. Linguistic work motivates separate grammar, morphology, channel and segmentation variables. Causal-abstraction work motivates behavioral interventions with controls. Exact finite Bayesian information gain motivates evidence selection.

This implementation supplies synthetic rules/keys/actions as training supervision. Unlike passive unknown-manuscript inference, that supervision is available by construction. Synthetic oracle symbol anchors are explicitly marked and compared with zero-anchor inference. No neural paper is represented as demonstrating this entire system or Voynich transfer.

## Inputs and fixed splits

- Versioned executable world generator: procedure, taxonomy and structured copy families; six role orders; prefix/suffix/no role morphology; fresh random global homophonic keys; globally licensed null symbols; randomized symbol alphabets. No free per-position unexplained deletion.
- Default entities=4; clauses 4–9; null rates in {0,0.1,0.25}; homophone counts in {1,2}; alphabet 24. Generator variants have documented limits, including no state-dependent historical cipher in this version.
- Training excludes (VOS,prefix) and (OVS,suffix). Validation uses (VOS,prefix), final synthetic holdout uses (OVS,suffix). All splits use separate SHA-256-derived seed domains keyed by run seed, split and episode index. Concrete manifests record source hashes and sampled input identities.
- Fresh training episodes are generated deterministically without exposing seed, gold key or grammar in the model condition. Half have zero anchors, half have two explicitly supervised synthetic correspondences. Unobserved key entries are masked out, not falsely treated as recoverable targets.
- Default synthetic validation uses 64 examples. It is a development/qualification set. Final synthetic test and manuscript final test are not scored in this task. No manuscripts or downloaded corpora enter the new training run.

## Model, training and resources

`configs/communication-local.json` freezes a six-layer, width 256, eight-head conditional Transformer over joint latent fields; full configuration is recorded per run. AdamW, learning rate 0.0003, warmup 100, 2,000 updates, batch 16, seed 41021; gradient clipping 1.0. The run stops at 2,000 updates or 1,200 seconds, whichever comes first. The best checkpoint is selected by fixed masked validation loss every 100 steps. A preliminary timing calibration may reduce the number of completed updates via the wall-clock bound; it cannot alter the validation rule or architecture after results.

The action model has four anonymous entities, role-conditioned equivariant representations, next-state classification and action-validity prediction. Its bounded qualification budget is at most 1,000 updates and 180 seconds. Its update budget/configuration, train/validation seed domains and complete held-out metrics are recorded with results before claims. Invalid actions contribute only to the validity objective, not fictitious next-state supervision.

Total intended local training cap:23 minutes plus tests, initialization, serialization and bounded evaluation. No paid API/cloud training, automatic downloads or open-ended jobs. Timings are measured, not inferred from prior unrelated models. Checkpoints/bulk logs remain under ignored `outputs/`; only compact results/manifests enter Git.

## Checks, baselines and measurements

Software gates: strict observation/target separation; exact generator/executor roundtrip; declared grammar and action validity independently checked without gold; immutable anchors; no unlicensed deletion; zero final MASK tokens; deterministic seeded sampling; resume/checkpoint integrity; shape/domain/nonfinite rejection; no test split access; unknown key slots not scored; candidate abstention when none is valid.

Report initial and trained fixed validation masked loss; generated candidate key accuracy on observed unanchored symbols (including a separate non-null measure), keep and boundary metrics, decoded edit similarity, candidate validity and family/grammar/morphology accuracy. Compare an untrained checkpoint and explicitly named random-key/all-null channel baselines using the same examples/anchors. The free-running evaluation uses 64 validation episodes, separately with zero and two synthetic anchors, four denoising proposals,12 denoising steps, and the same 20,000-expansion/beam 32 compiler budget for trained and untrained models. Compiler-only syntactic success is not credited to learned inference. Do not turn factorized proposal scores into posterior probabilities. Sampling/projection changes and candidate counts are recorded. No best-of-many selection by gold targets.

Causal checks use identity, full donor, targeted and norm-matched random patches with measured output effects. Finite transition extraction reports conflicts, unseen transitions and coverage. A known synthetic state label used by extraction is supervision, not discovered meaning. Bayesian evidence tests verify normalization, impossible evidence, duplicate/dependent evidence refusal, exact analytic information gain and serialization.

## Interpretation and stop rules

Any nonfinite loss/gradient, failed invariant, corrupted checkpoint or leaked split stops the affected run. A failed behavioral gate is reported without weakening it retrospectively. Lower denoising loss alone is not recovery. Valid re-encoding alone is not decipherment. Stable neural causal effects alone are not historical identification. No broad claim of universal communication-system inference follows from these restricted synthetic families.

All scores are labeled development qualification. There is no manuscript success criterion because no manuscript decoding claim is attempted. A later historical application requires revised channel families, suitable comparative data, independent grounding and a separate frozen evaluation.
