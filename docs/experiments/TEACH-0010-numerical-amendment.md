# TEACH-0010 native-weight head reconstruction amendment

**Written after an invalid first execution and before any valid TEACH-0010 result.** The first report's seed-0 base attention reconstruction error was `1.0728836e-6`, above the frozen `<1e-6` gate. The independent auditor rejected it. The invalid report and rows are preserved under `results/TEACH-0010/invalid-sdpa-*`; no behavioral result is valid yet.

TEACH-0008's generic head exposure obtains pre-output-projection values from `scaled_dot_product_attention`, then compares their projected sum with native `MultiheadAttention`. At encoder layer 2, their floating-point operation orders differ by one representable step above the threshold. PyTorch `MultiheadAttention` can return its own per-head attention weights while producing exactly the same native attention output used by the model. Multiplying those returned weights by the explicitly projected V vectors and applying the output projection reconstructs native attention within `7.1525574e-7` for both seeds and both base/edited panels; native attention followed by the explicit residual and MLP matches the native layer exactly.

The repaired TEACH-0010 decomposition therefore uses native MHA's returned per-head weights to expose head values. Interventions still replace only selected pre-output-projection head contributions and use the exact native attention write as the residual baseline. No seed, split, checkpoint, upstream key edit, head-selection rule, intervention, control or threshold changes. The first report exposed aggregates, so any corrected execution is explicitly non-blind and remains subject to the unchanged auditor.
