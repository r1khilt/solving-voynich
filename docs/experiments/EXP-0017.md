# EXP-0017 — Typed decoder-program search (synthetic method test)

Registered **2026-09-21** **before** Finnish holdout scores for this id. New experiment id. Does **not** alter EXP-0011–0016 thresholds. **Not** a Voynich decipherment and **not** a manuscript translation.

Linked: R1 in `docs/research/ai-hard-problems-2026-09-21/README.md`; HYP-001; HYP-002; M-001. Precedents (method, not claims): FunSearch-style program search with a frozen evaluator; Copiale hypothesize-and-retract; this repo’s recon/null gates.

## Question

Among a **restricted typed family** of short executable decoder programs (delete-nulls, copy/mutate deletion, homophone-class collapse, simple substitution into a held-out language), does search on **validation world-C only** produce a program that recovers synthetic \(C(L)\) on the frozen EXP-0013 Finnish holdout better than matched-random deletion and vocab-filter, after a length penalty?

Score is **not** Latin fluency and **not** EVA likelihood.

## Blindness

- Search and selection use EXP-0013 **validation** world-C rows only (English/Latin generated; digest `0d516e073ebd16d1a39a688a6a041900f94b72e4d10dacfc46c6eda8887d65ad`).
- Finnish holdout labels are **not** used to choose programs, operators, or the length penalty. One frozen winner is scored once on Finnish.
- Optional neural keep-probabilities come from the **frozen** EXP-0013 checkpoint (no architecture search, no retrain).

## Program family (frozen catalog)

Each program is an ordered list of 1–3 named ops. Human-readable form is `op1 |> op2 |> …`. Allowed ops:

| Op | Effect on keep-mask / string |
| --- | --- |
| `exact_count_neural` | Keep top \(n_{\mathrm{keep}}=\mathrm{round}(0.70 L)\) by frozen \(P(\mathrm{signal})\); ties → lower index |
| `joint_keep_run_neural` | EXP-0014c DP with frozen stickiness 0.88/0.72 and exact \(n_{\mathrm{keep}}\) |
| `exact_count_anti_copy` | Keep top \(n_{\mathrm{keep}}\) by **lowest** copy-aware feature (char-in-recent-window + token copy) |
| `exact_count_anti_periodic` | Keep top \(n_{\mathrm{keep}}\) by **lowest** period-hit score (periods 3–8) |
| `delete_copy_tokens` | Set mask 0 on tokens that are equal or edit-distance-1 copies of a previous token in the line |
| `homophone_collapse` | After the mask, map each kept non-space char to the most frequent char in its 4-bucket frequency class (changes recovered string; may hurt exact \(C(L)\)) |
| `mono_sub_rank` | After the mask, remap kept non-space chars by within-page frequency rank onto English training-surface rank (plaintext \(L\) metric is **secondary only** and **not** a pass criterion) |

Mask ops **AND** when sequenced. If a program has **no** mask op, deletion is `exact_count_anti_copy`. No other ops. No LM fluency term.

## Search (frozen)

- Enumerate programs of length 1, then 2, then 3 from the catalog (order matters; no repeated identical op). **Always keep every length-1 and length-2 program.** If length-3 candidates would push the pool over 200, shuffle length-3 only with seed `4017` and keep enough to reach 200 total.
- For each candidate, decode validation world-C. Require the EXP-0013 **null gates** on val (`null_recall ≥ 0.50`, `null_precision ≥ 0.50`, `pred_null_rate ∈ [0.15, 0.45]`); discard if any fail.
- Selection score: \(s = \mathrm{recon\_acc}_{\mathrm{val}} - 0.02 \times (\mathrm{n\_ops}-1)\). Length penalty is frozen; not tuned after Finnish scores.
- Winner = feasible program with highest \(s\). Ties: fewer ops, then lexicographically smaller readable string.
- Controls on val (reported, not used to peek Finnish): matched-random deletion (20 seeds); vocab-filter from training world-B/C tokens; **20 random same-length programs** from the catalog (seed 4017+1).

## Finnish pass rule (frozen before holdout scores)

Apply the frozen winner **once** to the EXP-0013 Finnish holdout (digest `31984a91eac2d4fecc44b716805dba11c939eb2c8a0b951090e683e7a3b93740`).

**PASS** if **all** hold:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc` **strictly greater** than matched-random `recon_acc` on this holdout (20 seeds; same procedure as EXP-0013)
5. `recon_acc` **strictly greater** than vocab-filter `recon_acc` on this holdout
6. vocab-filter signal-`mask_f1` ≤ 0.55
7. Winner’s **validation** \(s\) **strictly greater** than the mean \(s\) of the 20 random same-length val programs (complexity control)

**FAIL** otherwise. Secondary plaintext rank-sub accuracy vs true `plaintext` is logged when `mono_sub_rank` is in the program and **does not** decide PASS/FAIL.
