# TEACH-0004: learned two-read memory versus same-record controls

**Preregistration before any TEACH-0004 benchmark, training or evaluation.** This is a fresh-family, synthetic architecture-qualification experiment, motivated by [BEYOND_DENSE_BINDING_ARCHITECTURES.md](../research/latent-mechanisms-2026-09-21/BEYOND_DENSE_BINDING_ARCHITECTURES.md). TEACH-0002's small dense curriculum failed query-reversal binding; TEACH-0003 tests scale and auxiliary row supervision separately and is not used to choose this study's arms, thresholds or data. Neither outcome can decipher a manuscript.

## Rationale and restricted claim

[End-to-End Memory Networks](https://arxiv.org/abs/1503.08895) motivate successive differentiable reads; [Key-Value Memory Networks](https://aclanthology.org/D16-1147/) motivate separate address and value projections. [Attention Is All You Need](https://arxiv.org/abs/1706.03762) motivates the dense attention control. These papers concern other tasks and scales. Here the model receives the same **explicitly parsed four row records** in every arm. The two-read memory has learned token/role embeddings, learned F/G row encoders, learned query/key/value projections, softmax row attention, and learned answer classifiers. It is given row boundaries, task markers and the two-stage computation; it is **not** given token-equality operators, correct row indices, an intermediate-key oracle, or pointer supervision. A row head that classifies the right row is not sufficient evidence of causal mediation; this study tests behavior only.

The three frozen arms are `two_read`, `one_read` and `dense_row`. `one_read` has the same memory parameters (**222,215**), but for composed questions the G read receives a query plus an **unconditioned mean of the F row values**, rather than a query-conditioned F read. It still gets one learned F read for first-hop tasks and one learned G read for direct tasks. The dense control receives the same learned row-record encodings and task/query representations as six input slots and applies four dense self-attention blocks (**883,591** parameters). It has a different parameter count and compute cost. The principal comparison is matched **example exposure**, not equal-FLOP or equal-parameter causation. Benchmark median update times, parameter counts, measured wall time and sampled peak allocation are reported for each arm; any gain is an architecture-plus-compute contrast, not a pure efficiency or parameter effect.

## Frozen synthetic inputs and evaluation

The 14-token grammar has two F rows `name → key`, two G rows `key → object`, an explicit task marker and query, with 12 tokens per symbol class. New family namespace `TEACH-0004-v1/` hashes unordered `(name set,key set)` and `(key set,object set)` independently to train buckets 0–7 or holdout buckets 8–9. The training stream uses only F-train/G-train; row assignments and table ordering vary. Seeds: initialization `(64111,64121)`, stream `(64211,64221)`, evaluation `64311`. The same stream at each update, legal answer classes, evaluation suite and seeds apply to all arms. Training schedule: steps 0–1499 first-hop/direct/copy 45/45/10%; 1500–2999 first-hop/direct/composed/copy 30/30/30/10%; 3000–4999 10/20/60/10%. Each of two seeds runs 5,000 AdamW updates, batch64, 320,000 presented episodes per arm; repeated episodes and atomic relations are possible. Learning rate3e-4, weight decay.01, clip1.0, dropout0. No validation-selected checkpoints or seed substitution.

The frozen suite has 256 episodes in each of four F/G composed cells, 256 each first-hop train/holdout, 256 each direct train/holdout, 256 held-out copy, 128 held-out F-query reversal **pairs** (256 items), 128 held-out G-query reversal pairs (256), and 128 independently remapped F/G **quartets** (512): **3,328 items per arm**. A separate symbolic parser validates labels, splits, pair structure and four distinct quartet answers. These hold out *families*, not individual tokens. The lexical identities, row boundaries and table syntax are supplied by the generator, unlike Voynich text.

## Frozen metrics and decision

Report each seed and arm separately: exact item accuracy, held-out query-pair exactness and prediction changes, factorial quartet exactness, copy accuracy, visible-candidate membership, and descriptive Wilson intervals. Also report first- and second-read attention argmax agreement with the constructed row labels as **diagnostics**, not supervised targets or mechanistic proof. Query pairs and factorial variants share tables; report exact grouped denominators and do not treat them as independent item replicates.

`TWO-READ-QUALIFIED` requires **both seeds** of `two_read` to reach held-out first-hop and direct item accuracy≥.90; held-out first-hop and direct pair exact≥.80; jointly held-out composed item accuracy≥.85; each crossed F/G composed cell≥.85; factorial quartet exact≥.65; and copy≥.95. In **each seed**, two-read must exceed **both** same-row-record controls on jointly held-out composition accuracy and factorial quartet exactness by≥.15 absolute. If any gate fails after a complete qualified run, report `not_qualified`; this does not prove memory models cannot bind. If source, benchmark, numerical, artifact or global resource qualification fails, report `incomplete` and do not score a partial campaign. The later proposed four-row and causal cross-G transfer panels require separate registrations, not retrofitted success criteria here.
