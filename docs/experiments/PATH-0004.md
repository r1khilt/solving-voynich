# PATH-0004: where a composed lookup is causally carried

Registered 2026-09-22 before PATH-0004 model outcomes. PATH-0003 is inconclusive by its copy gate and its discovery panel is exposed. This study uses new lexical bundles and compares positions/layers rather than treating the selected PATH-0003 attention window as confirmed.

## Question and prior basis

On the fresh two-step `name -> key -> object` task, PATH-0003's post-block-15 edit of only changed first-table value fields redirected3/14 discovery answers. In a causal transformer, later second-table/question positions can already contain information copied from the earlier first table by that depth. The [QK/OV attention account](https://transformer-circuits.pub/2021/framework/index.html) and original-model [circuit tracing methods](https://transformer-circuits.pub/2025/attribution-graphs/methods.html) motivate testing that bypass, but do not establish it. In the Voynich case, [token co-occurrence structure](https://pmc.ncbi.nlm.nih.gov/articles/PMC3689824/) and [token-similarity generation](https://doi.org/10.1080/01611194.2019.1596999) likewise do not identify a reading. This synthetic qualification cannot be transferred directly to manuscript semantics.

## Panel and inputs

Twelve new, frozen bundles, six discovery/six confirmation, use disjoint names, keys, outputs and copy words from PATH-0003. Two templates. Each bundle has both first-table orientations, two queried names and one unrelated literal-copy task per orientation:24 composed and12 copy records per split. Source/donor differ only by swapping the two first-table keys; second table and question are unchanged. Verify equal rendered lengths, at least two changed token positions before the common suffix, and textual identity of the second table/question. First-token source/donor answers must differ for eligibility. Baseline competence gate per split: at least12/24 both-clean-correct composed records and10/12 source-copy correct; otherwise **inconclusive**. Reverse orientations/query variants are dependent; bundle is the resampling unit.

## Frozen intervention grid

At zero-based post-block layers7,15,23, capture clean source/donor prompt residuals and apply donor-minus-source deltas to seven fixed scopes: identity, only changed first-table value-token positions (`value`), only the unchanged downstream suffix after the last changed token and before the final query position (`suffix`), union of value and suffix (`value_suffix`), all earlier positions (`all_earlier`), whole prompt (`whole`), and independent Gaussian edits at suffix positions matched to the donor displacement norm at each position (`suffix_random`). The suffix deliberately includes the second table **and** later query text; it is not named a pure second-table mediator. Seed51071. All72 records ×3layers×7conditions=1,512 generations after baselines. Primary registered layer15, with7/23 as fixed timing diagnostics.

Whole-prefix donor first-token logits must agree with donor clean logits within .002 and match argmax for **every** record/layer; identity must exactly reproduce source generation. At primary layer, the whole-prefix full donor answer must be accepted on≥90% of eligible composed records, and copy preserved on≥90% of baseline-correct copy records, or positional tests are uninformative. Value/suffix positions are nonoverlapping and `value_suffix` must equal their sum; norm-matched random suffix is a confound control, not an alleged semantic null.

The primary **downstream-suffix bypass** is supported exploratorily if, at layer15 in confirmation, suffix-only reaches≥50% donor full answers on eligible composed records, beats suffix-random by≥20 percentage points, and preserves≥90% baseline-correct copies. The primary **combined rescue** is supported exploratorily if value+suffix reaches≥50%, beats value-only by≥20 points, and preserves≥90% copies. All earlier/full donor are positive/context controls, not claims of unique storage. Report all layers, templates, bundles, complete answers and first-token agreement even if a gate fails. No post-hoc removal or threshold changes. Use10,000 seed-fixed bundle resamples for descriptive differences only.

One existing local Qwen3-8B-4bit model, float32 dense block computation with `MLX_ENABLE_TF32=0`. No training, model download, paid API or manuscript final scoring. Maximum50 minutes including model load and baselines,≤45GB MLX allocation. Raw rendered IDs/captures ignored under `outputs/PATH-0004`; compact rows, source hashes, qualifications and audit under `results/PATH-0004`. Stop and record a cap/numerical failure; no unregistered rerun. Independently audit the full grid, labels, hashes, gates and decisions.
