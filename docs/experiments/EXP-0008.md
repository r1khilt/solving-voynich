# EXP-0008 — Blind predictive-state recovery across keys and generator families

Registered 2026-09-21 before real model training or recovery outcomes. Exploratory calibration of M-001/M-003 and the label-free direction in the backlog. This is a deliberately finite synthetic benchmark; it does not ingest any manuscript text or supply a Voynich decoder. It runs alongside EXP-0009 and EXP-0010 under CAMPAIGN-0001.

## Question and distinction from earlier experiments

Can a model trained only to predict visible symbols provide a compact predictive partition that we discover **without hidden-state labels, true state count, or oracle probabilities**, and does that partition remain useful on new encoding keys or an omitted family? EXP-0004 and EXP-0006 supplied correct latent labels/probabilities to the diagnostic or alignment fit. This experiment removes that supervision from fitting and selection.

The method is explicitly allowed to adapt an unsupervised partition and estimate observed future-symbol frequencies from fresh text for each evaluation key. Neural weights remain frozen. Therefore the transfer claim is **a frozen pretrained feature extractor with unlabeled per-key adaptation**, not zero-shot extraction, recovery of a historical cipher key, or full generator identification. A predictive partition is not automatically a minimal state machine, and many observationally equivalent generators exist.

## Sources reviewed before implementation

[Reddy and Knight, 2011](https://aclanthology.org/W11-1511.pdf), section 2.3, already use an unsupervised two-state HMM to recover a broad manuscript vocabulary division. Finding clusters alone would not be new semantic evidence.

Their residual-to-belief regression **uses true belief labels**. Their RRXOR case illustrates why next-symbol probabilities can discard distinctions relevant to later predictions. We inspected those methods and results; our text-only PCA/clustering and three-future-symbol evaluation are exploratory extensions, not a replication or a method attributed to that paper.
- [Weiss, Goldberg and Yahav, ICML 2018](https://proceedings.mlr.press/v80/weiss18a/weiss18a.pdf) extract automata using queries/counterexamples from recurrent networks. This motivates evaluating explicit abstractions, but our fixed k-means partition does not implement their active learning algorithm or guarantee an equivalent automaton. Primary paper and abstract inspected.
- [Kambhatla, Born and Sarkar, EACL Findings 2023](https://aclanthology.org/2023.findings-eacl.160/) train on synthetic cipher/plaintext examples and test simple/homophonic ciphers across keys. This supports key holdouts and recurrence-aware controls, while our models never receive plaintext. Primary abstract rechecked alongside the existing full-paper review.

## Fixed generators and independent streams

All observations use the same twelve-symbol alphabet, encoded as model IDs 1–12; ID 0 is padding only. No family/key/state token is given to the model. Original synthetic data is generated locally, with no third-party corpus or paid service.

1. **Cycle/null:** three hidden states. With probability 0.7 advance one state and emit uniformly from that state's four keyed symbols; otherwise retain state and emit uniformly from all twelve symbols. Prior is stationary uniform.
2. **Branch/null:** four hidden states. With probability 0.7, advance by one with probability 0.75 or by two with probability 0.25, then emit uniformly from the destination state's three keyed symbols; otherwise retain state and emit uniformly. Prior is stationary uniform.
3. **Lag copying:** first eight symbols uniform; thereafter copy the symbol eight positions back with probability 0.8, otherwise emit uniformly. The final diagnostic label is the next copy-source symbol, **not the complete hidden state**. Its distribution is invariant to alphabet permutations; separately seeded streams are controls, not genuine new-key transfer.
4. **IID control:** uniform independent symbols, with independently drawn seven-way state labels and binary nuisance labels. Neither hidden label is identifiable. Alphabet permutations have no substantive key meaning here.
5. **Held-out RRXOR family:** repeated random bit, random bit, their XOR, with six homophones for each bit and an unknown stationary initial phase. The edge-emitting process has five generating states. Four new encoding keys are used. No strings from this family enter LM training/checkpoint selection. This is an omitted algebraic dependency family, not a natural-language/cryptographic security benchmark.

All real generator state counts are confined to generation and frozen final diagnostics. The fitting API receives visible arrays/features/futures only. All families also have independent binary nuisance labels in the final test; they provide an observationally indistinguishable extra-state control. No promise of a uniquely identifiable true state count is made, especially for ambiguous nulls and mixed-state beliefs.

Master data seed 8201 generates key permutations; independent SeedSequence streams from 8202 generate data. The same number 8202 also seeds extraction through an independent RNG, which is not a shared generator stream. There are eight development encoding keys per training family. For each key generate 1,024 independent length-257 training strings and 16 independent validation strings: **32,768 training strings (8,421,376 stored symbols), 512 LM validation strings**. Homophonic families reserve keys 8–9 as new encodings. Copy/IID keys 0,1,8,9 denote independent-stream controls with permutation-invariant rules.

For each of 20 fixed diagnostic datasets—four per training family plus four RRXOR keys—generate disjoint fit/validation/test pools of 1,024/512/1,024 contexts, 128 preceding symbols plus three future observations. Only the test has saved truth arrays. Visible and sealed-truth files are separate; the visible loader rejects unexpected fields. Hash every file and preserve key/generator tables in ignored data storage. Assert no duplicate complete generated strings or complete diagnostic contexts in the audit's shared hash set. This is an exact full-string check, **not** a near-duplicate or all-substring audit. Independent seeds and full context holdouts define the split, not token-random splits.

Large: four layers, width 256, four heads, feedforward 704; **3,220,224 parameters**. Shared existing dense causal architecture with RoPE and SwiGLU, no new architecture feature. Both see the same mixture and tokenization; this is a controlled capacity comparison rather than importing unverified frontier-scale claims.

Each run: 4,000 AdamW updates, batch 32, context 256, learning rate 0.0003, weight decay 0.01, gradient clipping 1.0, float32, dropout zero. Uniformly sample stored training strings with replacement. Validate every 500 updates on all 512 fixed LM-validation strings; retain minimum validation-loss checkpoint. No early stopping or seed/size selection on recovery truth. ## Label-free extraction and frozen scoring

For each frozen model and diagnostic dataset, collect (a) its final-position last-layer residual and (b) its next-symbol probability vector, both from the preceding 128 visible symbols only. The second representation is an explicit output-information comparison; successful residual clustering that merely matches it does not demonstrate deeper mechanism recovery.

For each representation separately:

1. Standardize with fit-pool means/std, flooring std at 1e-5. Fit PCA to fit features and retain min(16, feature width) directions. Neither labels nor future observations determine this projection.
2. Fit k-means partitions with **K in 1,2,4,8,16,32**, fixed seed 8202+K, at most 30 iterations, fixed random observed-point initialization. K is not given the true state count. No repeated best-of-many starts.
3. For each cluster estimate twelve-way emission frequencies for future symbols at offsets 1, 2 and 3 from the fit pool, with additive-one smoothing. These are **real observed symbols**, not oracle probabilities or latent labels. The three marginals do not specify the full joint distribution over a future three-symbol sequence.
4. Select the smallest K whose mean observed validation bits across the three offsets is within 0.01 bits of the best candidate. Use all fixed candidates, report all validation scores. Test text never changes the chosen partition.

Preserve partition parameters, selection records and frozen test predictions. **Complete all four LM fits and all 160 representation fits before opening any sealed truth file.** Write and hash `FROZEN_BEFORE_TRUTH.json`, then run a diagnostic-only phase that verifies artifact hashes and cannot call a fit or change a selected model. Generator code necessarily knows truth while creating sealed files; blind fitting code never consumes it. This is a reproducible software separation, not an adversarial security enclosure against the researchers.

Baselines fitted to exactly the same unlabeled abstraction-fit examples: unigram; last-symbol conditional; last-four-symbol conditional with last-symbol fallback for unseen suffixes. Compare all three future offsets on the same test contexts. Also score the frozen neural next-symbol forecast itself, separately from abstraction prediction.

## Outcomes, controls and decision rules

Primary descriptive quantities: test observed bits at each future offset, mean across the three offsets, selected K, and final oracle KL at each offset. Lower prediction loss means better prediction, not decipherment. Preserve per-context mean loss and all model/key results; report variation across keys and seeds. Do not treat densely repeated observations as independent scientific replications or claim statistical significance after many comparisons.

Only after freezing, measure adjusted Rand index (ARI) between cluster assignments and true generating state / Bayesian posterior-MAP state. ARI is permutation invariant and chance corrected; no label mapping is fitted on test rows, and no accuracy percentage is inferred from it. For copying it instead compares with the explicitly limited next-copy-source label. Independently permute final MAP labels 100 times, seed 8203, and report their empirical 99th percentile. This is a descriptive null reference, not a multiple-comparison-corrected significance guarantee. Measure independent nuisance-label ARI and last-symbol-only ARI too. Never retrofit K or the fit after viewing these values.

Predeclared practical checks:

- **Predictive partition:** mean three-offset test gain over unigram at least 0.05 bits, plus posterior-MAP ARI above the fixed permutation null reference.
- **Beyond last symbol:** mean three-offset gain over last-symbol conditional at least 0.03 bits, and posterior-MAP ARI at least 0.05 above last-symbol ARI. A recoverable-but-trivial last-symbol partition does not satisfy this stronger check.
- **Unrecoverable controls:** report any positive IID/nuisance association as a warning and retain failures; no true recovery should be claimed from chance-level ARI or superficial K matching.
- Report key/family/seed/size outcomes, including failures; no blanket mechanism-recovery claim based on a favorable family. A novel-family failure may reflect poor frozen neural forecasting, poor abstraction, a false finite-partition assumption, or limited observational identifiability. The direct forecast/oracle comparison helps separate these possibilities without selecting another model.

The source is registered and published before full data/training. Tiny CPU unit tests verify probability/filter equations by explicit path enumeration, key equivariance, future exclusion, state-label isolation, partition save/load and no mutation, ARI semantics, split inventory, and normalized baselines. Unit-test synthetic examples are correctness fixtures, not experimental outcomes.
