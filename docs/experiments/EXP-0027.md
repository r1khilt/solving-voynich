# EXP-0027: prequential word-copy channel on manuscript pages

Registered 2026-09-24 before running this experiment's model scores. This is an **exploratory manuscript-facing model comparison** on the already repeatedly exposed ZL3b validation split, not a decipherment or a claim of untouched confirmation. The 25-page final test remains unscored.

## Question and prior work

Does a normalized one-edit copy channel improve prediction of the *next certain EVA word* beyond a strong word-frequency/character-spelling model and an exact-repeat cache? If it does, is the gain specifically tied to observed within-page order rather than merely the page's vocabulary? This asks whether adding a copy/edit channel to a future constrained decoder is empirically justified; it cannot distinguish meaningless self-citation from morphology, alliteration, topic, or a cipher with correlated outputs.

[Timm and Schinner's original generator and materials](https://github.com/TorstenTimm/SelfCitationTextgenerator) explicitly copy and vary previous tokens and use edit-neighbor networks; [Timm's earlier study](https://arxiv.org/abs/1407.6639) argues from nearby similar forms. Those are rival historical hypotheses, not established facts. [Lindemann and Bowern's corpus comparison](https://arxiv.org/abs/2010.14697) emphasizes transcription/section sensitivity and unusually constrained within-word characters. [Grave et al.'s neural cache](https://arxiv.org/abs/1612.04426) and [Khandelwal et al.'s context study](https://aclanthology.org/P18-1027/) show that ordinary language prediction can benefit from recent-word copies. Hence even a positive predictive result is *not* a hoax test. The repository's prior `evaluate.py` has an EVA-unit suffix-copy baseline; EXP-0019's surface-stat generator search failed its IID sanity gate. Neither tests normalized one-edit next-word likelihood against an exact-copy model on held-out physical leaves.

## Data and model

Use pinned ZL3b source SHA-256 `bf5b6d4ac1e3a51b1847a9c388318d609020441ccd56984c901c32b09beccafc`; derived train/validation SHA-256 `49618c7be69cef573fe9ad8ae3627ad9f7b495601af1897aafb6082837fceca4` / `9bee4149f26fc49b49e4a826b73598dfb79a1e785731c15a1763489315a2efd3`. Train contains 81 physical-leaf groups/177 pages; validation 10 groups/24 pages. No test read. Only words matching `[a-z']+` are scored or used as copy sources; other events remain in the page stream but cannot supply a copy. Reset copy context at page boundaries. Pool all locus types for the primary score; report `P0` and non-`P0` as descriptive strata. EVA characters are transcription units, not established glyphs or phonemes.

Base distribution over finite strings: empirical train word counts with a proper character 4-gram backoff (word-start padding and explicit end symbol), `P_base(w)=(count_train(w)+beta*P_char(w))/(N+beta)`. Unseen character strings outside the train alphabet have zero probability and halt if encountered in scorable validation; this is declared before outcomes. Character count smoothing is alpha 0.1, recursive concentration 5.0. The base is normalized over strings on the training alphabet. Select `beta` from {1,10,100,1000} using only a deterministic train-leaf calibration subset (last 16 of 81 SHA-256-sorted leaf IDs), fit on other 65 leaves, then refit on all 81.

For the last `W` certain words of the same page, define a normalized cache distribution as recency-weighted sum of `K(w|v)`. `K` is either exact copying or a mixture of exact, one substitution, one insertion, and one deletion. Each edit operation draws a position uniformly and, where needed, a new character uniformly from the training alphabet (substitution excludes the original); multiple edit paths to the same word are summed. Candidate edit mixtures are exact weights 0.25, 0.5, 0.75, with remaining mass split substitution/insertion/deletion 2:1:1. Candidate windows {4,16,64}, recency half-lives {4,16,infinite}, and cache mixture weights {0.05,0.1,0.2,0.4,0.6,0.8}; include lambda=0 as the base. Fit candidates to the same train-leaf calibration subset. The exact-copy arm receives its own selected window/decay/lambda. Never tune on validation.

## Fixed readout and controls

Score each certain validation word online, with only the prior observed words on its page as cache context. Primary metric is total negative log2 probability per scored word; retain per-page and per-leaf sums/counts. Primary contrast `exact bits - edit bits`: positive means the one-edit channel improves predictive coding over exact repetition. A programmatic arithmetic audit independently recomputes all reported aggregates from per-page rows. Report base-vs-exact and base-vs-edit too. Use a deterministic 2,000-replicate physical-leaf bootstrap for 95% intervals on paired score differences (seed 270027), respecting leaves as the unit.

Order control: 100 deterministic within-page permutations of the same eligible words (seed 270127), retaining page and locus slots and noneligible tokens, scored with *frozen* train-selected models. Compare the real edit-over-exact contrast and real edit-over-base gain with the permutation distributions. These are diagnostic nulls, not independent manuscripts. Positive control: on a separately generated stream in each validation page's slot skeleton, replace 30% of eligible words by a one-edit output from a uniformly chosen prior eligible word within 16 positions (seed 270227); retain the other 70% original words. The edit channel should beat exact on this known edit-insertion stream. This control changes word frequencies and cannot be used as a direct Voynich match.

Predeclared support for *further copy-channel research*, not a historical conclusion: real `exact bits - edit bits` >=0.05 bits/word, paired leaf-bootstrap lower 95% bound >0, real edit-over-base gain greater than the 95th percentile of page permutations, and positive control edit beats exact. Failure of any condition means no support under this restricted model. Report all outcomes and do not retune thresholds after seeing them. Even a pass needs independent language/cipher/nonsemantic corpora and a constrained decoder before interpreting manuscript meaning.
