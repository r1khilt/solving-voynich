# PATH-0009: retrospective first-token candidate evidence after output-format failure

Registered before opening PATH-0007's saved first-token logit arrays for this question. **Exploratory, exposed-data diagnostic only.** PATH-0007's generated two-hop answers were all non-exact explanatory responses; this test asks a narrower question: when forced to compare just the two object words, do its first-token logits track the queried table path? This cannot rescue PATH-0007's registered verdict or count as fresh confirmation.

Use the frozen PATH-0007 prompt/task records and ignored baseline `first_logits` arrays, with the existing local tokenizer only; no model inference. For each object word, consider only *single-token* variants of the bare word and leading-space word, deduplicated. Candidate score is log-sum-exp of its one-token logits, divided by no temperature because only within-prompt pairwise margins are compared. Words lacking a one-token variant would be excluded and reported, never silently approximated with a first subtoken. For each bundle/style/orientation, the two query prompts expect opposite object words. Score both query-specific expected-versus-alternate margins; count a **paired query reversal** only when both margins are positive. Source/donor swaps and reverse orientations are dependent; report by bundle, style and split, not as independent binomial evidence. Also report the correct-object first-token candidate rank and whether the generated first token was one of either object tokens.

A high paired-reversal rate would motivate a **new, preregistered** constrained two-choice output interface on fresh bundles; a low rate would motivate teacher training or different task/model. Neither outcome establishes actual composition: relative object-logit preference can reflect prompt artifacts or lexical priors, and the model was not asked to emit a constrained answer in PATH-0007. Do not retrofit a positive PATH-0007 decision. CPU-only under2 minutes, no manuscript score, paid API, training or network. Save compact results and exact source/input hashes in `results/PATH-0009/`; no threshold-driven model selection in this retrospective test.
