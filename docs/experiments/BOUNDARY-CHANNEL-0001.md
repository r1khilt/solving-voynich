# BOUNDARY-CHANNEL-0001 — boundary geometry is a useful but unreliable proxy

**Status:** retrospective, exploratory development assay on training-assigned leaves only (2026-09-25). This was **not preregistered**, and its observed score must not be treated as a confirmatory gate. No validation or reserved final-test text was scored. No word segmentation, language, meaning, key, or decipherment is inferred.

## Question and prior work

Are the spaces encoded by ZL3b's certain (`.`) and uncertain (`,`) separators faithful enough to the manuscript's physical gaps to support a new unit model? Existing EXP-0036–0042 edge assays predict one transcribed token's start from the preceding token's end, but those tokens are editorial units, not established plaintext words. Reddy and Knight [2011](https://aclanthology.org/W11-1511/) discuss the older end-to-start dependence; Rozanova and Temerev [2026](https://arxiv.org/html/2608.17096v1) quantify edge and weak whole-token order and explicitly distinguish transcription marks, manually drawn word boxes, and direct pixel gaps. Their [reproduction archive](https://github.com/lrozanova/voynich-units) supplies coordinates plus a small direct-ink pilot. Work on undersegmented ancient scripts by [Luo et al.](https://aclanthology.org/2021.tacl-1.5/) motivates representing boundaries as uncertain latent variables, but it relies on phonetic/cognate information unavailable here. This assay therefore tests a measurement channel and a predictive side feature, not a joint decipherment solver.

## Methods, observed results, and independent checks

The row builder parses only assigned train P loci, conservatively drops malformed/uncertain spans, aligns transcribed forms to visual box forms within each folio, and measures signed box-to-box gaps normalized by median box width. A separate auditor extracts the published author's parser functions from the pinned archive and independently reconstructs rows. It finds 16,705 possible author-parser boundaries, with our three conservative exclusions at `f103r`, `f2r`, and `f55r`, and matches every retained `(folio, visual index, label, pixel gap)` exactly. Audit: `results/BOUNDARY-CHANNEL-0001/audit.json`.

An **unregistered train-only** fivefold physical-leaf cross-fit predicts the next token's initial EVA compound from previous terminal compound, ZL separator label, and visible-line role. Adding four box-gap bins with fixed count shrinkage yields **+0.08637 bits per adjacent pair** over that base on 16,702 rows. A 2,000-draw physical-leaf bootstrap interval is `[+0.07322,+0.09781]`; 100 within-folio/label/previous-last/role bin permutations have mean **−0.01609**, maximum **−0.01145**, and a one-sided Monte Carlo p-value **0.0099**. These are development diagnostics, not an independent test: bins and shrinkage were chosen during this exploratory block, and the box measurement observes the right-hand visual token's bounding geometry. A second implementation independently replays all five folds, per-leaf sums, permutations, and bootstrap (`results/BOUNDARY-CHANNEL-0001/preflight_audit.json`).

The direct-ink check is the decisive limitation. On the 286 accepted pilot rows, normalized box and direct-ink gaps correlate only **Pearson 0.243 / Spearman 0.204**. Distinguishing certain from uncertain transcription labels by gap gives box AUC **0.895** versus direct-ink AUC **0.616** (six-folio bootstrap 95% `[0.554,0.684]` for direct ink); the box-minus-ink AUC gap is **0.279**, bootstrap interval `[0.205,0.368]`. Direct ink is not pure noise: certain gaps average **4.985 px** and uncertain gaps **3.143 px**, a **1.842 px** difference, positive in all five folios with both label classes. But it is far weaker than the box channel. The source paper likewise cautions that word boxes constitute another human segmentation judgment. The pixel pilot is only six folios and heavily label-imbalanced; its folio bootstrap is not a whole-manuscript estimate.

The exploratory `+0.08637` gain therefore demonstrates that box geometry contains information beyond ZL's separator mark **for predicting the next transcribed initial**. It does **not** show that commas join plaintext words, that dot-separated tokens are true words, or that a language model can infer actual ink gaps from text alone. Box coordinates and their alignment could encode annotation choices, glyph shape, spacing, hand, or layout. A future right token's box is side information; comparing this score to a prefix-only language model would be unfair.

The direct-pixel result shifts the next decision from building a larger box-conditioned decoder to **measuring raw ink at scale with blind quality control**. First calibrate a direct-ink extractor on the 300 archived boundaries, checking its per-folio errors and boundary-label leakage; then apply it only to training leaves and test known-boundary synthetic controls. Freeze a decision rule before any further exposed validation or reserved-test text. In parallel, the blinded plant-image matching request can provide an independent semantic anchor if a human reviewer selects matches from imagery alone. That review is pending and has no result in this report.

## Validation and limitations

Three focused tests, Ruff and Python compilation passed; the full repository suite passed **1,158 tests, eight skipped, 23 subtests** in 191.35 seconds. The first attempt to import the author's full reproduction module failed because an optional plotting dependency was absent, so the auditor extracted only its pure parser functions; the first preflight launch lacked `PYTHONPATH` and was rerun with the documented command. The ink-overlap join originally applied an overly broad uniqueness check to all 16,702 rows rather than the 300 pilot keys; it was corrected before reporting the direct-ink result. No paid API, material training run, or final-test scoring occurred. This retrospective work contains many researcher choices and the direct-ink sample is small; only a prospectively frozen, externally measured follow-up can support a stronger boundary claim.
