# EXP-0042 — does shared word/context structure add predictive information beyond the terminal glyph?

**Registered 2026-09-25 PDT before any EXP-0042 manuscript validation score.** The nine matched P0 validation leaves have been repeatedly exposed by EXP-0036–0041. Treat this as adaptive exploratory model criticism, never as independent decipherment confirmation; keep the manuscript final test unopened.

## Question and prior method review

The train-fitted EXP-0039 last-glyph model predicts the next initial glyph in both ZL basic-compound and Glen Claston's independently authored v101 reading, but sparse exact previous-token and two-back count tables fail to add held-out gain. That is not evidence that morphology, syntax or previous context is absent: exact-word cells are sparse. [Reddy and Knight (2011)](https://aclanthology.org/W11-1511/) and [Rozanova and Temerev (2026)](https://arxiv.org/html/2608.17096v1) already locate unusually strong Voynich edge dependence alongside weak observed-token identity order; the latter explicitly warns that observed tokens need not be plaintext words. [Chen and Goodman (1996)](https://aclanthology.org/P96-1041/) motivate comparing smoothed estimators by held-out predictive loss rather than unsmoothed table fit. [Berger et al. (1996)](https://aclanthology.org/J96-1002/) motivate additive feature combinations, while [Papay, Padó and Vu (2018)](https://aclanthology.org/W18-1204/) show why character-sharing can help sparse word representations in low-resource data. Our count-shrunk likelihood-ratio residual is **not** their maximum-entropy optimizer or proof of semantic morphology. The transfer from millions-of-word linguistic benchmarks to ~19k manuscript tokens is a hypothesis tested here, not a source-supported guarantee.

Question: can train-only shared form features and earlier context improve out-of-leaf next-initial-glyph log probability over a **train-selected edge-only recalibration of the frozen EXP-0039 last-glyph conditional baseline**? Both use the same residual model and hyperparameter grid, though richer features necessarily have more capacity. Without that comparator, a suffix feature could merely correct the baseline's fixed smoothing, so gain over `p0` alone would not show information beyond the last glyph. If richer features help, is the improvement present across both independent glyph readings and absent in a matched no-context synthetic control? If they do not, that is only a failure of this finite-data model class.

## Frozen model and selection

For each view, fit the unchanged EXP-0039 `global(role) → context(section,hand,role) → previous-last` Laplace/pseudocount conditional distribution on the fit groups. Let it be `p0(y|x)`. The full predictor is a normalized residual log-linear distribution

`p(y|x) ∝ p0(y|x) exp[(α / m(x)) Σ_{f∈F(x)} log(pκ(y|f)/q(y))]`,

where `q` is a Laplace-one global target-initial distribution on the same fit groups, `pκ(y|f)=(count(f,y)+κ q(y))/(count(f)+κ)`, and `m(x)` is the number of named feature templates present for that event. Unknown validation features contribute zero. All target alphabets include the baseline's `<unk>` class. This is an additive, shrinkage-controlled conditional model with exact normalization; it has no access to future tokens, plaintext, images, copy-source search or validation labels during fitting. `α=0` is exactly the unchanged last-glyph baseline.

The **edge-recalibration control** uses three named features: previous last glyph, `(last, edge role)`, and `(last, section, hand)`. Each richer family contains these same three features plus one fixed addition: (1) **form**: previous token first glyph, length capped at8, prefix2/3, suffix2/3 and exact whole form; (2) **history**: previous-previous token first/last and suffix2, with start sentinels; (3) **layout**: previous token's within-run relative-position quartile and run length capped at12; (4) **all**: union of the three additions. Feature values are exact glyph tuples, never relabeled between GC and ZL. The exact whole-form feature is a sparse fallback, not an assumption that tokens are words. Both edge and richer predictors start from the same `p0`; an edge-only fit can correct its smoothing without claiming new form information.

Split the **existing manuscript training leaves only** by `int.from_bytes(sha256(leaf UTF-8)[:4],big) mod 5`: remainder0 gives internal development (preflight:16 train-assignment physical leaves,624 runs/3,726 ZL adjacent pairs); other remainders internal fitting. Use the same leaf names for GC and both book controls, avoiding token-level leakage. For each view fit all feature counts and baseline on internal fitting groups, then separately select (a) the `edge` recalibration's κ and α, and (b) the best richer family, κ∈{5,20,80} and α∈{0,0.5,1,2,4,8}, by maximum internal-development gain in bits/pair over their common `p0`. A contender must exceed α=0 by **0.005** bits/pair; otherwise choose α=0. Resolve ties within `1e-12` by smaller α, larger κ, and fixed richer-family order `form,history,layout,all`. Refit both selected specifications and baseline on **all** source training groups, then score the unchanged validation groups once. Log both complete internal grids and selections. There is no neural training, so this directly probes feature-sharing before interpreting hidden states in a larger model.

Report per-view validation `edge−p0`, `richer−p0`, and primary **`richer−edge`** gain in bits/pair, per-leaf primary sums/pair counts, and a 2,000-draw physical-leaf bootstrap95% interval for manuscript views only (seeds `420600` ZL, `420700` GC). Report the already frozen EXP-0039 baseline last-glyph gain and reproduce it to `1e-10`. Do not bootstrap artificial book leaves as independent language samples. No model is selected based on manuscript validation, English/Italian outer validation, synthetic outer validation or any bootstrap interval.

## Decision and audit

Calibration passes only if **all three** synthetic positives have `richer−edge` at least +0.10 bits/pair on their outer validation and **all three** matched negatives have absolute `richer−edge` at most0.03. Readable-control sensitivity requires at least one of English/Italian to have `richer−edge` at least+0.02 on its outer validation; otherwise report the model as insufficiently calibrated for natural-language comparison. An exploratory `richer_context_signal` label requires calibration, readable sensitivity, and **both** manuscript views to have `richer−edge` at least+0.02 with physical-leaf bootstrap lower endpoint>0. All other outcomes, including negative gains, must be reported; failure does not establish absence of linguistic structure. Even a positive result identifies predictive structure under a competitor model, not historical meaning, syntax, language or decipherment.
