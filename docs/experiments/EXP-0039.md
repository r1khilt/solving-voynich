# EXP-0039 — independent-transcriber challenge to the known boundary effect

Registered 2026-09-25 **before** any EXP-0039 manuscript predictive score. This is adaptive exploratory work: the physical-leaf validation split has already been inspected repeatedly. The final test is reserved. The primary purpose is to determine whether the EXP-0036–0038 held-out end-to-next-start dependency persists in an independently created transliteration, not to claim a discovery or decipherment.

## Prior work and question

[Currier's 1976 observation, recounted by Reddy and Knight (2011)](https://aclanthology.org/W11-1511.pdf), [Smith and Ponzi's direct boundary-glyph study (2019)](https://agnosticvoynich.wordpress.com/wp-content/uploads/2019/06/glyph-combinations-across-word-breaks-in-the-voynich-manuscript-preprint.pdf), and [Rozanova and Temerev's edge-glyph and matched-generator study (2026)](https://arxiv.org/html/2608.17096v1) establish that the qualitative effect is prior art. The last study also shows that whole-token identity order is weak while edge order is measurable, and that tested Naibbe/self-citation generators do not reproduce the whole profile; these are source-specific findings, not an exclusion of all ciphers or nonsemantic generators. EXP-0036–0038 use an exposed ZL3b leaf split, train-fitted predictive likelihood, endpoint/half-shuffles and section/hand/edge-role controls; they have *not* checked a different transcriber's glyph choices. [Zandbergen's transcription overview](https://voynich.nu/transcr.html) identifies Glen Claston's v101 as an independent transliteration with finer glyph distinctions. [The IVTFF format account](https://voynich.nu/extra/sp_transcr.html) warns that the original v101 file's markup clashes with actual v101 glyph symbols; use its standardized GC IVTFF 2a file instead. The statistical method uses train-only smoothed conditional probabilities in the spirit of [Chen and Goodman (1996)](https://aclanthology.org/P96-1041/), without claiming optimal smoothing.

Question: does a previous token's terminal **v101 glyph** predict the next token's initial v101 glyph beyond a section/hand/line-role baseline, after keeping line endpoints, half-position and word inventory fixed in null shuffles? How does it compare with a matched ZL subset and with other properties of the previous token? This is not a test of word meaning, reading direction, copying, language or cipher identity.

Process GC page headers/loci only for train and validation assignments; skip reserved leaves before parsing content. Take `P0` paragraph loci, valid dot-linked runs of at least four certain tokens. Comma (uncertain separator), `?` unreadable text, editorial and drawing markup sever runs; discard the whole token containing `?`. Treat every permitted v101 ASCII glyph as one symbol and every `@nnn;` high-ASCII code as one atomic glyph. Preserve case and number glyphs. Apply page `$I`/`$H` metadata and start-of-locus `<@H=...>` hand changes; reject unsupported mid-locus changes. Never map v101 glyphs into EVA. Source preflight *before scoring* found 3,000 train and 383 validation GC P0 loci; all 3,383 locus IDs match a ZL P0 locus. The nine physical leaves with qualifying matched paragraph runs are the eligible validation units; absence of qualifying P0 on one leaf is not a negative score.

For the comparison, use only the matched ZL `P0` locus IDs in processed train SHA-256 `49618c7be69cef573fe9ad8ae3627ad9f7b495601af1897aafb6082837fceca4` and validation SHA-256 `9bee4149f26fc49b49e4a826b73598dfb79a1e785731c15a1763489315a2efd3`. Eligible ZL words match `[a-z']+`, other tokens interrupt runs; greedily merge `cth, ckh, cph, cfh, ch, sh`. Include source-recorded current hand tags. This comparison aligns physical leaves and standardized locus IDs, **not individual words or glyphs**; predictive bits from the two alphabets are not identical estimands.

## Frozen model, controls and gates

For each transcription separately, infer the target alphabet from **training** glyphs only, add an `<unk>` target for validation glyphs unseen in train, and report unseen-target counts. Fit the same role-conditioned global Laplace-one prior; a `(section I, hand H, first/middle/last pair role)` prior backs off to it with 50 pseudocounts. Fit train-only feature-conditional target distributions with 20 pseudocounts toward that prior. Features are previous token's `last`, `first`, length capped at 8, and penultimate symbol (or `<single>`). Report held-out log2 gain over the common base for each.

Two *richer but still finite-data* diagnostics: fit previous full-token identity and `(last, previous-previous token's last)` target tables with 20 pseudocounts backing off to the `last` predictor. Report their real incremental held-out gains over `last`, with physical-leaf bootstrap95% intervals; neither is a true conditional-independence test nor an exhaustive natural-language model. Full identity mathematically contains terminal identity, so a lower finite-sample score cannot show causal primacy of terminal glyphs.

For each transcription use 200 fixed-seed permutations that retain every run's first and last token and shuffle only within each interior half. They preserve the line's token multiset, uncertain-run breaks and coarse position. Compute real-minus-mean-null last-feature bits/pair, null95th percentile and 2,000-draw physical-leaf bootstrap95% interval; also bootstrap last-minus-first/length/penultimate and identity/two-back incremental gains. Seeds are 390039 for GC, 390139 for ZL; bootstrap seed is permutation seed+1000, with no validation tuning. A separately generated eight-symbol sequence with next-start copied from previous-last at probability0.8 (train seed390239, validation390339) must give last real-minus-half-shuffle and last-minus-first each≥0.1 bits/pair. Toy permutation seed390439.

`cross_transcription_signal` requires the toy control, at least 1,000 eligible GC validation pairs across at least eight physical leaves, and in **both** GC and matched ZL: last real-minus-null≥+0.02 bits/pair, leaf-bootstrap lower>0, and real last gain above the permutation95th. The separate `terminal_specific` label adds last-minus-first, last-minus-length and last-minus-penultimate≥+0.02, each leaf-bootstrap lower>0, in both. Otherwise report failed gates; invalid toy means no conclusion. An independently written auditor must replay source parsing, model probabilities, 200 shuffles per view, bootstrap draws, toy control and gates. CPU cap 180 seconds, no paid API or training. Freeze registration, code, tests, auditor and notebook by commit/push/remote verification before the first v101 score. A positive result would establish cross-transcriber persistence of this *known* boundary pattern on the same physical manuscript, not a new causal process or decipherment.
