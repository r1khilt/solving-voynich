# TEACH-0002: first-hop curriculum versus the unchanged mixture

**Preregistration, 2026-09-23 UTC. No model training or outcome has occurred in this study.** This is an adaptive successor to [TEACH-0001](TEACH-0001-results.md), which was **not qualified**: jointly held-out composed accuracy 127/256, held-out direct accuracy 134/256, literal copy 256/256, factorial 0/128 exact quartets. Its training loss plateaued near the loss of a two-visible-candidate guesser. The question here is whether supervised first-hop queries and an easy-to-hard schedule improve *held-out composition*, compared with the same model and number of updates on the original mixture. This remains synthetic method qualification, not a manuscript reading or a causal-circuit claim.

## Research basis and specific inference

[Wang et al., *Learning Compositional Functions with Transformers from Easy-to-Hard Data*](https://arxiv.org/abs/2505.23683) show in a different permutation-composition setting that staged easy-to-hard or mixed-depth supervision can make gradient learning possible; their theorem does **not** predict success for this token grammar or four-block model. [Lake and Baroni's SCAN experiment](https://arxiv.org/abs/1711.00350) motivates holding out recombinations and testing systematicity instead of judging familiar primitive symbols alone. [Wang et al., *Grokked Transformers are Implicit Reasoners*](https://arxiv.org/abs/2405.15071) distinguish within-distribution composition from unseen-fact transfer and leave open whether more training would suffice here. [Ontañón et al.](https://arxiv.org/abs/2108.04378) show compositional generalization depends on architecture choices, which makes a matched same-architecture control necessary. Prior Voynich structure ([Reddy and Knight](https://aclanthology.org/W11-1511/)) and nonsemantic text-generation alternatives ([Rugg and Taylor](https://doi.org/10.1080/01611194.2016.1206753)) explain why this synthetic result cannot identify glyph meanings or historical production. These sources motivate the design; none reports TEACH-0002 outcomes.

The treatment is **supervision/curriculum**, not extra optimizer steps, a larger model, or a hidden hard-coded interpreter. A new `FIRST_HOP` query asks `F(name)` and requires a key token. A `DIRECT` query asks `G(key)` and requires an object. `COMPOSE` asks `G(F(name))`. `COPY` returns an object shown in the question. The model never receives the intermediate key as part of a composed input; the first-hop examples teach a reusable subskill on separate episodes. At output time the query marker determines whether the twelve legal key or twelve legal object logits are scored. This constrained symbolic interface is shared across all arms, unlike TEACH-0001's object-only output. It simplifies the experimental teacher and is not a claim about natural language or the Voynich script.

## Frozen generator and split

Use **twelve fresh name, twelve key and twelve object symbols** (vocabulary 45 including nine markers), two rows per table and a fourteen-token input. Randomize names, keys, distinct objects, row assignments, table ordering and queried row continuously. Families are unordered `(name set, key set)` for F and `(key set, object set)` for G. Hash each family with SHA-256 under the frozen `TEACH-0002-v1/` domain; buckets 0–7 of ten are training and 8–9 are held out. The new symbol inventory, hash namespace and evaluation seed are distinct from TEACH-0001, whose outcome informed this design. Training uses only F-train/G-train. Individual atomic pairs can recur, so the claim is transfer to unseen **table families and combinations**, not unseen symbols. The symbolic oracle independently parses every evaluation label from token IDs.

One shared evaluation suite, seed `62311`, has 256 examples per cell: four crossed composed cells (F/G train or holdout), first-hop F-train and F-holdout with G-train nuisance, direct G-train and G-holdout with F-train nuisance, held-out copy, and 128 paired first-hop and direct **query reversals** (256 examples each). A query-reversal pair has identical tables and asks each of the two rows; both answers must be correct, preventing a fixed-candidate answer from passing. The factorial cell has 128 four-way quartets (512 examples), with F assignment swapped and G object mapping independently changed; all four answers are distinct. Fresh held-out F and G families are required in this cell. Exact family signatures, tokens, expected answers and per-item predictions will be retained in compressed compact artifacts for independent rescoring and shortcut diagnosis.

## Frozen arms, seeds and resources

All arms use the native four-block, width-128, four-head, feedforward-256 causal transformer, zero dropout, AdamW `lr=3e-4`, weight decay `.01`, gradient clipping `1.0`, batch 128, and **5,000 updates per arm**. Train only the final answer-token loss. There are two independently initialized/trained replicates (`init_seeds=(62111,62121)`, `train_seeds=(62211,62221)`). Within each replicate, all arms start from the same initialization seed. The curriculum and null arms use the same generated input episodes at every step. No evaluation-based checkpoint selection or rerun is allowed.

| Arm | Steps 0–1499 | Steps 1500–2999 | Steps 3000–4999 |
| --- | --- | --- | --- |
| Same-compute baseline | 70% compose, 20% direct, 10% copy throughout | same | same |
| Curriculum | 45% first hop, 45% direct, 10% copy | 30% first hop, 30% direct, 30% compose, 10% copy | 10% first hop, 20% direct, 60% compose, 10% copy |
| Independent-label null | Same **inputs** as curriculum | same inputs | same inputs |

For the null only, each composed target is replaced by an independently sampled uniform object token; first-hop, direct and copy labels remain true. This checks whether a model trained on the easy skills and the same table format can appear to compose without supervised composition. The baseline receives **more** composed examples than the curriculum overall, so a curriculum advantage cannot be explained by extra exposure to composed labels. Both have the same number of forward/backward updates; the null has the same compute too. Each arm sees 640,000 streamed examples; six arms total 3,840,000 example presentations. Repeated episodes are possible and will be acknowledged; neither this nor family holdout proves a unique learned algorithm.

Total cap: **1,800 seconds** across six arms, numerical gate and all evaluation; MPS fraction `.16` and stop above **8 GiB sampled per-process MPS allocation**. The comparable TEACH-0001 run took 109.21 seconds for two 2,500-step arms on this machine. Scaling only by update count suggests about **655 seconds** for six 5,000-step arms before larger vocabulary, per-item archiving and evaluation overhead; a practical planning range is **10–25 minutes**, not a measured TEACH-0002 runtime. If the time/memory cap is reached, stop and report **incomplete**; no partial score qualifies. A CPU numerical dry check is permitted before source freeze while another study uses Metal. Scientific training is planned only after this registration and code are committed and reviewed. No paid API, model download, cloud training, Voynich training or manuscript final-test scoring.

Run command after freeze: `PYTHONPATH=src .venv/bin/python -m voynich.workspace.teacher2_train --device mps`. The code refuses a dirty worktree for this experiment's registration, generator, trainer or base model. It records source/config/evaluation hashes, checkpoint hashes, hardware/software metadata, sampled peak MPS allocation, progress every 250 updates, aggregate scores and gzipped **individual** predictions with exact family IDs. Bulk model weights stay under ignored `outputs/TEACH-0002/`; compact reports under `results/TEACH-0002/`.

## Numerical gate, scores and decision

Before training, the exact device must show finite loss/gradients for early, middle and late curriculum batches, plus hooked-versus-native final logits within `.002`. Every evaluation label must match the independent symbolic parser. Any failure is **incomplete**, not a negative behavioral result.

For each replicate, report exact per-item accuracy and counts in every cell, pair-exact scores for both query reversals, factorial 4/4 quartet accuracy, candidate membership, and per-item predictions. Report Wilson 95% intervals for single episodes and for *pair/quartet units* separately; shared families make them descriptive. The four-way factorial also reports F-swap and G-remap pair-exact counts. Analyze both seeds separately before any aggregate. The registered verdict is **QUALIFIED for later mechanistic work** only if, **in each of the two seeds**, all of these hold:

1. Curriculum F-holdout first-hop accuracy ≥.90 and held-out first-hop query-pair exact accuracy ≥.80.
2. Curriculum G-train and G-holdout direct accuracy each ≥.90 and held-out direct query-pair exact accuracy ≥.80.
3. Curriculum F/G jointly held-out composition accuracy ≥.85; each crossed single-holdout composed cell ≥.85; held-out factorial exact-quartet accuracy ≥.65; held-out copy ≥.95.
4. Curriculum minus same-compute baseline ≥.20 in jointly held-out composed accuracy **and** ≥.20 in exact factorial quartet accuracy.
5. Curriculum minus null ≥.40 in jointly held-out composed accuracy, and null factorial exact-quartet accuracy ≤.10.

These are demanding **method-qualification thresholds**, not estimates of historical truth. If any gate fails, report **NOT QUALIFIED** (or **INCOMPLETE** if a numerical/resource gate prevents all frozen arms), preserve every negative cell and avoid causal claims about composition. A strong first-hop result with weak composition would suggest a bridge failure, not a solved mechanism. A strong composition result without a curriculum-over-baseline gain would show task competence but would not support the proposed curriculum treatment under this registration. Even a fully qualified teacher would still need a **new**, fresh-family causal intervention study before claiming an internal key route, followed by wholly separate manuscript-generator discrimination under the [research protocol](../research/PROTOCOL.md).
