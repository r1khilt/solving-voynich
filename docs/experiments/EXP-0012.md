# EXP-0012 — Null-aware escalation after easy-filler FAIL

Registered **2026-09-21** before EXP-0012 Finnish holdout scores. New experiment id (does **not** alter EXP-0011/0011a thresholds). Confirmatory on the rule below. Not a Voynich decipherment.

Linked: EXP-0011 FAIL; EXP-0011a FAIL (easy fillers still fail frozen rule); HYP-001; M-001.

## Question

On the same Finnish world-C holdout with **easy** fillers only (`random_char`, `periodic`, rate 0.30), can a **null-aware** model recover null positions under a pass rule that **cannot** be won by delete-nothing / signal-majority F1?

## Motivation (sourced from EXP-0011 / 0011a)

- EXP-0011 neural predicted ~3% nulls vs ~29% truth while signal `mask_f1` looked high.
- EXP-0011a raised null recall (~0.33) and pred null rate (~0.17) on easy fillers but still failed recon / bits under the old rule.
- Classical top-k rate calibration after Viterbi discards run structure.

## Setup (unchanged vs 0011a except models/metrics)

- Languages: English + Latin train; Finnish holdout (unseen alphabet/cipher stream).
- Seeds: data `4011`, model `42`, finnish `4012`.
- Filler families: `random_char`, `periodic` only; rate 0.30.
- Worlds A–D retained (C oversampled as in EXP-0011 fix).
- Baselines: majority, matched-rate random deletion (20 seeds), vocab filter, plus the new classical.

## Models (escalation)

1. **Neural deletion model:** same BiLSTM + copy side features, but mask loss is **class-balanced / recall-seeking** (null positions up-weighted; cannot minimize loss by predicting almost-all-signal). Checkpoint on validation **null-class F1** (not signal F1). Decode with a threshold calibrated on world-C validation to target ~0.30 predicted null rate (frozen procedure; not tuned on Finnish).
2. **Classical run-aware Viterbi / light HSMM:** keep the decoded path (no top-k overwrite); explicit null-run duration preference; periodic + rarity emissions; token-level copy score as anti-null on duplicated surface tokens.

Target ≪ 100k neural params; local MPS/CPU; ≤3,000 updates; no paid API.

## Preregistered metrics (Finnish world-C)

Primary (null class = mask 0):

- `null_recall`, `null_precision`, `null_f1`
- `pred_null_rate`, `true_null_rate`
- `recon_acc` vs matched random deletion
- `mask_acc` vs majority (secondary; not sufficient alone)
- `pred_bits_gain` vs matched random (secondary)

Signal `mask_f1` is **reported** but **not** a sole pass criterion.

## Pass rule (frozen before scores)

**PASS** if **either** neural or classical satisfies **all** of:

1. `null_recall ≥ 0.55`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45` (blocks delete-nothing and delete-everything)
4. `recon_acc ≥ mean_matched_random_recon_acc + 0.08`
5. `mask_acc ≥ majority_acc + 0.05`
6. `vocab_filter` signal-`mask_f1` ≤ 0.55 (else FAIL cheat-surface)
7. `pred_bits_gain ≥ mean_matched_random_pred_bits_gain + 0.03`

**FAIL** otherwise. No silent threshold moves. One experiment = one scored run (no post-fail retune in this id).

## Voynich gate

Only if PASS: label-free structure test on ZL3b **validation** only (not test), same spirit as EXP-0011. Positive structure ≠ decipherment. Synthetic PASS ≠ manuscript plaintext.
