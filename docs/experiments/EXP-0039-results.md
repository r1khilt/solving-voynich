# EXP-0039 result — the known edge-order effect survives independent v101 transliteration

**Adaptive exploratory result: `cross_transcription_signal=true`, `terminal_specific=true`; independent raw-input replay passed.** The previous token's terminal glyph predicts the next token's initial glyph in Glen Claston's **independently authored v101 transliteration** under the registered train-to-exposed-validation assay. The matched ZL3b comparison passes the same assay. This tests whether the known [Currier/Reddy–Knight](https://aclanthology.org/W11-1511.pdf), [Smith–Ponzi](https://agnosticvoynich.wordpress.com/wp-content/uploads/2019/06/glyph-combinations-across-word-breaks-in-the-voynich-manuscript-preprint.pdf) and [Rozanova–Temerev](https://arxiv.org/html/2608.17096v1) boundary phenomenon depends on one transcriber's glyph choices. It does not discover the phenomenon, identify its mechanism, or decipher a word.

The richer context diagnostics are **not** a claim that more context lacks information. A full previous-token identity table backing off to the last-glyph predictor adds −0.01333 bits/pair on GC, bootstrap95% [−0.04112,−0.00073], and +0.00235 on ZL [−0.01534,+0.01525]. The `(previous last, previous-previous last)` table adds −0.08702 on GC [−0.14456,−0.06558] and −0.05002 on ZL [−0.06165,−0.03447]. Those finite-data count tables overfit or fail to generalize with the fixed smoothing used here; they are **weak competitors to a trained language or structured-generator model**. Full-token identity mathematically contains its last glyph, so lower held-out performance of this sparse estimator is no evidence that terminal glyphs are causally primary or that syntax is absent.
