# PATH-0006: fresh direct-binding attention mediation

Registered before any PATH-0006 model outcome. Exploratory original-model causal study, with a disjoint discovery/confirmation panel and a frozen selection rule. The goal is to test whether the strong PATH-0002 post-block-23 value-field effect depends on a localized range of *later final-query attention writes* on fresh explicit English lookups. This is not a Voynich semantic test.

## Prior and rationale

PATH-0002 passed its registered diagnostics: post-block-23 value-field donor edits gave 45/46 eligible donor answers versus 0/46 matched random; the final-query-only edit gave 0/46, and the late control point changed at block32. PATH-0003's composed-query attention test failed its competence gate and had only 3/14 upstream successes. PATH-0004's composed-query position crossover is discovery-only because the confirmation competence gate failed. This experiment returns to a qualified task to test a narrower mediator. Causal attention in a decoder-only transformer is the only route by which an edit confined to earlier positions after block23 can first affect an unchanged final query position: MLPs act positionwise. Therefore, cutting **all** later final attention writes is an architectural identity check, *not* a novel circuit result. Concentration in a selected short window, beyond matched random cuts on fresh bundles, would be a useful mechanistic clue, not a uniquely identified head or semantic variable.

Method basis: the [QK/OV transformer-circuit account](https://transformer-circuits.pub/2021/framework/index.html), [original-model circuit-tracing intervention validation](https://transformer-circuits.pub/2025/attribution-graphs/methods.html), and PATH-0002/0003/0004. Prior Voynich [co-occurrence analysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC3689824/) and [token-similarity generation](https://doi.org/10.1080/01611194.2019.1596999) do not establish a reading; this known-answer synthetic control is much easier than historical decipherment. The model is an existing local Qwen3-8B-4bit snapshot, not newly trained on this task.

## Frozen panel and gates

`path6_tasks.py` contains 16 new lexical bundles, 8 discovery and 8 confirmation; each has two value orientations, two queried names, and an unrelated literal-copy task in each orientation: 32 binding and 16 copy records per split. The two prompt templates are fixed by bundle. Source/donor swap only the two value fields, with unchanged question; rendered token lengths must match, changed positions must precede the query suffix, and source/donor first-answer tokens must differ for binding eligibility. No bundle shares a name or answer word with another PATH-0006 bundle; split membership is frozen. Each split must have at least 24/32 both-clean-correct binding comparisons and 14/16 source-correct copy records or the run stops **inconclusive**. Bundle, not orientation or question, is the resampling unit.

## Intervention and decisions

At zero-based post-block23, transplant only changed value-position residuals from the matched donor to source. Run the full model forward. Then replace only the final-query attention write with the clean source write at one of three prespecified 4-block windows: 24–27, 28–31, or 32–35. Discovery measures all three and selects the window with the most donor-first-token removals among eligible cases where the upstream value edit yielded the *full* donor answer; ties go to the earliest window. Confirmation scores only the selected window, the uncut upstream edit, an all-12-block clean-write cut, and equal-norm Gaussian write edits in the selected window. The random edits are deterministic from seed 51081 and matched to the actual clean-minus-edited write norm independently by layer/task. Whole-donor residual transport, untouched clean generation, identity field, and all-cut full-logit restoration are numerical controls. The cut recomputes every downstream block, not a static logit correction.

The selected-window mechanism is **exploratory supported** only if both splits pass competence, the confirmation upstream value edit gives full donor answers on at least 75% of eligible bindings, whole-donor and all-cut logit controls each have max absolute error <0.002 with correct argmax on every record, selected window removes the donor first token on at least 35% of upstream successes and at least 25 percentage points more than matched random, and copy is preserved on at least 90% of baseline-correct copy records under the upstream and selected conditions. Failure of an upstream or numerical gate means uninformative; a qualified negative is reported as such. Report full-answer effects and first-token margins separately. A selected short window does not identify a unique head, channel, or literal information-storage location.

Seed 51081. Maximum 50 minutes elapsed and 45 GB MLX allocation, no paid API or manuscript final-test score. Source hashes, rendered-input hashes, baseline-array hashes, full compact rows, decision and bundle-resampled descriptive interval saved under `results/PATH-0006/`; raw arrays and prompt IDs under ignored `outputs/PATH-0006/`. No automatic rerun or post-hoc threshold changes. Independent audit and full repository checks follow the run.
