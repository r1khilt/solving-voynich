# HERBAL-CONTROL-0002: fresh-chapter three-manuscript visual matching

**Question, registered before images are cropped or scored.** Can a fixed three-way, one-to-one matching rule repair the five cross-manuscript errors of the generic pairwise feature baseline without using plant labels to form the matches? The development panel in HERBAL-CONTROL-0001 is exposed and cannot count as a fresh test. This assay reserves six different Tractatus de Herbis chapter categories, each available in BnF Latin 6823, BL Egerton 747 and Casanatense 459: **arthemisia, arthemisia tagantes, torbentilla, ieribulbo, aristologia, terbentina**. They are historical chapter identities, not modern botanical ground truth. Three-way matching is meant to calibrate a visual reference library, not decode Voynich text.

## Prior work and scope

[Kaoua et al., *Image Collation* (ICDAR 2021)](https://arxiv.org/pdf/2108.08109) annotate correspondences across six historical manuscripts. Their paper reports that deep local feature similarity is substantially better than raw global features on hard plant illustrations, that bidirectional normalization helps, and that 2/3-cycle-consistent correspondences are especially precise. They use specialist review and local-order propagation; their reported gains are not a license to assume the same performance with Apple Vision's opaque global feature prints or with this tiny hand-cropped panel. This experiment borrows only the **cycle-consistency / bijection constraint**; it does not reproduce their network, local matching, supervision, or order-based propagation. [Zandbergen](https://www.voynich.nu/illustr.html) cautions that Voynich plant resemblances are uncertain. HERBAL-CONTROL-0001's 13/18 and failed gate are development information, not a result to retune away.

The six categories are fixed from Wikimedia Commons' chapter pages: [arthemisia](https://commons.wikimedia.org/wiki/Category:De_arthemisia_in_Tractatus_de_herbis), [arthemisia tagantes](https://commons.wikimedia.org/wiki/Category:De_arthemisia_tagantes_in_Tractatus_de_herbis), [torbentilla](https://commons.wikimedia.org/wiki/Category:De_torbentilla_in_Tractatus_de_herbis), [ieribulbo](https://commons.wikimedia.org/wiki/Category:De_ieribulbo_in_Tractatus_de_herbis), [aristologia](https://commons.wikimedia.org/wiki/Category:De_aristologia_in_Tractatus_de_herbis), and [terbentina](https://commons.wikimedia.org/wiki/Category:De_terbentina_in_Tractatus_de_herbis). Each category lists the three named manuscripts. Exact page-file titles and image/crop hashes will be frozen in a manifest before feature extraction. Public JPEGs and crop PNGs remain Git-ignored. Some folios depict more than one plant; crops must isolate the category drawing without using Voynich text or any feature score. Record any ambiguous drawing location before scoring, do not silently switch chapter or manuscript after outcome.

## Frozen algorithm and controls

Use the same Apple Vision `VNGenerateImageFeaturePrintRequest` revision 2, scaleFit, 512-square white-padded crops as HERBAL-CONTROL-0001. No model training, hyperparameter search, Voynich query, or word processing. First compute the **raw pairwise** directed nearest-neighbor accuracy across the six ordered pairs of distinct manuscripts, six queries per direction: 36 decisions. As in HERBAL-CONTROL-0001, a first/second distance difference of at most `1e-7` counts as a tie and is wrong.

Next, use the 18×18 symmetric distance matrix to form six unlabeled triplets, one image from each manuscript, with one-to-one use of every image. Fix BnF as an arbitrary index anchor and enumerate all `(6!)² = 518,400` pairs of Egerton/Casanatense permutations. Minimize the total of the three distances within each triplet, each divided by the median of all 36 inter-image distances for its manuscript pair (`BnF–Egerton`, `BnF–Casanatense`, `Egerton–Casanatense`). Medians depend on pixels only, not chapter names. Resolve exact objective ties by lexicographic permutation order. This global assignment enforces pairwise bijections and three-cycle consistency; there is no manually chosen seed or page-order feature.

Report **complete triplets** (all three images share the chapter label, out of six), the induced **36 directed** pair matches, raw pairwise 36-match baseline, per-class and per-manuscript-pair errors, and the cost gap between best and second-best global assignments. For an exact conditional null, keep the frozen unlabeled assignment and independently permute the six chapter labels within Egerton and Casanatense while BnF labels remain fixed; enumerate the same 518,400 possibilities and compute a one-sided p for the complete-triplet count. This tests only whether this chosen panel's recovered assignment aligns with the curated chapter metadata.

A *fresh-panel visual feasibility pass* requires **at least 4/6 complete triplets**, **at least 28/36 induced directed pair matches**, **at least +2/36 improvement over raw pairwise matches**, and **exact p ≤ 0.05**. All conditions must hold. If any fail, do not use this method to name Voynich f35v. A pass would still require out-of-set rejection controls and independent historian review before using the external herbals as semantic anchors; it would not validate a historical reading or make f35v text available for adaptive tuning. The six chapters are hand-selected based on documented availability, crops are manually chosen, and category labels may disagree with depicted content, so population-level retrieval accuracy is not claimed.

Resource cap: at most 18 historical JPEGs, below 20 MiB source data target, CPU/local Vision under ten minutes, no paid API. Source-freeze crops, code and manifest before feature scores; log exact commands, source versions, hashes, failures and complete results. Preserve the final manuscript text holdout.
