# EXP-0015 — Multi-language latent recovery (exact-count decode)

Registered **2026-09-21** **before** multi-language holdout scores. New experiment id. Does **not** alter EXP-0011–0014 thresholds. **Not** a Voynich decipherment.

Linked: EXP-0011–0013 FAIL (Finnish-only bar superseded); HYP-001; M-001.

## Supersedes Finnish-only bar

- EXP-0011–0013 used English+Latin train and Finnish holdout. That is too narrow for a manuscript with unknown language family.
- EXP-0014 (Finnish exact-count confirmation on frozen EXP-0013 weights) was **preregistered but not scored**. It is abandoned as the session bar; any future Finnish-only number is a **side result**, not the pass gate.
- The peeked EXP-0013 exploratory Finnish exact-count ≈0.218 is **not** a blind multi-language result and is not used as a threshold here.

## Question

Under `L → C(L) → N(C(L))` with a fresh alphabet/cipher every sample and easy structured fillers, does a CTC-deletion BiLSTM with a **preregistered exact-count** decoder recover `C(L)` above matched-random deletion across **many held-out language families** (romanized Latin-letter inventory)?

## Romanization (documented; not silent CJK-as-alphabet)

All training and holdout plaintext is mapped into the Latin inventory `a–z` plus space before ciphering. Rules:

| Source script | Rule |
| --- | --- |
| Latin-script languages | Unicode NFKD; strip combining marks; keep `a–z` and space; other → space |
| Cyrillic (Russian) | Scientific / ISO-9-like letter map → Latin; then NFKD fold |
| Greek | Standard classicizing map (α→a, β→b, …, χ→ch as `c`+`h` collapsed to single-letter approx: χ→x, ψ→y, ω→w); then fold |
| Hebrew | ISO 259-ish consonant map to Latin letters; vowels if present folded |
| Arabic | Buckwalter-inspired consonant/vowel map to Latin ASCII; then fold |
| Devanagari (Hindi) | IAST-inspired map without diacritics (ā→a, ś→s, …) |
| Mandarin | **Requires pre-romanized pinyin text** or an available pinyin converter; native Han characters are **not** treated as alphabetic cipher units. If neither is obtainable quickly, Mandarin is skipped and recorded. |
| Japanese / Korean | Same: require romaji / Revised Romanization text, or skip. Do not treat kana/hangul/han as Latin letters. |

Transliteration tables and digests live in the data manifest. Invented text is forbidden.

## Method

- Pipeline / worlds A–D / cipher / fillers: same as EXP-0013 primary (`random_char` + `periodic` only, rate **0.30**).
- Objective: copy-constrained CTC deletion + light null BCE + rate penalty (reuse EXP-0013 learner design).
- **Decoder (frozen before scores):** exact-count keep — for length \(L\), \(n_{\mathrm{keep}}=\mathrm{round}((1-0.30)L)\); keep the \(n_{\mathrm{keep}}\) positions with highest \(P(\mathrm{signal})\); ties prefer lower index. No val-threshold retune after seeing holdout numbers.
- Architecture: BiLSTM + copy features, **larger than 70k** if the machine finishes in ~1–2 hours. Target ~2–3M params (`emb=128`, `hidden=256`, `layers=2`) on MPS; fall back to smaller if needed. Record estimate and actual count.
- Seeds: data `4011`, model `42`, holdout `4012` (+ per-language stream offsets recorded in manifest).
- Baselines **per language:** majority/delete-nothing; matched-random deletion (20 seeds); vocab filter from training world-B/C surfaces.
- No paid API. ZL3b **final test untouched**.

## Primary metric

`recon_acc` as in EXP-0013: prefix character-match fraction × min/max length ratio. Secondary: `recon_edit_sim`, null recall, null precision, predicted null rate.

## Pass rule (frozen before multi-language scores)

Apply **per held-out language**. A language **passes** iff all of:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc >` that language’s matched-random `recon_acc` (strict)
5. Vocab-filter is **not** the thing that “passes”: report vocab-filter signal-`mask_f1`; if vocab-filter `recon_acc` ≥ model `recon_acc`, treat that language as **FAIL** (cheat surface)

**Run PASS** only if:

- At least **4** held-out languages pass individually, **including at least one non-Indo-European family**, **AND**
- Macro-average `recon_acc` (mean over scored holdout languages) **>** macro-average matched-random `recon_acc`

A single easy language is not a pass. Historical transfer is reported only.

## Contingent falsifier

**EXP-0015b**: same model + exact-count decoder; fillers `random_char,periodic,copy_mutate` on the held-out set. Preregistered in `EXP-0015b.md`. Run only if primary PASS. Same pass rule.

## Voynich gate

Only if primary multi-language PASS **and** EXP-0015b does not collapse the rule: label-free structure test on ZL3b **validation** only. Exact-count at 30% null rate is an **assumption** (manuscript null rate unknown). Compare to matched random. Never score the final test. Synthetic PASS ≠ decipherment.
