# TEACH-0008 native-residual numerical amendment

**Written after two invalid executions and before any valid TEACH-0008 result.** The first repair replaced the explicit attention kernel with PyTorch's scaled-dot-product implementation, but the second execution reproduced the same seed-0 donor-layer error of `1.0728836e-6`. The independent auditor again rejected the report. That second invalid report and rows are preserved under `results/TEACH-0008/invalid-sdpa-*`; no valid TEACH-0008 verdict or audit exists yet.

Direct diagnostics showed that the remaining attention reconstruction error is below the frozen threshold in all four base/donor checks (`5.96e-7` to `8.34e-7`). Adding that numerically equivalent write to the residual stream and running the MLP can amplify floating-point operation-order noise by one representable step, pushing one whole-layer comparison just above `1e-6`. Reconstructing the layer with PyTorch's native attention write followed by the explicit residual and native feed-forward block matches the native layer output exactly in both seeds and both input panels. Enabling or disabling PyTorch's attention fast path does not change any prediction.

The repaired pipeline therefore keeps two distinct objects: (1) the explicitly reconstructed per-head values and their output-projected sum, whose error against native attention remains subject to the original `<1e-6` gate; and (2) the native attention write as the base residual-stream value. Head interventions add output-projected differences from the explicit per-head values to that native base write. The explicit residual-plus-feed-forward reconstruction is still compared with the native layer under the unchanged `<1e-6` gate.

No seed, split, checkpoint, selected-head rule, intervention, control, scientific threshold or behavioral output has been changed. Both earlier executions exposed aggregate behavior, so any valid third execution is explicitly non-blind and supports only a numerically repaired replication of the already-exposed mechanism.
