# EXP-0035 result — posterior training targets do not improve source-free copy recovery

**Registered decision: NOT_SUPPORTED.** On a newly sourced Portuguese book, replacing one sampled training mask with the exact generator-weighted posterior over masks did **not** improve the same 10.746M-parameter source-free Transformer. Across two matched seeds, copy-null F1 changed by **−0.00248** versus the frozen hard-label baseline, paired row-bootstrap 95% interval **[−0.00690,+0.00210]**. Mean copy reconstruction fell from **0.21471** to **0.20895**. This misses the registered +0.03 F1, lower-bound>+0.01 and +0.03 reconstruction gates. The periodic competence, iid impossibility and glyph-renaming invariance controls all pass, so this is a valid negative result for this objective/training regime, not an invalid comparison. No Voynich manuscript text or image was scored.

## Implication and next experiment

EXP-0033/0034 established that mask ambiguity exists and a source-given generator posterior can localize synthetic copy nulls very accurately. EXP-0035 now rules out the **simple finite-run fix** of swapping sampled masks for these soft posterior targets under the same 10.746M model, data and fixed decoder. The hard sampled labels are already an unbiased training signal in expectation; soft targets only changed a minority of training positions (mean absolute change0.034 for weighted copy rows). Better soft supervision alone did not bridge the source-free gap on a fresh language. This does **not** show that source inference is impossible, or that a larger model, a different objective, explicit source/channel factorization or more training cannot work.

The next mechanistic step should give the model an explicit **latent source hypothesis** and score it jointly with insertion emissions, rather than only classifying each visible glyph. It needs its own fresh prospective source and controls that separate learned language/source structure from copy-channel heuristics and simple repetition. Any later Voynich test must compare against no-null and structured nonsemantic generators on untouched physical folios. No source language, null layer, glyph reading or decipherment of the manuscript follows from this synthetic failure.
