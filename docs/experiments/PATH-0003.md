# PATH-0003: causal attention-window mediation on composed lookup

Registered 2026-09-22 before any PATH-0003 task outcomes. Adaptive successor to PATH-0002; its 12 bundles are exposed and never reused as a fresh test. The study tests a known two-step English rule, not a manuscript reading.

## Question and basis

PATH-0002 established that swapping the full residual at changed value fields after block 16 often swaps a directly copied answer, while the effective control point moves to the final query position by block 32. PATH-0001's single-block head positive control failed. We now ask whether a new **composed** lookup, `name -> key -> output`, depends on final-position attention writes in identifiable downstream block windows. The original [QK/OV framework](https://transformer-circuits.pub/2021/framework/index.html), [circuit-tracing methods](https://transformer-circuits.pub/2025/attribution-graphs/methods.html), and [causal abstraction/interchange](https://arxiv.org/abs/2106.02997) motivate original-model intervention and a known symbolic counterfactual. They do not predict a particular Qwen block. Prior Voynich token co-occurrence and generating-rule work is reviewed in `SIMILARITY_THEORY.md`; none supplies labels for this task.

## Panel, gates, and controls

Eight disjoint bundles, four discovery/four confirmation, each contain two invented names, two arbitrary keys, two arbitrary outputs, and a copy word. Two prompt templates; each bundle has both orientations of the first table, both queried slots, and an irrelevant copy query per orientation: 16 composed and 8 copy records per split. The second key-to-output table and the question are identical in a source/donor pair; only the two name-to-key fields swap. The registered task generator fixes every word and template. Fail before scoring if chat-tokenized source/donor lengths differ, changed positions are not confined to the first table, or answer tokens are the same. Baseline competence requires at least 8/16 both-clean-correct, first-token-distinct composed records and 6/8 correct source-copy records **per split**. Score only baseline-eligible composed records and baseline-correct copies; retain all rows. The bundle, not the reversed/queried variants, is the independent unit.

The upstream edit transplants donor-minus-source post-block-15 residual states at the changed first-table token positions. It must produce the full donor answer on at least 50% of eligible composed confirmation records and preserve at least 90% of baseline-correct copies; otherwise window claims are **uninformative**. Clean source and donor first-token logits, identity execution and a full-prefix donor transport are numerical controls. No task is silently removed for an unsuccessful upstream transplant.

Capture the clean source's native final-query attention write in zero-based blocks 16..35. During the value-field-patched run, replace that final-query attention write with the clean source write in each fixed window `16-19`, `20-23`, `24-27`, `28-31`, or `32-35`, as well as the full `16-35` cut. The full cut is a structural positive control: since the upstream edit is restricted to earlier fields and the final position's only cross-position input is attention, replacing **all** downstream attention writes should restore its clean first-token logits (tolerance .002, exact argmax) if the implementation is correct. It is expected by architecture, not a discovered circuit. A per-block independent Gaussian final-write edit matched to each actual clean-versus-patched write norm is a nuisance control for the discovery-selected window. Capture writes from the *actual patched run*, not the clean donor, and recompute downstream blocks after each cut.

On discovery records, select one of the five windows by maximal reduction of donor first-token answers among upstream-success cases, then by window order. Freeze it before opening confirmation outcomes. On confirmation, the selected window is a supported **local mediator** only if it removes the donor first token on at least 50% of upstream-success cases, beats matched random by at least 20 percentage points on that same denominator, and preserves at least 90% of baseline-correct copy outputs. The full `16-35` cut must restore source first-token logits on **every** record to pass numerical qualification. Report complete answers, first tokens, margin changes, every window, every bundle, and random norm errors. A supported window is a task-specific attention cut, not a unique head, semantic variable, or Voynich mechanism. No layer/head choice is revised from confirmation outcomes.

Use the existing cached Qwen3-8B-4bit snapshot with float32 block evaluation and `MLX_ENABLE_TF32=0`. One model resident, ≤45GB MLX allocation, ≤50 minutes model computation, seed 51061, greedy 12-token outputs, no paid API, no new model download, no manuscript final split. Preserve full prompt/token/capture arrays in ignored `outputs/PATH-0003`, compact rows/hash manifests in `results/PATH-0003`. Independently audit labels, grid, gates, selection, source hashes, and numerical controls. A resource or numerical stop remains an incomplete record; do not silently loosen criteria.
