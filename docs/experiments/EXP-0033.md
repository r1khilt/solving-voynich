# EXP-0033 — source-conditioned alignment ambiguity of corrected null insertion

**Exploratory diagnostic, registered after EXP-0032's Polish evaluation was exposed and before any EXP-0033 alignment counts.** It is not a new model, a Bayes-optimal decoder, or a Voynich manuscript test.

## Question and method basis

The two large EXP-0032 encoders localize synthetic copy nulls above random yet recover zero entire copy masks. Is the mask itself combinatorially ambiguous even **when the true pre-null cipher stream is supplied**? The corrected generator's source-oracle audit guarantees each saved `ciphered` target is the true kept subsequence, so we can enumerate every positional embedding of that string in the 128-character observed text. This is the deletion/subsequence alignment problem. [Graves et al. (2006)](https://www.cs.toronto.edu/~graves/icml_2006.pdf) marginalize many sequence-label alignments for CTC, but their collapse map deletes blanks **and repeated labels**; here every kept repeated glyph remains, so this study uses a distinct, exact subsequence dynamic program. Prior Voynich/synthetic null applications and the channel-alignment erratum are in `docs/research/deep-review-2026-09-21/DECIPHERMENT.md`, EXP-0030–0032 and `docs/research/PROTOCOL.md`. Their success/failure does not reveal historical nulls.

Run one exact-integer forward/backward subsequence DP per row to count masks `m` such that deleting zero-mask positions from observed `X` gives the known target `Y`. Verify the saved gold mask is one such path and that the sum of per-position keep counts equals `|Y| × total_alignments`. Save integer counts as decimal strings, not floating approximations.

Primary descriptive measures by filler family: fraction of rows with **exactly one** valid alignment, log2 number of alignments, fraction of all and **nonspace** positions forced to the same keep/delete status in every alignment, and fraction with at least one adjacent equal-glyph signal/null swap (a direct alternative-mask certificate). Also rank per-position keep marginals under a **uniform distribution over valid alignments**, choose exactly `|Y|` keep positions and report its null F1 against the generated gold; compare with a 20-seed `|Y|`-matched random mask. This uniform-alignment rule is a *descriptive sensitivity calculation*, not the posterior of the nonuniform copy-mutate generator and not a bound on any source-free model. It receives the true target, so its F1 is not directly comparable to EXP-0032's decoder. A trailing-space sensitivity repeats the exact count and nonspace forced fraction after stripping all terminal observed spaces and recomputing the target from the corresponding gold-mask prefix; this can also remove genuine terminal spaces and is explicitly not the primary task.
