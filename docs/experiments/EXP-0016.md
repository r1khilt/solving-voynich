# EXP-0016 — Thousand-language family-holdout latent recovery

Registered **2026-09-21** **before** multi-language holdout scores. New experiment id. Does **not** alter EXP-0011–0015 thresholds. **Not** a Voynich decipherment.

**Supersedes EXP-0015 as the session bar.** EXP-0015 (~12 train / 6 holdout) is interrupted by user order to scale language count ~100×. Any EXP-0015 scores are **side results only**, not the pass gate.

Linked: EXP-0011–0013 FAIL modes (localization / threshold decode); HYP-001; M-001.

## Question

Under `L → C(L) → N(C(L))` with a fresh alphabet/cipher every sample and easy structured fillers (`random_char` + `periodic`, rate **0.30**), does a CTC-deletion BiLSTM with a **preregistered exact-count** decoder recover `C(L)` above matched-random deletion across a **thousand-language** pool with **entire families held out**?

## Family holdouts (entire families unseen in training)

Hold out **whole families**, not a token language. Training must contain **zero** languages from a held-out family. Planned holdout families (exact ISO sets frozen in the data manifest **before** scores; ≥8 families):

1. **Uralic** — includes Finnish and Hungarian (family unseen)
2. **Basque + other isolates** — Basque and all Glottolog isolates in the pool
3. **Afro-Asiatic** — entire family (Hebrew + Arabic unseen together)
4. **Austronesian** — Pacific / SE Asia family slice in source
5. **Quechuan** — Americas
6. **Tupian** — Americas
7. **Dravidian** — South Asia
8. **Kartvelian** — Caucasus
9. **Mayan** — Americas (expanded to grow holdout count)
10. **Otomanguean** — Americas
11. **Aymaran** — Americas

**Held-out language count ≥150.** Score **every** held-out language. Stratify the report by family. A pass **cannot** be carried by Indo-European alone.

## Method

- Pipeline / worlds A–D / cipher / fillers: same as EXP-0013 primary (`random_char` + `periodic` only, rate **0.30**).
- Objective: copy-constrained CTC deletion + light null BCE + rate penalty (reuse EXP-0013/0015 learner).
- **Decoder (frozen before scores):** exact-count keep — for length \(L\), \(n_{\mathrm{keep}}=\mathrm{round}((1-0.30)L)\); keep the \(n_{\mathrm{keep}}\) positions with highest \(P(\mathrm{signal})\); ties prefer lower index.
- Architecture: BiLSTM + copy features, **scale with data** (target ~5–20M params on MPS if a few-hour bound holds; record estimate and actual count). Fallback smaller if needed.
- Seeds: data `4016`, model `42`, holdout `4017` (+ per-language stream offsets in manifest).
- Baselines **per language:** majority; matched-random deletion (20 seeds); vocab filter from training world-B/C surfaces.
- No paid API. ZL3b **final test untouched**.

## Primary metric

`recon_acc` as in EXP-0013: prefix character-match fraction × min/max length ratio. Secondary: `recon_edit_sim`, null recall/precision, predicted null rate. Report family macros and a path to full per-language JSON.

## Pass rule (frozen before scores)

1. At least **100** held-out languages each have `recon_acc` **strictly greater** than that language’s matched-random `recon_acc`.
2. Those ≥100 include languages from at least **5** families, and **≥50%** of the passing languages are **non-Indo-European**.
3. **Macro-average** `recon_acc` over **ALL** held-out languages (not only winners) **>** macro-average matched-random `recon_acc`.
4. On **macro** numbers over all held-out languages: `null_recall ≥ 0.50`, `null_precision ≥ 0.50`, `pred_null_rate ∈ [0.15, 0.45]`.
5. If vocab-filter **macro** `recon_acc` ≥ model macro `recon_acc`, **FAIL** (cheat surface).

**Run PASS** only if all five hold. One easy family is not a pass.

## Contingent falsifier

**EXP-0016b**: same model + exact-count; fillers `random_char,periodic,copy_mutate` on the held-out set. Preregistered in `EXP-0016b.md`. Run only if primary PASS.

## Voynich gate

Only if primary PASS **and** EXP-0016b does not collapse the rule: label-free structure test on ZL3b **validation** only. Exact-count at 30% null rate is an **assumption**. Never score the final test. Synthetic PASS ≠ decipherment.
