# TEACH-0009 attention-weight numerical amendment

**Written after an invalid first execution and before any valid TEACH-0009 result.** The first report's behavior was exposed, but explicit matrix-multiply/softmax/value reconstruction missed TEACH-0008's scaled-dot-product head output by `1.1920929e-6` in seed 0 and `1.4305115e-6` in seed 1, above the frozen `<1e-6` gate. The independent auditor rejected the report. Its report and rows are preserved under `results/TEACH-0009/invalid-softmax-*`; no valid decision exists.

PyTorch's math implementation of scaled-dot-product attention returns both the attended values and the exact softmax weights it used. A diagnostic on the same tensors showed that invoking this math backend on the full six-query tensor, then selecting query slot 5, matches TEACH-0008's scaled-dot-product head output within `9.5367432e-7` in both seeds. Multiplying its returned weights by V and summing the six source contributions matches its returned output within `2.3841858e-7`.

The corrected pipeline uses `torch._scaled_dot_product_attention_math` on the full query tensor for both native and hybrid Q/K/V cells, and uses the returned attention weights for source contributions. Hybrid donor Q still changes only query slot 5; the other query vectors remain base vectors and cannot influence slot 5 because attention rows are independent. This changes only floating-point operation order. No seed, split, checkpoint, fixed head, QKV cell, source subset rule, intervention, control or threshold changes. Any corrected execution is explicitly non-blind and must pass the unchanged independent auditor.
