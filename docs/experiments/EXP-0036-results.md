**Interpretation.** Adjacent word boundaries contain reproducible predictive structure beyond the particular line-level shuffle null. This is a stronger observation than a descriptive plug-in mutual information because the conditional probabilities were learned from separate physical leaves. It is compatible with grammar, phrase formulae, line-position conventions, a stateful cipher, and local copying; the assay distinguishes none of them. Crucially, the permutation moves each run's first and last word. Line-initial and line-final vocabulary could therefore explain part of the contrast without a neighbor-copy mechanism. The next registered control should keep those endpoints fixed while permuting interior words, and should test whether a section/line-position baseline absorbs the rest. Both studies remain exploratory on exposed validation data; a successful model and rule must eventually be frozen for genuinely untouched physical folios.
