# EXP-0040 — independent out-of-leaf challenge to a published stock/flow generator

Registered 2026-09-25 before any EXP-0040 generator-to-manuscript score. This is **adaptive exploratory model criticism**, not a decipherment attempt or a fresh manuscript confirmation: EXP-0039's ZL validation score and interval are already known, and its nine physical leaves have been used repeatedly. No final-test leaf is accessed.

## Why this comparison

[De Stefano's public *Generative Frontier* study](https://github.com/cadeos/voynich-frontier) (source revision `da5320c47910b9eee54d372e3a68be23bc9639fb`, report 08 dated 2026-07-24) proposes a character-stream `stock_flow` process with a local recent-word opening copied before a Markov tail is drawn. It reports matched reuse, character entropy, hapax share and edit profile, plus a four-signature check using Parisel's verifier. Its own report says stock size and Zipf exponent were fitted in an earlier two-stage variant; the final `stock_flow` still uses manuscript-trained character transitions and tuned default parameters. The published held-out A→B table measures reuse, lag-one similarity, entropy, TTR and hapax, **not the train-fitted last-glyph→next-first held-out predictive contrast of EXP-0039**. The Parisel cross-boundary MI gate is a floor and is passed even by a deliberately bad grille, as the authors themselves report. Thus passing it is not equivalent to reproducing EXP-0039's specific effect.

[Rozanova and Temerev (2026)](https://arxiv.org/html/2608.17096v1) find that previously published Naibbe and self-citation controls miss the manuscript's edge-glyph association and hapax-rich vocabulary under their own estimator. Their result does not assess this later stock/flow process or our held-out score. [Timm and Schinner (2020)](https://doi.org/10.1080/01611194.2019.1596999) motivate local copying; [Gelman, Meng and Stern (1996)](https://www3.stat.sinica.edu.tw/statistica/j6n4/j6n41/j6n41.htm) motivate checking a fitted generator on held-out discrepancies rather than treating the ability to sample plausible text as mechanism identification. EXP-0028 in this repository found no held-out gain from a particular one-edit local cache over a stronger static model; that neither refutes this different generator nor endorses it. The statistical scorer remains EXP-0039's train-only smoothed model, whose assumptions and source review are in that registration.

**Question:** when these external generators are fitted solely to the EXP-0039 matched ZL **train** paragraph text, do independently sampled, validation-shaped streams reproduce the already observed held-out edge score? Is any apparent match accompanied by plausible novelty/hapax rather than only recycling train words?

## Frozen families and score

Five conditions, **16 deterministic seeds each**: external `stock_flow` defaults (order 3, copy probability .6, keep fraction .55, recency 1.07, window 25); external `stroke` defaults (order 4, copy probability .15); external `timm_faithful` defaults (probability .3, window 16, edit probability .9); external `cardan_grille` defaults; and an iid word draw from the train profile's empirical token frequencies. The Timm implementation omits its first internally sampled token from emitted lines; request `N+1` to obtain exactly `N` observable words and report this source behavior. Do not retune families after reading validation results. Seeds are `400000 + 1000*family_index + replicate` in the listed order; do not select a best seed.

For each family/seed, take the generated token stream in order, then segment it by the **fixed validation run lengths**. Score its last-glyph predictive gain in bits/pair using the exact EXP-0039 ZL train-fitted probabilities and role/context labels. Apply **200** endpoint-fixed, interior-half-preserving shuffles to that generated stream (`410000 + 100000*family_index + 1000*replicate + permutation_index`). Report the real-generated gain, mean shuffled gain, and their contrast. Independently report (a) generated-token fraction absent from train vocabulary, (b) fraction of generated word *types* occurring once, (c) type/token ratio, and (d) last-minus-first gain. No vocabulary/hapax metric is used to choose parameters. The already frozen EXP-0039 matched-ZL reference is last gain `+0.1184774810`, contrast `+0.1971658710` with physical-leaf bootstrap95% `[+0.1221108346,+0.2683944521]` bits/pair on 2,335 pairs/nine leaves. A separate audit must reproduce exact generated streams from the pinned external code, independently parse source ZL, fit/score the frozen conditional table, replay all 200 shuffles/seed and check hashes and summaries.

Predeclared **one-sided narrow-family falsification**: label a family `edge_below_reference` if its maximum of 16 seed contrasts is below `0.1021108346` (the existing manuscript leaf-bootstrap lower endpoint minus a practical .02 bits/pair margin). Label `edge_above_reference` if its minimum exceeds `0.2883944521` (upper endpoint plus .02). All other edge outcomes are `not_falsified_by_this_edge_assay`; this is **not** evidence of historical identity. For the joint descriptive profile, flag if the absolute novelty or hapax difference from real validation exceeds .05, but do not use that flag to rewrite the edge decision. This seed-range rule is conservative and compares generator randomness with a different source of manuscript uncertainty; report both distributions and do not call it a calibrated hypothesis test. If the independent audit or source check fails, the result is invalid.

Expected local CPU time: at most 300 s runner and 300 s auditor for 5×16 streams and 16,000 shuffles; abort on cap, no paid API or model training. Freeze this registration, runner, auditor, tests and pre-score notebook in a pushed commit, verify `origin/main`, then run once. A positive resemblance would show observational non-uniqueness of a surface constraint; a negative result would reject these *specific frozen implementations*, not nonsemantic generation, language or cipher families. Neither outcome yields plaintext.
