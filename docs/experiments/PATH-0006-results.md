At post-block23, changed value-position residuals from a donor prompt gave full donor answers on 31/32 eligible confirmation bindings. Discovery selected the fixed four-block attention window 28–31, because restoring the clean final-query attention writes removed the donor first token in 19/31 upstream successes, versus 10/31 at 24–27 and 7/31 at 32–35. On **fresh confirmation** bundles, the frozen selected window removed that first token in **20/31** upstream successes (64.52%), whereas independently norm-matched random write edits removed it in **0/31**. Full donor-answer counts were 31/31 after the upstream patch, 11/31 after the selected cut, and 31/31 after matched random. The selected cut produced the clean source answer in 18/31 upstream-success records; thus first-token removal and full source-answer restoration are not identical claims.

The architectural all-12-block attention cut removed the donor first token in 31/31 upstream successes and restored the full source answer in 30/31. Its first-token logit vector matched clean source with maximum absolute error 0.00003815 across all confirmation records; whole-prefix donor transport matched donor first-token logits within 0.00011445. One all-cut continuation yielded `pewron` rather than clean `pewter` despite the first-token restoration, because the changed earlier-position cache remains available during generation. Do **not** interpret the all-cut as whole-answer identity or as evidence for a special circuit. Random-cut norm mismatch was at most 0.00001526. Copy answers were preserved in 13/14 baseline-correct records under both upstream and selected-window edits and 14/14 under all-cut; these pass the registered ≥90% condition for the selected claim.

Four orientation/query variants per bundle are dependent, so 20/31 is not 20 independent replications. The panel is too small and task-specific for a universal layer claim.

Interpretation: a short range of later final-query attention writes carries substantial causal leverage for this direct lookup. The all-cut restoration is expected from the causal transformer architecture because the value edit was confined to earlier positions. The selected four-block concentration over fresh examples and matched-random cuts is the nontrivial observation. Restoring entire attention writes can change many features at once and can trigger downstream repair; this result does **not** isolate an attention head, a unique edge, a semantic latent variable, a reusable two-hop key, or the historical source of Voynich text. A stronger successor would test reversible head/edge-level mediation and factorial second-table relabeling after two-hop competence is qualified.
