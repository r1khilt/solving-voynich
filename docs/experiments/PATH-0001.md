# PATH-0001: attention routes in fresh two-slot bindings

Registered 2026-09-22 UTC before any PATH-0001 model outputs. This is a new exploratory mechanism study, not a rescue of JSPACE-0001/NEURON-0001 or a Voynich reading.

## Question and prior evidence

ROUTE-0001 found that whole-state interventions at earlier positions in block 24 redirected 15/16 eligible answers, whereas final-position interventions redirected 0/16; four blocks later the pattern shifted. Those exposed development records cannot confirm a new claim. The proposed test asks whether attention outputs and value flow mediate a fresh, controlled binding between an arbitrary name and its value. Anthropic's [circuit-tracing methods](https://www.transformer-circuits.pub/2025/attribution-graphs/methods.html) separate value flow from attention-pattern formation and validate approximate graphs with interventions. This study uses the original Qwen3 model and direct interventions, without a replacement-model graph. Prior Voynich work in this repository has not supplied validated semantic anchors; this synthetic binding exercise is method qualification only.

## Inputs and splits

The existing local, four-bit Qwen3-8B snapshot and dense-F32 block reconstruction are frozen from JSPACE-0001. No retraining or download. Prompts state two invented names and two value words in a two-line record, then query one name. The donor swaps the values but leaves the query and all other prompt text unchanged. Both queried slots are used. A copy task with the same records but an unrelated literal target checks nuisance preservation. Discovery and confirmation use disjoint names, value words, and wording templates from fixed source tables; seed 51041 selects the random head control. The renderer must verify equal token lengths and that all differing token positions precede the unchanged query suffix. The only source-text differences are the two value fields. A token-length or suffix failure stops the study before scoring. Prompt text and token IDs remain in ignored local artifacts; compact hashes and counts are tracked. No prior JSPACE final or ROUTE development examples enter this panel.

The unit of generalization is a **name/value vocabulary bundle**, not an intervention row. Reverse value swaps, two queried slots, and paraphrases within one bundle are dependent. Report bundle-level as well as record-level results. The confirmation set must remain unopened for method or head selection until the code and decision rule are frozen in Git.

## Model intervention

Capture each block's final-query attention head outputs before the output projection, plus source/donor Q/K/V. The backend must reconstruct native attention output and logits within numerical tolerance on a tiny Qwen3 and the actual 8B model before scoring. In the source run, replace selected head outputs at one block with donor outputs **after attention, before the MLP**, then resume native computation. This changes only one answer-position attention write and is a broad attention-output control.

For a narrower path intervention, retain source Q and K and substitute donor V at token positions changed by the two value fields, then recompute only selected head outputs. This isolates the value stream under the source attention pattern. Also compare donor Q/K with source V (addressing-only), donor V at all prompt positions, source identity, and a norm-matched random head set. These paths need not add linearly because normalization, attention and later MLPs are nonlinear. A positive value-stream result does not show which earlier block constructed that value.

## Selection and decision

Baseline competence is assessed by greedy 12-token generation with the same strict normalized accepted answer word; only records where both source and donor are correct and their first generated tokens differ enter the causal denominator. If fewer than eight discovery and eight confirmation semantic records are eligible, mark mechanism inference **inconclusive**; still report every baseline and control. This gate is based on capability, not intervention outcomes.

Scan zero-based attention blocks 23, 24, 27, 28 and all 32 query heads on discovery only. Rank a `(block,head)` by mean increase in the donor-first-token minus recipient-first-token logit margin after a single-head donor-output patch. Ties use earlier block, then lower head index. Select the top four heads *from the same block as the best single head*; no confirmation-based reselection. On confirmation, test identity, top-1 and top-4 full-head donor-output patches, top-4 fixed-source-QK/value-token-V patches, top-4 donor-QK/source-V patches, top-4 all-position donor-V patches, four seeded random heads in the selected block, and all-32 full-head patch. Measure full greedy answer switches, first-token margin changes, and copy preservation. The primary exploratory success check requires top-4 value-token-V switches in at least 50% of both-clean-correct confirmation semantic records, at least a 20-point advantage over random-four and QK-only, and copy preservation >=95%. If the full-head all-32 positive control fails to switch at least 50%, label the path test uninformative rather than treating narrow failure as a negative mechanism conclusion. Multiple tested heads and layers are selection, not independent replications. No use of confirmation results for further tuning.

## Bounds, validation and limits

At most 4 blocks x 32 heads x the discovery panel, followed by a fixed eight-condition confirmation grid and copy controls. Stop at 45 minutes or 45 GB MLX allocation, with partial output labeled incomplete. No paid API, external upload, new weights, or historical test-page scoring. Preserve intervention-level outputs, source digests, baseline generations, and failures; commit compact reports. A passing study would identify a task-specific route for explicit two-slot bindings in this one model. It would not identify Voynich symbols, prove a unique semantic variable, or establish transfer to an unsupervised cipher.
