**Registration before any TEACH-0025 suite generation or trained-model intervention, 2026-09-24.** TEACH-0022's independently frozen scoring is running; its prediction files and scores have not been read or audited at registration. This assay neither changes TEACH-0022 nor opens TEACH-0014's reserved seed84311 for neural scoring.

## Question and antecedents

TEACH-0021 and TEACH-0024 localized an exposed-development failure of the TEACH-0014 v3 public-row reader. On seed74111 confirm-confirm, replacing the native first soft read with the model's *own* top-ranked first-row value repaired23/31 and19/28 clean errors while damaging3/97 and2/100 clean-correct answers. That is a finite causal effect in two trained models, but the panel was already exposed during diagnosis. The specific question is whether the same frozen intervention produces a positive paired effect on new graphs without selecting episodes by correctness or first-row rank.

The Voynich analogue remains indirect: no manuscript glyph sequence is known to encode public graph rows. TEACH-0018's architecture review and the project's protocol require fresh families, native controls, and behavior rather than attention images or probe readability. TEACH-0004 shows that typed rows can make a simpler synthetic graph task solvable, but its small alphabet and explicit F/G types do not establish competence for this task or the manuscript. This study modifies no model weights and introduces no new literature-based mechanism claim.

## Frozen inputs and decision

Generate the unchanged TEACH-0014 `evaluation_suite` at seeds **84611 and 84621**, 128 groups each, once. Retain full 19-panel manifests and audit exact graph, logical and render identities for zero overlap against exposed seed74111, reserved ID-only seed84311 and TEACH-0022 seeds84411/84511, and between the two new suites. The two previously completed TEACH-0014 v3 `oracle_rows_workspace` step6000 checkpoints are fixed by the SHA-256 values in TEACH-0024. Score only the `composed_confirm_confirm` 128-item panel in each new suite, in both checkpoint seeds, without filtering any item. No checkpoint selection, retraining, redraw or adaptive threshold change is permitted.

Use the existing TEACH-0024 implementation of the eight finite conditions: clean, identity, native hard-first, native hard-second, native hard-both from the **clean** second argmax, gold-first, gold-last and deterministic wrong-first. The primary endpoint is paired net gain `hard_first correct - clean correct` in each of the four (suite seed, model seed) cells. Call the native repair **fresh-replicated** only if each cell gains at least **10 percentage points** (at least13/128 additional exact answers). Require identity logits to match clean within1e-5, wrong-first accuracy to be below clean, gold-last not below clean, and no checkpoint, suite or source integrity failure. Independently report each cell's raw clean error count, hard-first rescue and damage, first-correct-error denominator, first/second attention target-row hits and mass, attention entropy, all condition accuracies, and cross-cell totals. A threshold miss is a failed replication, not a reason to redraw or reinterpret the predeclared gate. These gates were chosen from the exposed TEACH-0024 effect and are intentionally stronger than merely detecting one rescued item.

The source guard must bind the model, old TEACH-0024 intervention implementation and this registration. Preserve exact suite/checkpoint/source hashes, environment, runtime, raw archive SHA and compact results. Raw suite, optimizer weights and item/logit archives stay ignored; track compact manifest/audit/replay and the notebook. CPU run cap20 minutes, replay cap10 minutes, combined new-artifact cap100MiB, no paid service. If a structural or source gate fails, stop before inference and record the failure rather than silently substituting a seed.

Even a four-cell pass would confirm this intervention on the specified synthetic generator, not identify a unique neuron/circuit, provide a fully autonomous hard-reader architecture, or decipher Voynich. Subsequent model changes must use newly frozen suites; TEACH-0022's separate confirmation comparison remains a distinct result.
