# EXP-0011 — Recover latent signal under random cipher + structured nulls

Registered **2026-09-21** before corpus download outcomes, model fitting, or held-out Finnish scores. Confirmatory on the synthetic holdout rule below; Voynich application is gated and does not score the manuscript final test split.

Linked hypotheses: HYP-001 (filler), HYP-002 (non-1:1 encoding), M-001 (synthetic recovery transfer). This does **not** claim a Voynich decipherment.

## Question

Can a small structural model learn to recover a coherent latent message from an unknown writing system contaminated by structured pseudolanguage, when every training sample uses a fresh cipher and filler is drawn from several families?

Pipeline per sample: `L → C(L) → N(C(L))`.

## Prior work (scope, not replication)

- EXP-0004 recovered supervised signal/filler on a fixed toy alphabet; no language/cipher transfer.
- EXP-0008 failed unfamiliar-key blind transfer for predictive partitions.
- Classical null/filler and Naibbe-style “meaningful ciphertext looks like gibberish” trap: treat worlds B vs D as distinct.
- Method precedents motivating controlled recovery (not historical conclusions): synthetic cipher calibration in this repo; filler/homophony discussions in the project charter and deep-review notes. No claim that Voynich uses these generators.

## Worlds (trained jointly)

| World | Content |
| --- | --- |
| A | Pure natural-language text (Latin-script identity orthography; no nulls) |
| B | Language under a fresh random cipher; no extra nulls |
| C | Ciphered language + structured null/filler insertion |
| D | Pure structured pseudotext (no underlying L) |

World labels are available at training time so the model is not forced to treat all gibberish-looking text as filler.

## Cipher family C (new mapping every sample)

Always: monoalphabetic substitution onto a fresh cipher alphabet drawn from a fixed symbol pool disjoint from Latin letters when the world is B/C.

Cheap optional transforms (independent Bernoulli draws, rates frozen in code/manifest):

- Homophones (one plaintext letter → two cipher symbols)
- Merged symbols (two plaintext letters → one cipher symbol)
- Abbreviation-style vowel deletion (subset of vowels dropped before ciphering)
- Broken word boundaries (delete or insert spaces)

## Null family N (primary rate 0.30 of emitted tokens; secondary 0.15 if budget allows)

Mixed per sequence from:

1. Random characters from the sample’s cipher alphabet
2. Random syllabic pseudowords
3. Copy/mutate of nearby real tokens (required)
4. Periodic filler
5. Shifting phase by line
6. Stateful Markov filler

## Languages and holdout

- **Train/dev languages:** English and Latin public-domain text (Project Gutenberg or already-local), licenses recorded in the download manifest.
- **Held-out language (killer benchmark):** Finnish if a clean public-domain text is obtained; otherwise the best licensed held-out language actually acquired. Encoded with an **unseen** alphabet subset and **unseen** cipher stream; primary filler rate **0.30**.
- Training never sees Finnish plaintext or Finnish-derived cipher samples.

## Models

1. **Tiny character-level neural model** (BiLSTM + mask/recon heads). Target ≪ 100k parameters; measure and record exact count. Prefer finishing on this machine (MPS if available, else CPU). No paid API; no open-ended training.
2. **Classical 2-state (signal/null) Viterbi** with copy/mutate-aware and rank features, run beside the net. If it beats the net under the same rule, that is preferred for interpretability.

## Baselines (held-out Finnish world-C)

1. Majority / delete-nothing (all-signal mask)
2. Random deletion of the same predicted-null count (matched rate; 20 seeds mean)
3. Vocabulary filter: delete tokens absent from training-language ciphertext vocabularies accumulated over training world-B/C surfaces (**must be weak**; see pass rule)
4. Classical null model above

## Preregistered metrics

On held-out Finnish world-C sequences (character tokens including spaces):

- `mask_f1`: F1 of predicted signal positions vs true signal mask
- `mask_acc`: token-level signal/filler accuracy
- `recon_acc`: character accuracy of the sequence obtained by keeping predicted-signal positions, aligned to true `C(L)` (truncate/pad to compare prefix of min length; report also exact-sequence match rate)
- `pred_bits_gain`: bigram bits/char of true `C(L)` vs bits/char of the model-selected subsequence, compared to the same quantity under matched random deletion (positive gain = selected subsequence is more predictable / lower bits than matched random). Primary predictability measure: empirical character bigram cross-entropy on the selected string using a bigram model fit on **training-language world-B ciphertext only** (cipher-invariant via rank-bucketing: replace each char by its within-sequence frequency rank bucket). Details frozen in code.

## Pass rule (frozen before test scores)

On the Finnish holdout, primary filler 0.30, single registered seed set:

**PASS** if **either** neural or classical satisfies all of:

1. `mask_f1 ≥ 0.65` (signal-class F1)
2. `mask_acc ≥ majority_acc + 0.08` (majority = delete-nothing / all-signal; avoids majority’s inflated signal-F1 under ~70% signal)
3. `mask_f1 ≥ mean_matched_random_f1 + 0.08`
4. `mask_f1 ≥ vocab_filter_f1 + 0.05`
5. `vocab_filter_f1 ≤ 0.55` (if violated → **FAIL** with diagnosis “vocabulary baseline too strong / possible cheat surface”)
6. `recon_acc ≥ mean_matched_random_recon_acc + 0.08`
7. `pred_bits_gain ≥ mean_matched_random_pred_bits_gain + 0.05` (bits; higher = better structure vs matched random)

Rationale for (2) vs raw signal-F1-against-majority: with filler rate 0.30, all-signal predictions already achieve signal-F1 ≈ 0.82, which would force an unfair ~0.90 bar unrelated to null detection. Accuracy and matched-random F1 are the registered comparisons for that trap.

**FAIL** otherwise. On FAIL: one bounded diagnostic fix and a single rerun; do not silently move thresholds. Any post-hoc metric is labeled exploratory.

## Voynich gate

Only if PASS: run label-free selection on ZL3b **validation** pages (not test): optimize whether a selected subsequence has substantially stronger rank-bucketed bigram structure than the original and than matched random deletions. Segmentations if cheap: glyph, transcribed token, and any existing edge-aware multi-glyph unit. No fitting or scoring on the final test split. A positive structural result is **not** a decipherment.
