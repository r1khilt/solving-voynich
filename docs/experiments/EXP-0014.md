## Decoder (frozen before confirmation score; pick one)

**Exact-count keep (chosen).** For each sequence of length \(L\) with frozen keep-probabilities \(p_i = P(\mathrm{signal})_i\):

1. \(n_{\mathrm{keep}} = \mathrm{round}((1 - 0.30) \times L)\)
2. Keep the \(n_{\mathrm{keep}}\) positions with the **highest** \(p_i\) (ties: lower index first).
3. All other positions are null/delete.

No post-score retune. No threshold calibration. Secondary CTC blank-count path is **not** used in this id.

## `recon_acc` definition (unchanged; primary)

```text
pred = characters kept by pred_mask
n = min(len(pred), len(true_ciphered))
recon_acc = (fraction of matching prefix chars over n) × (min_len / max_len)
```

Secondary (non-deciding): `recon_edit_sim` = 1 − Levenshtein / max_len.

## Pass rule (frozen before confirmation score)

**PASS** if neural exact-count satisfies **all** of:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc > 0.2043264147237504` — the **already-recorded** EXP-0013 matched-random mean (reported as 0.204); **not** a post-hoc recomputed gate

**FAIL** otherwise. Report recomputed matched-random for transparency only; do not switch the primary gate to it. Do not tune the decoder after seeing the confirmation number. Vocab-filter signal-f1 reported; cheat-surface FAIL if > 0.55 (continuity with EXP-0013).
