## Oracle decoder (frozen before scores)

**Name:** `oracle_gold_mask_delete` — human-readable inverse of `insert_nulls` in `latent_recovery.py`.

1. For each holdout sample, read the noisy surface `text` and the stored binary `mask` (1 = signal / ciphered char; 0 = inserted null).
2. Predict keep-mask = that stored mask unchanged.
3. Reconstruction keeps characters where mask == 1. That is the inverse of the generator’s interleave of signal with family-specific nulls (`random_char` / `periodic` / `copy_mutate`). Copy_mutate nulls are nearby-signal copies, optionally `_mutate_token`-edited; those edits affect **only** null characters, so the inverse does **not** need to undo character mutations—it deletes the null positions.

**Generator-trace use (explicit):** Ciphertext alone does **not** uniquely determine which positions are inserted nulls (a mutated copy can look like a signal glyph). The inverse therefore uses the **stored mask** already written into the EXP-0023 synthetic jsonl for evaluation/supervision. That mask is the generator’s insertion plan (edit trace of which positions were spliced in). No invented edits. If a future run lacked stored masks and the map were not invertible from ciphertext, the decision would be FAIL mode `channel_not_invertible` and stop.

This is an **oracle** decoder, not a discovered one. No neural model. No typed search.

## Pass / FAIL modes (frozen before scores)

Score the oracle **once** on the EXP-0023 Finnish holdout with the **unchanged** EXP-0014 gates:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc` **strictly greater** than **0.2043264147237504**
5. vocab-filter signal-`mask_f1` ≤ 0.55

Also report EXP-0023 winner recon **0.17585403660739804** beside the oracle (from `results/EXP-0023/decision.json`). Do not lower any threshold.

**Decision rule:**

- If the oracle **passes** all gates and the EXP-0023 winner **failed**: experiment decision **FAIL**, mode **`search_missed_inverse`** (the typed family/search cannot find a decoder the metric can see; the bar itself is reachable by the true inverse).
- If the oracle **also fails** the recon bar (or any of the listed gates): **FAIL**, mode **`gate_blind_to_copy_inverse`** (this metric cannot certify the true channel).
- If the oracle cannot be defined because the generator mask/trace was not stored and the map is not invertible from ciphertext: **FAIL**, mode **`channel_not_invertible`**; stop. Do not invent edits.
