Registered **2026-09-21** **before** any fresh-key joint-NLL scores for this id. New experiment id. Does **not** alter EXP-0011–0019 thresholds. **Not** a Voynich decipherment and **not** a manuscript decode.

Linked: R4 in `docs/research/ai-hard-problems-2026-09-21/README.md`; NEXT_DESIGN P2; THEORY edge-emitting belief update; EXP-0008 transfer negatives (familiar-key gains without unfamiliar-key transfer under marginal futures). HYP-003 (state-dependent encoding) as a synthetic calibration only.

## Question

Does a compact **explicit edge-emitting** probabilistic channel, fitted from unlabeled prefixes with state-count selected on development data only, predict **joint continuation strings** on **fresh keys** better than a matched **transformer reference**, under preregistered probability-validity, update-closure, non-first-symbol-only, and equivalent-generator controls?

Hypothesis wording (memo / NEXT_DESIGN): a compact probabilistic channel predicts **strings**, not just next tokens, on fresh keys better than the transformer reference.

## Why EXP-0018 is not a prerequisite

EXP-0018 is a preregistered **ZL3b null-rate grid** on a frozen EXP-0016 checkpoint (manuscript validation select/confirm). It is **not** listed as a dependency of R4 / NEXT_DESIGN P2. This stretch leaves EXP-0018 unexecuted.

## Blindness / leakage

- Generator family identity, true state counts, edge matrices, and key permutations are **sealed** from fitting APIs.
- Fit / select-K / short transformer adaptation use only **visible** symbols on declared fit/validation pools.
- Fresh-key **test** joint scores are computed **once** after models and K selections are frozen.
- No manuscript text. No paid LLM API. ZL3b unscored.

## Generators (frozen; alphabet size 4)

All observations are symbols in `{0,1,2,3}`. Edge form: for each symbol \(a\), matrix \(M_a\) with \(M_a[i,j]=P(\text{next}=j,\,a\mid i)\); rows sum to 1 over \((a,j)\).

| Family | Role |
| --- | --- |
| `iid` | Uniform independent symbols (unrecoverable structure null). |
| `cycle_null` | 2-state cycle: with p=0.7 emit keyed symbol for next state and advance; else emit uniform and stay. Homophones make states ambiguous. |
| `delayed_parity` | 3-phase edge process: emit bit-homophone, emit bit-homophone, emit XOR-homophone (RRXOR miniature; 5 generating states collapsed to alphabet-4 homophony). |
| `copy_lag` | Lag-3 copy with p=0.75 else uniform (variable copying). |
| `equivalent` | Minimal 2-state deterministic cycle with unique symbols per edge; sealed **redundant** 4-state unfolding is observationally identical after state merge. |

**Keys:** master data seed **4020**. Per family: **6** train/familiar encoding keys + **4** fresh holdout keys (independent permutations / stream seeds). Copy and IID “keys” are independent streams (permutation-invariant).

**Pools per key (frozen counts):**

| Pool | Strings | Length | Use |
| --- | ---: | ---: | --- |
| `lm_train` (familiar keys only) | 256 | 65 | Transformer mixture training |
| `fit` | 128 | 40 | Unlabeled edge fit / optional TF adapt |
| `val` | 64 | 40 | Select K / early stop |
| `test` | 128 | 40 | Frozen joint scoring only |

Prefix for conditioning: first **32** symbols. Joint horizon **H=3** (enumerate all \(4^3=64\) strings). One-step marginals reported as secondary.

## Models (frozen)

### Edge-emitting channel

- Softmax-normalized edge logits per state over \((a,j)\); learned initial belief logits.
- State-count grid **K ∈ {1, 2, 4, 8, 16}**; **K=1 is the mandatory null**.
- Fit by Adam on mean next-symbol cross-entropy through exact differentiable belief updates (float64 CPU reference path for validity checks; float32 allowed for fit).
- Restarts: **3** random initializations per K; keep best val NLL.
- **K selection (frozen):** among K with val next-symbol NLL within **0.01** bits of the best, choose the **smallest** K. True K and family never enter selection.
- Interfaces required in code: `initial_state`, `step`, `score_continuation`, `snapshot`/`restore`, probability-validity audit.

### Transformer reference

- Existing `VoynichTransformer`, compact envelope: `d_model=64`, `n_layers=2`, `n_heads=4`, `d_ff=128`, `context_length=64`, dropout 0, vocab = 5 (pad 0 + 4 symbols).
- Train **once** on the mixture of all familiar-key `lm_train` strings: AdamW lr `3e-3`, **800** updates, batch 64, seed **42**. Checkpoint by familiar-key LM val NLL.
- Fresh-key protocol (declared unlabeled per-key fitting): freeze backbone; fit only a bias + temperature on the last-layer logits for **200** Adam steps on that key’s `fit` pool (same observed-prefix budget family as edge fit). If this adapter worsens val NLL, use frozen weights.

### Joint scoring (identical targets)

For each test string, condition on prefix \(x_{1:32}\), then score the joint log-probability of the next H=3 symbols:

- Edge: \(P(a_1\ldots a_H\mid\text{prefix})=b\,M_{a_1}\cdots M_{a_H}\mathbf{1}\) via sequential updates.
- Transformer: teacher-forced product of next-token distributions along the true continuation (AR joint under the model).

Primary metric: **mean joint bits per continuation symbol** = \((-log_2 P(\text{continuation}))/H\), averaged over test strings, then macro-averaged over the **4 fresh keys** of each family.

## Pass rule (frozen before scores)

Evaluate structured fresh-key families **`cycle_null`, `delayed_parity`, `copy_lag`** only for the predictive gate. `iid` and `equivalent` are controls.

**PASS** iff **all** hold:

1. **Probability validity:** every selected edge model on every scored key has nonnegative finite parameters, each state-row sums to 1 within `1e-6`, and every emitted next-symbol / joint distribution is nonnegative and sums to 1 within `1e-6`. Else FAIL mode `probability_invalid`.
2. **Update closure:** for each selected model, algebraic check \(\|b' - b M_a / (b M_a 1)\|_\infty < 10^{-5}\) on 32 random beliefs × all symbols (CPU float64). Else FAIL mode `no_update_closure`.
3. **Not first-symbol only:** let \(\Delta_{\mathrm{joint}}\) = (transformer − edge) mean joint bits/symbol on the three structured families (positive means edge better). Let \(\Delta_1\) = same for horizon-1 only. Require \(\Delta_{\mathrm{joint}} \ge 0.05\) **and** \(\Delta_{\mathrm{joint}} \ge \Delta_1 + 0.02\). Else FAIL mode `first_symbol_only` if \(\Delta_{\mathrm{joint}} < \Delta_1 + 0.02` (even if joint beats TF), or `joint_not_better` if \(\Delta_{\mathrm{joint}} < 0.05\).
4. **Equivalent-generator control:** on `equivalent` fresh keys, oracle next-symbol marginals under sealed minimal vs redundant generators agree within `1e-8`. Require mean \(|\mathrm{KL}(p_{\mathrm{edge}}\|p_{\min}) - \mathrm{KL}(p_{\mathrm{edge}}\|p_{\mathrm{red}})| \le 0.05\) bits on test prefixes. Else FAIL mode `false_unique_recovery`. (Selection already prefers smallest K among near-ties; this gate blocks a fitted channel that secretly aligns to one equivalent parameterization.)

**FAIL** if any gate fails. Negative results are retained; no post-hoc threshold change in this id.

Secondary (non-deciding): per-family tables; K=1 null vs selected K; adapter-vs-frozen transformer choice counts; wall-clock.
