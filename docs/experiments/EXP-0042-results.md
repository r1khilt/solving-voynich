This does not establish that deeper context is absent; it shows that this small-data model did not make a robust enough cross-transcription case under its own rule.

## Interpretation and next discriminating work

The known manuscript end-to-next-start effect survives independent glyph reading under EXP-0039, while this stronger *additional* context test is mixed. The ZL improvement is suggestive because its physical-leaf interval is positive and the model works on known-rule/readable controls. The GC result prevents treating that as a robust new manuscript finding. Both transcriptions concern the same manuscript and the same repeatedly exposed validation leaves, so their agreement would still be adaptive evidence rather than an independent historical confirmation. The model is a small count-based predictor and uses metadata inherited from the manuscript template for books; its failure cannot rule out morphology, syntax, stateful encoding, nonsemantic procedures, or a different representation.

The next useful step is a source-family-disjoint comparison against explicit stateful/verbose channels with multiple readable works, followed by a **fresh physical-leaf or external image/semantic anchor** test before ranking historical explanations. Do not increase confidence by tuning more feature families on these nine validation leaves. No word meaning, language, key, plaintext or generating mechanism was recovered.
