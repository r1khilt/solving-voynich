# ZODIAC-0001 results: no transferable spelling code at fixed diagram position

**Registered prediction.** If the label beside the nth figure in one complete zodiac diagram carries a reusable ordinal/degree component, its 2–3-character features should be unusually close to labels at the same IVTFF-listed position in other signs. The fixed method and threshold are in [`ZODIAC-0001.md`](ZODIAC-0001.md), source-frozen at commit `f49fb45` before any position/form score.

**Execution.** `PYTHONPATH=.:src .venv/bin/python -c 'from voynich.zodiac_ordinal import run; run()'` used four f72 diagrams as reference and two f73 diagrams for evaluation. Train-only inverse-document-frequency weights used 95 certain single labels; 28/30 f73r and 27/30 f73v labels were eligible. Runtime was 0.02787 seconds CPU, with no training or paid API. Result is `results/ZODIAC-0001/results.json`, SHA-256 `bba8af47f2a1215fd4c5b9334991706e0fdcb05e49be5902c1dbd890f89de601`. The separate `scripts/zodiac0001_audit.py` passed, independently rebuilding every corpus source/hash, all 55 label score vectors and ranks, all 900 whole-diagram rotations, and the decision. The full pre-score repository suite passed 1,056 tests, 8 skipped, and 23 subtests; changed-file Ruff and diff hygiene passed.

Chance under the registered rotation null has mean **0.5000**. The exact conditional one-sided probability is **0.4811** (900 rotations). Four labels had strict rank 1 of 30, but that secondary count is not an evidence gate and the aggregate ranks are at chance. The predeclared support gate required overall ≥0.60, exact p≤0.05, and both diagrams ≥0.55; it fails. Registered decision: **`no_support_for_fixed_ordinal_proxy`**.

**Meaning and limits.** This does not identify a numeral, sign name, or star name. It weakens the *specific* idea that the IVTFF listing index carries a shared, easily detectable 2–3-character spelling component across these signs. The proxy may be wrong: figures can be read around nested rings with different starting points or directions, and a historical code may represent each degree with unrelated abbreviations. The four reference diagrams share physical leaf f72; the two evaluation diagrams share adjacent leaf f73. The rotation probability is conditional on these pages, not an independent-manuscript or population probability. The f73 validation text was already part of earlier exploratory work; no claim of pristine final confirmation is made. No `test.jsonl` text was read by this runner or auditor. This result should prevent tuning another string kernel on f73 and treating its best fit as a discovered number system.

The next external anchor should use physically adjudicated image/label correspondences or a historically documented catalogue whose entries can be aligned independently of text. The current public plant-pair inventory does not yet meet that standard; see NOTEBOOK NB-115 and `data/manifests/anchor0002_candidates.json`. The source authors themselves distinguish labels from established names: [Zandbergen](https://www.voynich.nu/extra/labels.html) leaves their function open, and [Averyanov](https://voynich.site/en/hypotheses/zodiac-degrees/) explicitly reports no label reading. [Rozanova and Temerev](https://arxiv.org/abs/2608.17096) further caution that transcription units need not be plaintext letters/words. Our result is about a narrow transfer prediction, not decipherment.
