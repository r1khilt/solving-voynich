# EXP-0004 results — Hidden state is readable; probe-direction steering failed

Completed 2026-09-20 PDT / 2026-09-21 UTC. [Registration](EXP-0004.md), [full summary/provenance](../../results/EXP-0004/summary.json), [seed-42 causal measurements](../../results/EXP-0004/cycle_null-seed42.json).

## What was trained and tested

Six separate 406,656-parameter synthetic models: structured cycle/null and IID families × seeds 42/43/44, 1,000 updates each, 63.77 seconds summed measured training time. Clean source `a84e46da3bb5508898acf4bac8df7ba51fea5a90`, local MPS float32, 600 training/96 validation/192 synthetic test pages per family. Checkpoints selected on synthetic validation only. Structured best steps 1,000/1,000/1,000; IID 900/900/400. All commands are generated by `scripts/run_interpretation_round.py`; corpus settings/digests and weight digests are archived.

The language models saw **only visible synthetic text** and next-symbol targets. Diagnostic linear readouts were then trained using known training-set state/role labels. Thus this experiment demonstrates supervised recoverability from learned activations; it does not discover labels without supervision. The real manuscript supplies no equivalent ground-truth labels.

Readouts were scored on the fixed 4,608 synthetic test positions per model. Those correlated positions and the shared test set across seeds are not independent statistical replications. Bayesian references know the exact generator and return optimal posterior decisions; realized finite-sample accuracy is a reference, not an inviolable empirical ceiling.

## Structured generator results

Means across seeds; the readout SD reflects training variation, not a confidence interval over historical texts.

| Diagnostic | Visible-symbol embedding only | Model final-residual readout | Last-four-symbol Bayesian reference | Full Bayesian reference |
| --- | ---: | ---: | ---: | ---: |
| Hidden state accuracy | 74.48% | **86.25% ± 0.16 pp** | 84.03% | 86.61% |
| Signal vs filler accuracy | 65.19% | **81.58% ± 0.11 pp** | 80.40% | 82.73% |

The true filler rate is 35%, with identical signal/filler marginal alphabets; guessing the majority role gets 65.19% on this test sample. Perfect identification is impossible because filler can mimic a valid signal emission. State/role class recalls and balanced accuracies are archived; in particular, high overall role accuracy does not mean all filler is detected.

## Unrecoverable IID control

IID symbols have hidden state/role labels generated independently of the text. Final-residual state readout averaged **25.39%**, around four-way chance (individual seeds 24.93/26.45/24.78%). Role accuracy was **64.34%**, exactly majority guessing on the empirical test labels; balanced role accuracy is 50%. Next-character loss averaged 3.000693 bits, compared with the 3-bit uniform oracle. The control did not manufacture strong latent recovery.

This is only one structured family and one unrecoverable control with a fixed alphabet. It does not establish recovery across languages, keys, generator families, natural text, or Voynich-like copy/mutate alternatives.

## Causal test: a useful negative result

The registered seed-42 test found 64 pairs with identical final observed symbols but different high-confidence Bayesian states. Donors can repeat. Replacing only the three directions used by the state readout had almost no useful effect relative to a random rank-three control with matched displacement norm.

| Intervention | Distance to donor's known-rule next-symbol distribution, KL bits ↓ |
| --- | ---: |
| Unchanged recipient | 1.437021 |
| Replace state-probe subspace | 1.431043 |
| Norm-matched random subspace | 1.431330 |
| Replace complete final residual | 0.047051 |

The state-direction patch improves the metric by only 0.005978 bits; random-direction patch improves it by 0.005690. This fails to demonstrate meaningful selective state steering under the registered construction. Complete residual replacement reproduces the donor model logits exactly; identity and full-donor controls have maximum error 0.0. The remaining 0.047051 KL comes from differences between donor-model and Bayesian predictions, not patching failure.

**Interpretation:** information being linearly readable does not make those readout-weight directions a sufficient causal state representation. We have a reliable positive calibration for decodability and a negative result for this particular intervention. A different coordinate geometry, nonlinear state representation, or intervention location may matter; none was tested here. Do not relabel this as circuit recovery.

## Consequences for Voynich work

Continue mechanistic research, but require demonstrations beyond probes and attention plots. Before using any filler detector on Voynich, develop label-free proposals and test on new generator families with matched nonsemantic controls. Any learned causal-subspace method should use a fresh registered synthetic holdout rather than silently retuning against these exposed test results. Historical HYP-001/002/003 remain unresolved. No paid API calls, no manuscript test scoring and no decipherment.
