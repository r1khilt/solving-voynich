## Question

If a TinySignalModel is **trained** on synthetic world-C with fillers `random_char,periodic,copy_mutate` @ 0.30, and an EXP-0017-family typed decoder program is **searched** on validation world-C only (length penalty 0.02), does the frozen winner recover Finnish holdout \(C(L)\) above the already-frozen EXP-0014 bar?

## Pass rule (frozen before scores; quote EXP-0014 thresholds)

Apply the typed winner **once** to the Finnish holdout. **PASS** if **all** hold:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc` **strictly greater** than **0.2043264147237504** (frozen EXP-0014 / EXP-0013 matched-random gate; **do not lower**)
5. vocab-filter signal-`mask_f1` ≤ 0.55
6. Winner’s validation \(s\) **strictly greater** than the mean \(s\) of 20 random same-length val programs (seed 4023+1)

**FAIL** otherwise. Do not search new architectures or retune gates after seeing scores. No label-free manuscript decode. No paid LLM. No EVA fluency score.
