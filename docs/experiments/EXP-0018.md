## Question

On the **frozen** EXP-0016 neural checkpoint, does any fixed exact-count null rate in a preregistered grid produce kept subsequences on ZL3b **validation** with higher next-unit predictability than matched-random deletions of the same count?

## Segmentation (frozen; same as EXP-0016 Voynich gate)

- Units: **transcribed character stream** (page `text` with PUA `\ue000–\uf8ff` stripped; **not** lowercased; spaces/newlines retained)
- Windows: non-overlapping chunks of `SEQ_LEN=128` characters; drop chunks with length `<32`; score on unpadded raw length after model forward on space-padded windows
- Do **not** switch to word/token units after seeing scores

## Bits-gain definition (same as EXP-0016 Voynich label-free)

Fit an 8-bucket rank bigram on ZL3b **train** pages only (`fit_rank_bigram`). For a window text \(T\) and keep-mask \(m\):

- `full_bits` = bigram bits of rank-bucket sequence of \(T\)
- `selected_bits` = bigram bits of the kept subsequence under \(m\)
- **bits-gain** = `full_bits − selected_bits` (higher means the kept stream is more predictable under the train rank-bigram than the full stream)
- A window **beats random** iff `gain > mean_random_gain + 0.05` (same +0.05 margin as EXP-0016)

## Decoder family

Exact-count keep (EXP-0016 family): for length \(L\) and null rate \(r\),

\[
n_{\mathrm{keep}} = \mathrm{round}((1-r)\,L);\quad
\text{keep top }n_{\mathrm{keep}}\text{ by }P(\mathrm{signal});\quad
\text{ties → lower index}.
\]

Only \(r\) changes across the grid. Rate \(r=0\) (delete nothing) is a **reference**, not a candidate winner.

## Matched-random control (prespecified)

For each window and each rate, matched random deletes exactly the same count \(n_{\mathrm{null}}=L-n_{\mathrm{keep}}\) positions:

- **20** random masks per window
- Seeds: `numpy.random.default_rng(9011 + s)` for `s ∈ {0…19}` (same base as EXP-0016 Voynich gate)
- Report mean bits-gain over those 20 masks, then mean over windows

## Validation split (frozen before scores)

Seed: **`4018`**. Shuffle the 24 validation `page_id`s with `numpy.random.default_rng(4018)`, take first 12 as **SELECT**, remaining 12 as **CONFIRM**. Page lists written to `data/manifests/exp0018_split.json` **before** any per-rate scoring.

| Half | Role |
| --- | --- |
| SELECT | Choose the rate maximizing `mean_gain − mean_random_gain`. Tie-break: higher `fraction_beats_random`, then **lower** rate. Report full select-half table; label as **selection**, not confirmation. |
| CONFIRM | Score **only** the selected rate. This is the result that counts. |

## Pass rule (CONFIRM half only; frozen)

**PASS** iff **both**:

1. `mean_gain` **>** `mean_random_gain` at the selected rate
2. `fraction_beats_random` **>** `0.50`

Otherwise **FAIL**: fixed-rate exact-count transfer from the multilingual deletion model is **rejected** on this validation split. Do **not** search a new architecture in this session.
