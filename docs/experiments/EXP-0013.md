# EXP-0013 — Subsequence alignment (CTC deletion) after null-rate FAIL

Registered **2026-09-21** before EXP-0013 Finnish holdout scores. New experiment id (does **not** alter EXP-0011 / 0011a / 0012 thresholds). Confirmatory on the rule below. Not a Voynich decipherment.

Linked: EXP-0011 FAIL; EXP-0011a FAIL; EXP-0012 FAIL (null rate ok, recon below matched random); HYP-001; M-001.

## Verified failure mode (prior)

- EXP-0011a easy fillers (`random_char`+`periodic`, rate 0.30): neural `recon_acc` 0.096 vs matched-random ~0.20 under frozen EXP-0011 rule.
- EXP-0012: neural `null_recall` 0.584, `null_precision` 0.542, `pred_null_rate` 0.309, but `recon_acc` 0.151 < matched-random 0.204; `bits_gain` −0.308. Localization is the bug, not class balance.

## Question

If the training loss forces the **kept subsequence** to align to `C(L)`, does localization beat matched-random deletion on the easy Finnish holdout?

## Method (smallest explicit alignment)

**Copy-constrained CTC deletion:** at each surface position the model emits either CTC blank (delete/null) or a **copy** of the observed character (keep). Target sequence is `C(L)`. CTC marginalizes alignments so the non-blank subsequence must match `C(L)` token-for-token. This cannot pass by predicting the right null *rate* alone.

- Architecture: same tiny BiLSTM + copy side features as EXP-0012 (target ≪100k params; exact count at run).
- Auxiliary: light null-weighted mask BCE + mean-null-rate penalty toward 0.30 on world-C (rate gates remain informative).
- Decode (free-running, primary): val-calibrated signal threshold targeting ~0.30 predicted null rate (frozen procedure; not tuned on Finnish).
- Teacher-forced gold-mask reconstruction reported as a **labeled secondary sanity check only** (must be near 1.0 on world-C by construction of deletion).
- Secondary metrics (non-deciding): `recon_edit_sim` (1 − normalized Levenshtein), `mask_acc`, `pred_bits_gain`.

Classical sticky-null Viterbi retained as a baseline method under the same pass rule.

## Setup (unchanged vs 0011a / 0012)

- Languages: English PG#11 + Latin PG#218 train; Finnish PG#7000 Kalevala holdout.
- Seeds: data `4011`, model `42`, finnish `4012`.
- Filler families: `random_char`, `periodic` only; rate 0.30. **No `copy_mutate` in the primary run.**
- Worlds A–D retained (C oversampled). Fresh cipher every sample.
- Baselines: majority, matched-rate random deletion (20 seeds), vocab filter.
- Local MPS/CPU; ≤3,000 updates; no paid API.

## `recon_acc` definition (unchanged; primary)

```text
pred = characters kept by pred_mask
n = min(len(pred), len(true_ciphered))
recon_acc = (fraction of matching prefix chars over n) × (min_len / max_len)
```

Not exact full-string equality. **Kept as primary** for comparability with EXP-0011/0011a/0012. Do not replace after seeing numbers.

## Pass rule (frozen before scores)

**PASS** if **either** neural or classical satisfies **all** of:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45` (blocks delete-nothing / delete-everything)
4. `recon_acc > mean_matched_random_recon_acc` (strictly beats matched-random deletion)
5. `vocab_filter` signal-`mask_f1` ≤ 0.55 (else FAIL cheat-surface)

**FAIL** otherwise. No silent threshold moves. One scored primary run in this id (no post-fail architecture retune).
