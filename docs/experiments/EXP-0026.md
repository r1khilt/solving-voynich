## Pass rule (frozen before test scores)

Unchanged EXP-0014 gates on the **holdout**:

1. `null_recall ≥ 0.50`
2. `null_precision ≥ 0.50`
3. `0.15 ≤ pred_null_rate ≤ 0.45`
4. `recon_acc` **strictly greater** than **0.2043264147237504**
5. vocab-filter signal-`mask_f1` ≤ 0.55

**Decision:**

- If all gates pass: **PASS** mode `ciphertext_only_inverse`. Synthetic only; **not** a manuscript reading.
- Else: **FAIL** mode `ciphertext_only_inverse_missed`; quote test recon beside EXP-0024 oracle recon **1.0** and EXP-0023 winner **0.1759**.

Do not lower thresholds after seeing scores.
