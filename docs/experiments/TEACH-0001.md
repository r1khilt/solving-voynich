# TEACH-0001: a bounded, randomized compositional teacher

**Registration; no training outcome yet.** Date: 2026-09-23 UTC. This study follows PATH-0007's unqualified two-hop prompt interface (0/24 both-clean-correct composed records in each split). It does not revise PATH-0004/0007 outcomes or claim manuscript decipherment. The objective is to obtain a known-answer model whose internals can later be tested for a reusable intermediate key, while measuring whether it generalizes to new table combinations rather than memorizing a fixed table.

## Prior work and rationale

[PATH-0007](PATH-0007-results.md) motivates a purpose-trained local teacher instead of another unqualified 8B prompt. [PATH-0006](PATH-0006-results.md) establishes a fresh attention-write mediation effect only for direct lookup. [The causal-flow memo](../research/latent-mechanisms-2026-09-21/CAUSAL_FLOW_NEXT_TEST.md) explains why a later factorial first/second-table test is necessary. [Lake and Baroni's SCAN work](https://arxiv.org/abs/1711.00350) warns that familiar primitive symbols do not guarantee systematic composition. [Wang et al.'s compositional-function study](https://arxiv.org/abs/2505.23683) supplies a source-based reason to train on a mixture of one-hop and two-hop examples instead of two-hop-only data; its theoretical bounds do not transfer directly to our small lookup grammar. [Grokked Transformers are Implicit Reasoners](https://arxiv.org/abs/2405.15071) distinguishes in-distribution fact recall from generalizing two-hop inference over held-out facts. [Ontañón et al.](https://arxiv.org/abs/2108.04378) show that Transformer architecture choices affect compositional generalization. Our deliberately small four-layer causal transformer and finite task grammar are a qualification instrument, not a replication of those results. Prior Voynich co-occurrence ([Montemurro and Zanette](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0066344)) and nonsemantic generation ([Rugg and Taylor](https://doi.org/10.1080/01611194.2016.1206753)) show why a synthetic mechanism result cannot identify a manuscript reading.

## Frozen generator and partitions

The generator has eight atomic name symbols, eight key symbols and eight output symbols, all represented by separate token IDs. An episode contains a two-row first table \(F:\mathrm{name}\to\mathrm{key}\), a two-row second table \(G:\mathrm{key}\to\mathrm{object}\), and a query. The first table and second table always use exactly the same two distinct keys, with independent assignment/order. The correct composed answer is \(G(F(n))\). Direct queries ask only \(G(k)\); copy queries return an object shown in the query. All inputs have fourteen tokens and one categorical output token. Objects are sampled uniformly without replacement within each two-row table. An independent parser computes every evaluation answer from rendered tokens.

Each table-family partition is a stable BLAKE2s hash of **unordered** (name set, key set) for \(F\), and (key set, object set) for \(G\), reduced modulo ten. Buckets 0–7 are train; buckets 8–9 are holdout. This makes both orientations of one family stay together and guarantees exact family disjointness across partitions. Training samples only F-train/G-train families; no finite training table is materialized. Every optimizer step generates new randomized episodes from a deterministic per-step seed. Evaluation uses a separate seed and reports F-train/G-train, F-holdout/G-train, F-train/G-holdout, and F-holdout/G-holdout conditions separately. **Important limit:** individual name→key and key→object *pairs* can still recur across families; held-out family success is stronger than exact episode memorization but not novel-symbol transfer.

The factorial evaluation consists of 128 fresh held-out quartets when `eval_size=256`: same names/keys, first-table assignment F0 or reversed F1, and second-table output assignment G0 or G1. The four outputs are distinct, so all four answers must differ. Exact 4/4 accuracy is scored per quartet. This forces the answer to depend on the first mapping **and** on the independently selected second mapping; it weakens a fixed-answer injection explanation. It still cannot prove a unique internal key without later causal interventions.

## Frozen model, training and null

Reuse the repository's native `VoynichTransformer`: four causal blocks, width 128, four attention heads, feedforward width 256, context length 14, dropout 0, 32-token vocabulary, untied output embeddings. The architecture has enough depth for separate reads from first and second tables and exposes post-block/head activations for a later causal study. It is also small enough for capped local training. Optimize only the answer-token cross-entropy with AdamW (learning rate 3e-4, weight decay .01, gradient clip 1). Each arm gets 2,500 updates of batch 128, so **320,000 generated training episodes per arm**. The primary arm's episode mixture is 70% composed, 20% direct and 10% copy, sampled stochastically per example. The null arm has the same initial weights, same input episodes, optimizer and steps; only its composed answers are independently uniform random object labels. Its direct and copy labels remain true so it is a matched training/architecture null rather than a broken-model control. An exact symbolic oracle supplies a positive control and checks evaluation labels.

No checkpoint selection on evaluation scores. Save final weights only, histories of training loss every 250 updates, exact Git source revision, registration/source/config/episode-suite digests and compact aggregate scores. An atomic `results/TEACH-0001/status.json` update every 250 steps reports arm, step, elapsed time, latest and recent loss, and peak sampled MPS allocation; stopped status retains those provenance and memory fields. The synthetic evaluation is **development evidence for method qualification**; it is not a manuscript test or a reusable hidden holdout after adaptive tuning.

## Numerical and resource gates

Before scientific training, the exact device must pass finite forward/backward gradients and cached-versus-normal forward logits within 0.002 on a small fixed batch. This is a numerical gate, not a behavior score. The local campaign has one strict wall-clock ceiling of 3,600 seconds across both arms, qualification and evaluation; each step synchronizes MPS for a meaningful elapsed-time check. Per-process MPS fraction is set to 0.16 and sampled allocated memory is stopped above 8 GiB. The native model has **664,704 parameters**; its float32 weights occupy about 2.54 MiB before gradients and optimizer state. At batch 128 and fourteen tokens, activation memory should be far below 8 GiB, but MPS kernel overhead and speed are unknown until a separate pilot. Based on WMD-0001's 2,000-update/453-second 4.945M-parameter denoiser, **roughly 15–45 minutes for 5,000 small-model steps is a planning range, not a measured forecast**. The hard 60-minute cap prevents an open-ended run. If the cap or numerical gate fails, status is stopped/inconclusive and no behavioral qualification is claimed. No paid API, cloud compute, model download or Voynich final-test scoring.

Frozen command after source checkpoint and review: `PYTHONPATH=src .venv/bin/python -m voynich.workspace.teacher1_train --device mps`. The model checkpoints live under ignored `outputs/TEACH-0001/`; compact report/status under `results/TEACH-0001/`.

## Registered metrics and decision

For each 256-example condition report exact answer-token accuracy; report the 512 factorial predictions also as 128 exact quartets. **QUALIFIED for a later causal study only if all hold**: primary F-holdout/G-holdout composed accuracy ≥0.90; each crossed single-holdout composed condition ≥0.90; held-out factorial exact-quartet accuracy ≥0.70; direct and copy accuracy each ≥0.95; null-arm F-holdout/G-holdout composed accuracy ≤0.25; and primary-minus-null composed accuracy on that same condition ≥0.60. Report Wilson intervals on episode counts and on **quartet** counts separately; the latter does not treat four members of a quartet as independent. The generator can repeat an exact episode within an evaluation condition, so episode intervals are descriptive rather than a claim of independent manuscript-style samples. Results failing any gate are **NOT QUALIFIED**, even if training loss decreases or train-family accuracy is high. The random-label null can fail by learning unintended leakage; such a result is diagnostic, not permission to relabel it.

If qualified, preregister a *new* mechanistic study on fresh factorial families: patch the first-table key site, then test whether the changed output follows independently changed second tables, followed by both reversion and injection of selected downstream writes. TEACH-0001 itself makes no causal mechanism claim. Even a clean synthetic teacher would establish competence for this artificial generator only; historical document-generating mechanisms and decipherment require independent controls and held-out folios under the [protocol](../research/PROTOCOL.md).
