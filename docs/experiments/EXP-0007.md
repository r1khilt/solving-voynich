# EXP-0007 — At what scale does distant order matter?

Registered 2026-09-20 PDT / 2026-09-21 UTC after EXP-0005 and before these perturbations/results. Exploratory HYP-003/HYP-006 test. Same768 validation targets, no new neural training, no manuscript final-test scoring.

## Theory and prior work

EXP-0005 found a reproducible modest loss from distant character scrambling, but this destroys both within-group forms and between-group order. One theory is that distant context helps through reusable local forms or spelling patterns; another is that longer ordered relationships matter. Neither requires a claim about plaintext words.

[Reddy/Knight2011](https://aclanthology.org/W11-1511.pdf), sections3–5, discuss character/word-form constraints and word classes. [Lindemann/Bowern2021 v2](https://arxiv.org/abs/2010.14697v2) examine conditional character entropy across transcriptions and comparative corpora, reporting strong within-word placement constraints. Their paper is already in our prior review; primary abstract/version rechecked2026-09-20 PDT. Those observations motivate preserving local forms while disturbing ordering. Our model-intervention test and matched corruption construction are separate from their analyses and do not replicate a decipherment.

## Fixed tests

- Frozen compact checkpoints42/43/44; same contexts and targets as EXP-0005, no target reselection. Original last16 units always unchanged. Four repetitions, seeds7201–7204.
- Order-scale spectrum: divide distant112 into blocks of1/2/4/8/16/28/56 units and permute block order, preserving internal order. If the sampled permutation is identity, rotate it by one block. These conserve exact symbol histograms but differ in disruption extent; save/rebuild corruptions and interpret descriptively.
- Matched group test: groups are contiguous units between definite spaces/newlines. Leave remote-edge fragments unchanged. Only interior complete groups of length>=2 with another group of exactly the same length can move. Permute whole groups within each length bucket, retaining exact separator locations, lengths, local16 and symbol inventory.
- Construct character-scramble control starting from that group permutation. Use exactly the positions whose symbols changed. Attempt up to `min(1024,10*n_changed)` random two-position swaps, accepting only when neither position returns to its original symbol. This conserves both the exact changed-position mask and symbol multiset while disrupting group forms. It is a constrained random walk, not an asserted uniform sampler. Record how often it actually differs from group permutation. Keep no-op examples in the primary analysis.
- Primary contrast: character-scramble minus group-permutation prediction loss on identical changed positions. Report all three seeds, affected-position fractions, control divergence, per-target losses and equal-leaf descriptive bootstrap intervals (2,000 draws,seed7205). Secondary: block-size damage spectrum. No formal multiple-comparison significance claim.

If matched character destruction consistently hurts more than group movement, that supports local-form sensitivity in these models under this control. If differences are small or control divergence weak, retain ambiguity. Equal-length swaps test only restricted ordering; absence of an effect cannot rule out general syntax or larger-scale dependencies. No additive information decomposition or historical-code identification.
