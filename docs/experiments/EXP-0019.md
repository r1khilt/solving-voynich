# EXP-0019 — Generator-adversary search for HYP-005 (R3)

Registered **2026-09-21** **before** any evolutionary fitness scores or held-out diagnostic scores for this id. New experiment id. Does **not** alter EXP-0011–0018 thresholds. **Not** a Voynich decipherment and **not** a historical hoax proof.

Linked: R3 in `docs/research/ai-hard-problems-2026-09-21/README.md`; HYP-005; NB-0022 preregistered match rule; Timm & Schinner–style self-citation / copy–mutate (Cryptologia 2020; D07 SelfCitationTextgenerator materials). Precedents: AlphaEvolve-style construction search with a frozen evaluator; project note that matching selected surface stats is not a hoax proof.

## Question

Can an evolutionary search over a **typed** copy-mutate / self-citation generator force a match on preregistered **optimizable** surface statistics of ZL3b validation, **and then** fail preregistered **held-out** diagnostics (joint word futures, line-initial inventory, A/B top-50 Jaccard) under the NB-0022-style tolerance rule?

Matching a handful of selected stats is **not** accepted as evidence for HYP-005. The held-out block is the verifier that the optimized match did not secretly purchase the withheld structure.

## Blindness / leakage

- Fit character/word inventories and Currier A/B style models on ZL3b **train** only.
- Emit validation-**shaped** pages (line word-counts and page `L` from validation structure only).
- Score reference metrics on **validation**; train metrics enter only as the natural train↔val fluctuation scale for tolerances.
- **Held-out diagnostics are never used in fitness, selection, mutation, or early stopping.** They are scored **once** on the selected winner after search ends.
- ZL3b **test split** is not opened for fitting or scoring (presence may be counted for provenance only).

## Generator family (frozen)

Same simplified self-citation family as NB-0022 `selfcite_ab`:

- Recent-buffer copy / single-edit mutate / prefix–suffix splice, else fresh word from a train-fitted character bigram + length histogram.
- Separate A/B buffers from Currier `L`∈{A,B} train pages; generated pages use validation `L` when A/B, else draw style from train A/B page proportions.
- Explicit simplifications vs published full generator: no folio/illustration geometry; not a port of the published Java codebase; no similarity-network parameters.

**Searchable genome** (continuous/discrete ranges frozen; not expanded after seeing scores):

| Gene | Range | Notes |
| --- | --- | --- |
| `window` | integers `{5,…,40}` | recent-buffer citation window |
| `p_cite` | `[0.30, 0.95]` | probability of citing the buffer vs fresh |
| `p_mutate_given_cite` | `[0.05, 0.85]` | among cites, mutate |
| `p_splice_given_cite` | `[0.05, 0.85]` | among cites, splice; require `p_mutate + p_splice ≤ 0.95` |

Fixed NB-0022 defaults `(window=20, p_cite=0.72, p_mutate=0.55, p_splice=0.25)` are always evaluated as a **non-evolved reference** (not eligible as the evolutionary winner unless re-sampled by search).

**Negative control (not searched):** `iid_char` from train character unigram (NB-0022). Expected to separate on most optimizable metrics.

## Metrics

### Optimizable surface set (fitness only) — 4 metrics

1. `zipf_slope_top500`
2. `adjacent_repeat_rate`
3. `char_h2_bits`
4. `top1_word_share`

### Held-out diagnostics (scored once on winner) — 3 metrics

1. `line_initial_type_share` — line-initial inventory concentration (top-20 line-initial types share)
2. `ab_top50_jaccard` — Currier A vs B top-50 word-type Jaccard
3. `word_h2_bits` — empirical next-**word** conditional entropy \(H(W_t \mid W_{t-1})\) in bits (joint one-step word futures; **not** character \(h_2\))

Floors for τ (same spirit as NB-0022; `word_h2_bits` frozen here):

| Metric | Floor |
| --- | ---: |
| `zipf_slope_top500` | 0.15 |
| `adjacent_repeat_rate` | 0.005 |
| `char_h2_bits` | 0.25 |
| `top1_word_share` | 0.010 |
| `line_initial_type_share` | 0.05 |
| `ab_top50_jaccard` | 0.15 |
| `word_h2_bits` | 0.25 |

**Per-metric match rule (frozen):** Let \(R\) = validation, \(T\) = train, \(G\) = generator. \(\tau = \max(|T-R|, \mathrm{floor})\). **Match** iff \(|G-R| \le \tau\); else **separate**.

## Search (frozen)

- Seed: **`4019`**
- Population: **24**; generations: **20**; elite keep: **4**
- Initialize: 1 individual = NB-0022 defaults; remaining drawn uniformly in gene ranges (invalid genomes repaired by renormalizing mutate/splice)
- Each individual: one validation-shaped corpus with child seed derived from `4019` and a genome hash (deterministic)
- Fitness primary: number of **optimizable** metrics matched (0–4)
- Fitness secondary (tie-break): negative sum of \(\max(0, |G-R|/\tau - 1)\) over the four optimizable metrics
- Variation: Gaussian noise on continuous genes (σ = 0.08 of range) + integer window ±{0,1,2}; clip/repair; 2-point crossover among non-elites
- Budget stop: 20 generations or earlier if any individual reaches **4/4** optimizable matches (still finish current generation)
- **Winner** = highest fitness individual after search. Ties: higher secondary, then lexicographically smaller `(window, p_cite, p_mutate, p_splice)` rounded to 6 decimals

Held-out scores are **not** inspected until the winner is frozen.

## Pass rule (frozen before scores)

**PASS** (R3 hypothesis supported as a methodological counterexample pattern) iff **all**:

1. Winner matches **≥ 3 / 4** optimizable surface metrics
2. Winner **separates** on **≥ 2 / 3** held-out diagnostics
3. `iid_char` negative control separates on **≥ 3 / 4** optimizable metrics (sanity that the match rule is not vacuous)

**FAIL** otherwise, with labeled mode:

| Mode | Meaning |
| --- | --- |
| `surface_unmatched` | Winner < 3/4 optimizable — family+budget cannot force selected surface match |
| `heldout_also_matched` | ≥3/4 surface match **and** held-out separates on ≤1/3 — optimized generator also hits withheld structure; R3 “and then fail” claim rejected for this family |
| `iid_control_failed` | iid does not separate on ≥3/4 optimizable — match rule/data issue; do not interpret surface/held-out |

Secondary (non-deciding): per-metric tables for defaults reference and generation-best history; exploratory hapax fraction / mean word length.

## Interpretation bounds

- **PASS** means: selected surface stats can be gamed by this copy-mutate family while withheld joint-futures / line-initial / A/B inventory still separate. That is evidence **against** treating surface-stat match alone as a HYP-005 proof. It is **not** evidence that the manuscript is language, and **not** a decipherment.
- **FAIL / heldout_also_matched** means this searched family matched both blocks under the frozen rule; still **not** a historical nonsemantic proof (HYP-005 failure mode in the register: competing semantic generators and stronger diagnostics remain open).
- **FAIL / surface_unmatched** means this simplified generator could not be forced onto the selected surface set; does not prove language.
