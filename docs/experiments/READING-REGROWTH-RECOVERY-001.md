## Frozen accuracy and comparison gates

Report exact records, complete used dictionaries, used-row matches, integer/string edit distance and full Gold length; unused rows excluded. A failed reading gets full Gold-length penalty and zero exact/matched rows, though retained MH states should remain complete. No q field is required or assigned to a chain endpoint.

For EACH regrowth seed, inverse-competence gate requires≥90% used-row matches,≤10% edits relative to Gold length,≥50% exact records and≥50% complete used dictionaries. Additional benefit requires strictly fewer edits AND strictly more used-row matches than both the root-only arm and initial baseline for that seed. Every gate must pass for combined recovery PASS. These deliberately ambitious thresholds were fixed before this longer run; failing them is an informative result, not grounds to change thresholds or restart. Report both seeds and every case, no cherry-picked translation.
