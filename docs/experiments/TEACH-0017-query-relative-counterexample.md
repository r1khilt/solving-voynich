# TEACH-0017 visible query-relative coding rival

**Status:** mathematical construction to be scored source-frozen, before any
TEACH-0014 final neural decision or TEACH-0015--0017 trained intervention.
It does not modify a registered neural threshold or train a model.

## Question

Does changing distractor context and row order force a globally stable
intermediate key coordinate? TEACH-0017 was designed to defeat a four-bit
rank among sorted row left operands. Every source and recipient episode in
its declared paired surfaces still shares a visible query token `q`.

Let the ordinary-symbol alphabet be `Z_M`, `M=2048`, and let the first visible
hop from source query `q_s` reach `k_s`. Carry the **single modular offset**

```
c = (k_s - q_s) mod M.
```

At the recipient, compute `k_r=(c+q_r) mod M` and follow the visible row
whose left operand is `k_r`. If `q_r=q_s`, then `k_r=k_s` exactly, regardless
of changed distractors, row order, markers and G outputs. The code is
query-relative: the same `k` has different `c` for different queries. It
is key-equivalent only *conditional on the query*. A fixed-query
interchange assay cannot determine whether the carried state is `k`,
`k-q`, `k XOR q`, or another invertible query-dependent transform.

This is an elementary non-identifiability construction. It is compatible
with the general causal-representation caveat in
[Bing et al. (2024)](https://proceedings.mlr.press/v236/bing24a.html) and
distributed alignment in
[Geiger et al. (2024)](https://proceedings.mlr.press/v236/geiger24a.html),
but neither paper is being credited with this specific counterexample.

## Source-frozen visible-only check

Use the audited128+128 TEACH-0017 manifests, all eight donor surfaces and
all3×3 source/recipient G crossings. The recipient changes `d` and row
order as registered; retain all9,216 attempts per split and designate the
already registered shifted-rank, off-diagonal subset as the primary count.
The symbolic program parses visible tokens with the public strip-and-pair
rule; it never reads `key1` metadata to compute the donor state. Its
identity, same-key, F0 wrong-key, distinct-group, deterministic random
offset, final-answer-injection and relative-rank outputs are reported
separately. The distinct-group donor uses the previously fixed global
derangement; an absent decoded row produces an explicit miss, not a
fabricated target symbol.

The independent auditor reconstructs every expected output from validated
serialized-row metadata, verifies the source/recipient query equality,
first-hop/continuation availability, donor/recipient rank relation,
archive coverage and exact compact counts. It must also verify committed
source and frozen manifest hashes. Store raw rows outside Git and track
only compact score/audit. The random offset is symbolic and is **not** a
norm-matched neural vector. Therefore even perfect symbolic transfer cannot
be called a neural mechanism, a passed numerical replay, or decipherment.

## Discriminating successor

A later cross-group challenge must pair the **same key across different
queries** while keeping an appropriate recipient continuation. Its source
answer, base answer and target answer should be distinct, with multiple G
remaps to preclude source-final-answer copying. A same-query positive
control and a cross-query patch-validity control are needed before a
failed cross-query intervention can be interpreted. The same-rank/different-
key triad in `TEACH-0017-cross-context-design.md` addresses the separate
rank rival. Even both challenges cannot identify a unique neuronal basis:
an invertible global recoding of `k` remains behaviorally equivalent.
