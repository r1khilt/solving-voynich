# PATH-0009 result: weak candidate-logit signal does not rescue two-hop qualification

This is a **retrospective exposed-data diagnostic**, not fresh confirmation. Using PATH-0007's saved first-token logits, we compared only the expected object word with the alternate second-table object word. Bare and leading-space spellings were combined only when each was a single Qwen tokenizer token; no word lacked a usable variant. Across both splits and styles, the expected object had the higher combined candidate logit in 14–17 of 24 individual queries. That number alone is misleading because each two-query pair expects *opposite* objects; a fixed lexical preference can make one look correct.

The stronger paired check required the preferred object to reverse correctly when the question changed between the two names, holding the same table and orientation. Correct paired reversals were **2/12** for colon and **4/12** for arrow on discovery, then **5/12** and **4/12** on confirmation. These 12 pairs per cell come from only six lexical bundles with two dependent orientations. The model generated neither object word as its first token in any of the 96 analyzed composed prompt records. The candidate ranking therefore shows at most a weak, bundle-dependent context effect, far short of a reliable output interface or a verified two-hop algorithm. It cannot change PATH-0007's unqualified verdict or PATH-0004's inconclusive one.

The metric is restricted to the *first generated token*, when the actual model often begins an explanation. A relative two-object logit comparison under that distribution is not the probability of a completed final answer. It also lacks fresh held-out evaluation: PATH-0007's words and output failure were known when this question was registered. A constrained decoder would need separate fresh calibration and confirmation before being called competent; merely selecting the higher of two words here could conceal errors.

Exact source/input/array hashes, token IDs, margins and pair labels are in `results/PATH-0009/results.json`. No Voynich meaning or model-internal causal route is inferred.
