# A visible relative-address counterexample to key-token identification

**Status:** exploratory structural falsification, designed 2026-09-24 before
any trained TEACH-0015/16 inference or final TEACH-0014 v3 neural outcome.
The TEACH-0016 causal benchmark is admitted, but this symbolic exercise does
not alter its frozen behavioral thresholds or claim a trained mechanism.

## The overlooked invariant

TEACH-0016 changes the **order** of rows between source and recipient. It
leaves the set of row left operands unchanged within a group at fixed
distractor topology. The F0/F1 change swaps two right operands, while the G
remaps change only right operands. Marker and row-order changes also preserve
the left-operand set. A visible scan of all9,216 source/recipient G attempts
in each frozen split found matching sorted left-operand sets in9,216/9,216
discovery and9,216/9,216 confirmation attempts. This is a property of the
synthetic input family, not an observed neural representation.

Consider a solver that parses the visible rows, performs the first hop
`k=F(n)`, then stores **only the ordinal rank** of `k` among the sorted set
of row left operands. That rank is a small program-relative address, not the
token identity of `k`. In a recipient program, it selects the left operand
at the same rank and follows its outgoing row. The rank survives arbitrary
row serialization and G output remapping because the left-operand set is
unchanged. The same-group F0 wrong-key state has another rank; a distinct
group's F1 state has generally unrelated rank. Thus the TEACH-0016 controls
can in principle favor this mechanism too. Unlike an abstract group-ID
lookup, both extraction and decoding use only the visible token stream.

The executable constructor uses the repository's deterministic public row
parser, records every source/recipient identity and rank, and applies the
frozen TEACH-0016 all-attempt scorer. Its distinct-group control uses the
same global derangement as the neural assay. A deterministic hash chooses a
symbolic random **rank**; this is not the neural assay's norm-matched random
512-vector, and this oracle does not pass or attempt checkpoint replay. A
separate no-generator auditor reconstructs expected ranks and predictions
from independently validated serialized-row metadata, verifies all archive
rows and score denominators, and checks source hashes. Report both splits and
all controls; do not choose a new seed after seeing the score.

This construction sets an interpretation limit even if a trained model later
passes TEACH-0016: `ORDER-ROBUST-PORTABLE-STATE-SUPPORTED` rejects the
literal **absolute physical row index** rival, but it cannot identify a
globally stable key-token representation. A relative rank is causally useful
within this family while failing when the same key appears among a changed
set of other left operands. The next discriminating input family would pair
the **same key** across independently generated graphs with deliberately
different left-operand sets and key ranks, while pairing **different keys**
at the same rank. It needs fresh clean competence, a patch positive control,
and changed-context nuisance controls before a failed transfer is
interpretable. Even that would identify a key-*equivalent* variable only up
to an invertible recoding, not a unique neuron or J-space axis.

This distinction follows the general warning that causal representation
identification requires intervention diversity and assumptions
([Bing et al., 2024](https://proceedings.mlr.press/v236/bing24a.html)).
Distributed alignment permits non-neuron bases and evaluates a specified
causal abstraction, not a unique natural code
([Geiger et al., 2024](https://proceedings.mlr.press/v236/geiger24a.html)).
Neither paper asserts this particular rank mechanism or transfers an
identifiability guarantee to the Voynich manuscript. The manuscript has not
been tested here.
