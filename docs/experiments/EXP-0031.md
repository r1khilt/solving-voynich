# EXP-0031 — causal symbol-renaming assay of the corrected-channel model

Registered before any EXP-0031 output. **Exploratory** on the already exposed EXP-0030 Finnish holdout; no new training, model selection, Voynich score, or final manuscript test.

## Question and source rationale

Does the frozen EXP-0030 null decoder behave as the synthetic generative distribution requires under arbitrary renaming of non-space cipher symbols? See the proof, iid impossibility control and caveats in [SYMBOL_RENAMING_IDENTIFIABILITY](../research/SYMBOL_RENAMING_IDENTIFIABILITY.md). Prior Voynich applications are the synthetic latent-recovery sequence and corrected EXP-0030 FAIL; [Kambhatla et al. 2023](https://aclanthology.org/2023.findings-eacl.160/) use recurrence encoding for substitution-key generalization, and [Cohen and Welling 2016](https://proceedings.mlr.press/v48/cohenc16.html) give the group-equivariance rationale. Their tasks/data differ; this assay diagnoses the current model, not the manuscript.

## Outcomes and controls

Identity re-inference must match original probabilities within `1e-6`, and feature arrays under every relabeling must match exactly. Otherwise the assay is **invalid**, not a model result. Measure per-row/per-family mean absolute probability drift, exact-count keep-mask flip fraction, embedding and BiLSTM hidden-state relative L2 drift. Resample the 99 copy rows 2,000 times by row (seed `310131`) for a 95% interval on mean keep-mask flip rate. An arbitrary glyph embedding is the only changing model input path; these measurements do not uniquely identify a hidden circuit.

Classify a **material symmetry violation** if copy-row mean keep-mask flip fraction is **>0.05** and its row-bootstrap 95% lower bound is **>0.02**. Otherwise call the observed output approximately stable at this resolution. Separately average the 32 probability vectors per row (identity + 31 renamings), apply the unchanged exact-count decoder on the **original** text, and report reconstruction/null metrics by family. Call group averaging an exploratory benefit only if copy-only reconstruction exceeds the original model by **>0.02** *and* exceeds the frozen copy matched-random score **0.2074623649767012**. Otherwise report no benefit. These thresholds were set before running this assay; the Finnish source was already exposed, so even a benefit is not independent confirmation.

Controls: the original exact-count score must reproduce EXP-0030's mixed **0.18838171635900422** and copy **0.16651924193353831** within `1e-10`; a deterministic identity replay must be numerically stable. Save compact packed keep masks per row. A separate auditor will independently decode those masks, recompute every row's reconstruction and null counts, verify aggregate arithmetic, hashes and threshold decisions, and directly replay a fixed sample of raw model predictions/renamings. No statement about actual Voynich symbol exchangeability follows.
