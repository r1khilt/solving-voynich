# EXP-0038 — transcription and no-copy challenges to the boundary signal

Registered 2026-09-25 **before** EXP-0038 scores, after EXP-0036/0037. Adaptive exploratory work on the same exposed ZL3b train/validation physical leaves; final test remains untouched. Linked HYP-004/HYP-005. A passing result would specify a reproducible boundary constraint, not decipher the text or identify copying.

## Trigger, prior Voynich work and method rationale

EXP-0037's last-EVA-codepoint→next-first-codepoint signal survives endpoint-fixed, interior-half permutations, but EVA codepoints are not established glyphs and the predictor does not condition on section/scribe. [Zandbergen's transcription analysis](https://www.voynich.nu/analysis.html) explains that EVA sometimes uses several letters for one plausible character and that spaces need not delimit linguistic words; his [Cuva analysis alphabet](https://www.voynich.nu/extra/sp_analysis.html) explicitly groups `ch`, pedestalled forms and final minim sequences while disclaiming a uniquely correct segmentation. [Parisel's positional analysis](https://arxiv.org/html/2604.19762v2) motivates controlling boundary placement and Currier-type differences, but its descriptive MI does not identify a mechanism. EXP-0028's stronger spelling/no-copy comparison did not support a one-edit word cache. [Chen and Goodman's smoothing study](https://aclanthology.org/P96-1041/) motivates held-out predictive likelihood with backoff rather than unsmoothed plug-in MI; the particular pseudocounts here are fixed pragmatic controls, not claimed optimal. A meaningful language, a stateful cipher, layout conventions and nonsemantic copying remain rivals.

## Frozen input and four observation views

Use only `data/processed/zl3b/train.jsonl` SHA-256 `49618c7be69cef573fe9ad8ae3627ad9f7b495601af1897aafb6082837fceca4` and `validation.jsonl` SHA-256 `9bee4149f26fc49b49e4a826b73598dfb79a1e785731c15a1763489315a2efd3`. Process exactly contiguous `[a-z']+` word runs **within one locus**, length≥4; noneligible tokens interrupt a run. No boundary pair across uncertainty, locus or page. For all views retain the same runs unless the fourth view excludes the entire locus. These are transformations of **one transcription**, not independent transcriptions or claims about true glyphs.

1. `codepoint`: every EVA Latin codepoint is a unit, as EXP-0037.
2. `basic_compound`: greedy longest match of `cth, ckh, cph, cfh, ch, sh`; remaining letters stay singletons.
3. `cuva_like`: the above plus greedy `iiin, iiir, iiil, iiim, iin, iir, iil, iim, in, ir, il, im, eeee, eee, ee`. This is a transparent sensitivity transform inspired by the cited Cuva table, **not** a complete official Cuva conversion.
4. `clean_cuva_like`: same tokenization as view3, but drop any locus marked `uncertain_space`, `alternative`, `rare_eva`, `unreadable` or `unknown_span`; retain other markup as recorded. All complete groups from a marked locus are excluded, not silently repaired.

Use a fixed target alphabet equal to `a-z`, apostrophe and the declared compound units. No token inventory is inferred from validation. Previous-word feature candidates: `last` unit, `first` unit, and tokenized length capped at8. The prediction target is the *first unit of the following word*. For each edge role (first/middle/last pair in its run), fit on train only a global Laplace-one target prior. Back off a **section/hand (`I`,`H` metadata) + edge-role** prior toward it with50 pseudocounts. Each feature-conditional distribution backs off toward that section/hand/role prior with20 pseudocounts. All are normalized probabilities. The no-copy baseline is the section/hand/role prior. Compare held-out log2 gains of `last`, `first` and `length` over this same baseline; no validation-based smoothing choice.

## Frozen controls, uncertainty and decisions

For each view use **200** endpoint-fixed, interior-half-within-bin permutations of each run (seed `380038+replicate`); use the same seed and group order across views, including excluded clean-view groups, before filtering. Preserve run lengths, endpoints, word multiset, half-position bin, locus/page/leaf, section, hand and uncertainty exclusions. Report each feature's real and permutation-mean bits/pair. For `last`, bootstrap the real-minus-permutation contrast over physical leaves with2,000 draws seed `380138` and report the permutation95th percentile. Also bootstrap `last-minus-first` and `last-minus-length` on real data by leaf, same draw rule. All intervals are descriptive because validation is exposed and multiple views are correlated. A fixed eight-symbol toy sequence with next-first copied from previous-last at probability0.8 is a sensitivity control; require its `last` real-minus-half-shuffle≥0.1 bits/pair and `last-minus-first` real gain≥0.1.

`representation_robust` requires the `last` real-minus-permutation contrast≥0.02 bits/pair, leaf-bootstrap lower>0, and observed score>permutation95th **in all four views**, plus both toy controls. `terminal_specific` separately requires `last` real gain to exceed **both** `first` and `length` by≥0.02 bits/pair with leaf-bootstrap lower>0 in **all four** views. Otherwise report the failed label(s); if toy fails, result is invalid. A positive label can arise from language, formulae, a copy channel or cipher state. It cannot name a word or prove a null layer. A separate source-to-result auditor must recompute all input groups, normalization, predictors, **200 per view** permutations, bootstrap values and gates independently.
