# EXP-0022 — Language-ID / simple-substitution counterexample with null controls (R5)

Registered **2026-09-21** **before** any language-ranking or null-control scores for this id. New experiment id (EXP-0021 is the separate rate-free decode prereg). Does **not** alter EXP-0011–0021 thresholds. **Not** a Voynich decipherment and **not** a frozen reading.

Linked: R5 in `docs/research/ai-hard-problems-2026-09-21/README.md`; Hauer & Kondrak (TACL 2016) language-ID under substitution/anagram assumptions with explicit artifact warning; Knight-style monoalphabetic attacks (Copiale / Knight et al. 2006 lineage as method precedent only). Linked hypotheses: HYP-004 (linguistic structure without removable filler) as a **class under test**, not as a positive claim.

## Question

Under a **frozen** UDHR/FLORES language panel and a **frozen** monoalphabetic + soft-homophonic attack family, does any language **uniquely prefer** true ZL3b EVA (train+validation) over **scrambled-glyph** and **section-shuffled** null controls?

Hypothesis (memo R5, confirmatory for class rejection): **no** panel language wins on true EVA **without** also winning on the null controls; the same attack must **not** prefer Hebrew or Latin on length- and Zipf-matched null text.

## Blindness / leakage

- Language LMs are fit **only** on the frozen romanized UDHR/FLORES panel files listed below (already vendored under `data/raw/exp0016_corpora/romanized/`). No new downloads. No paid API. No LLM translation.
- Ciphertext for ranking is ZL3b **train + validation** pages only. ZL3b **test** is not opened for fitting or scoring.
- Panel membership, attack budgets, margin, null constructions, and pass/fail modes are frozen in this document **before** inspecting rankings.
- No label-free “reading,” no plant IDs, no held-out leaf semantic test.

## Attack family (frozen)

Units: lowercase `a–z` plus space. Voynich cleaned like EXP-0019 (`PUA` stripped; non-`a–z` → space). Language files: keep `a–z` and spaces only.

### Language model

Per language: character **bigram** with add-1 smoothing over alphabet `{a…z, space}`. Score of a plaintext string = mean \(-\log_2 P(c_i\mid c_{i-1})\) (bits/char; lower better).

### Monoalphabetic attack (`mono`)

1. Initialize cipher→plaintext as **frequency-rank** map of the top-\(|A_L|\) cipher letters onto language letters by descending unigram frequency (spaces fixed as space; leftover cipher letters map to rarest language letters in cyclic order).
2. Hill-climb by random **letter swaps** of the mapping: seed **`4022`**, **2500** proposals, accept if bits/char decreases.
3. Report best bits/char.

### Soft-homophonic attack (`homo`)

Many-to-one allowed. Initialize each non-space cipher symbol to the language letter with closest unigram rank. Then **8** iterated conditional-mode passes: for each cipher symbol in frequency order, assign the language letter minimizing mean bits/char with other assignments fixed (spaces fixed). Seed only affects any tie breaks via stable sort (deterministic).

**Primary ranking** uses `mono` bits/char. `homo` rankings are logged and used only in the secondary artifact table, not in the pass rule.

## Corpora under attack (frozen)

**Ciphertext budget (frozen):** build the full cleaned train+validation concatenation, then keep the shortest prefix that contains exactly **12,000** `a–z` letters (spaces/newlines retained inside that prefix). All four corpora below are derived from that same prefix so length and letter count match. Rationale: bound local CPU cost of the hill-climb; budget fixed before scores.

| ID | Construction |
| --- | --- |
| `true_eva` | Prefix of cleaned ZL3b train+validation concat (`page_id` sort) with exactly 12,000 letters as above. |
| `scrambled_glyph` | Global permutation of non-space character **types** in `true_eva` (seed **4022**); spaces/newlines preserved. |
| `section_shuffled` | Group train+validation pages by illustration code `metadata.page_variables.I`; within each group with ≥2 pages, shuffle page **texts** among those page slots (seed **4023**); concatenate in the same `page_id` order; then apply the **same letter-prefix cut** as `true_eva`. |
| `zipf_length_null` | Preserve exact whitespace/newline mask of `true_eva`. Fill non-space positions by sampling **without replacement** from the multiset of non-space characters of `true_eva` after a seeded shuffle (seed **4024**). Exact length, exact character multiset (hence same unigram / Zipf of glyphs), destroyed order. |

## Preference rule (frozen)

On a corpus \(C\), language \(L\) is **preferred** iff:

1. Its `mono` bits/char is **strictly minimal** among the 24 panel languages on \(C\), and
2. Margin \(m = s_{(2)} - s_{(1)} \ge 0.020\) bits/char, where \(s_{(1)}, s_{(2)}\) are the best and second-best `mono` scores.

If no language meets both, the preferred set is empty.

## Pass / fail rule (frozen before scores)

Evaluate once. Modes:

1. **`panel_too_short` / `corpus_missing`:** abort; no scientific decision.
2. **`hebrew_latin_null_preferred` (method_invalid):** if `heb` or `lat` is preferred on `zipf_length_null` under the preference rule → **FAIL** this mode. Rankings on EVA are not interpreted as language ID.
3. Else let \(W_{\mathrm{true}}\), \(W_{\mathrm{scram}}\), \(W_{\mathrm{sect}}\) be preferred sets on `true_eva`, `scrambled_glyph`, `section_shuffled`.
4. **`lead_open`:** ∃ language \(L\) with \(L \in W_{\mathrm{true}}\) and \(L \notin W_{\mathrm{scram}}\) and \(L \notin W_{\mathrm{sect}}\). Record \(L\) as an **artifact-resistant lead under this attack only** — **not** a decipherment (no frozen reading, no held-out leaf test). Decision: **FAIL** mode `lead_open` relative to the class-rejection hypothesis (lead recorded).
5. **`simple_language_id_rejected`:** otherwise (**PASS** of R5 class-rejection hypothesis). Includes: empty \(W_{\mathrm{true}}\); or every preferred true-EVA language also preferred on scrambled and/or section-shuffled (artifact).

Secondary (non-deciding): full 24×4 score tables; `homo` top-3; whether any language is preferred on all of true/scram/sect; wall-clock.

Local CPU only; expected minutes. Stop if a single language×corpus hill-climb exceeds 120 s. No paid API. No new bulk corpus download.
