# What the two fresh binding studies establish about information routing

2026-09-22. This memo separates observation, architectural deduction, and hypotheses. The model is the existing cached Qwen3-8B four-bit checkpoint with dense-F32 block evaluation. The tasks are explicit, known-answer English registries. Nothing here labels a Voynich glyph or decodes a manuscript page.

## The causal pattern, stated without a feature name

The source prompt contains two invented names and two arbitrary value words. The donor prompt swaps the two values while keeping the question identical. At each layer, we either replace the model's internal state at selected prompt positions with the corresponding donor state or leave it alone. The output asks for one named value.

PATH-0002 precommitted to twelve fresh name/value bundles, three wordings, five post-block layers, seven position scopes and a full-prefix donor control. At block 24, donor states at changed value-field token positions produce the donor answer in45/46 eligible cases; matched random directions at those same positions produce0/46. Donor states at unchanged earlier positions produce0/46. Donor states at the last query position produce0/46. At block32, last-position donor states produce41/46 and changed-value-field states only1/46. The whole-prefix donor control produces46/46 at block24 and45/46 at block32. Copying stays22/22 under every condition at every layer. Source and donor clean competence is46/48, leaving two records outside the primary causal denominator.

The narrow conclusion is a **depth-dependent effective control site**. At early/middle blocks, the changed value fields have enormous causal leverage; late in the network, the final query position has most of it. This corroborates ROUTE-0001's position-dependent country-codebook diagnosis on a new task and many more bundles. It does not follow that the model stores one abstract, reusable “value variable” at those token sites. A full residual vector contains all local and contextual information, and the model may simply be performing a token lookup/copy.

## Why the head search was weak even though the position test is strong

PATH-0001 chose heads from a discovery scan and patched their **attention outputs at the final query position in one block**. On disjoint names/values, four selected heads changed5/16 answers, a source-QK/donor-value patch changed3/16, random four changed0/16, and replacing all32 heads in the block changed only3/16. The registered positive control failed. The scan therefore did not identify a sufficient one-block route.

PATH-0002 perturbed an earlier **full residual state at the value fields**. Every later block could then recompute its own attention, normalization and MLP behavior from the modified state. Its45/46 result and PATH-0001's3/16 narrow value-head result are compatible: the latter interrupted only one candidate read step, while the former changed the information available to all downstream steps. The two studies also use disjoint tasks and answer vocabularies, so the numeric rates should not be subtracted as if they were paired trials.

This distinction matters for JSPACE-0001 and NEURON-0001. Stable/J-readable directions and conspicuous neurons were weak output controls when edited at one late position. PATH-0002 demonstrates that the **location** of an edit can dominate its effect. It does not prove those old directions or neurons would work if moved, and their registered failures remain valid. A better next study should test both representation specificity and route support. A raw donor state is a broad positive control; a concept direction is a selective hypothesis.

## Architectural expectations versus measured claims

A causal transformer permits a token position to influence later positions only through subsequent attention. An edit at an early value token has many remaining blocks in which it can change later states. An edit at a late value token has fewer opportunities, whereas an edit to the final answer position is already on the output path. Thus a broad early-to-late shift is consistent with the architecture and should not be presented as the discovery of a special biological-style global workspace. What required measurement was its strength, specificity against norm-matched random edits, persistence across fresh word bundles/templates, and the crossover between sampled blocks.

The observed zero for “other earlier” positions is unusually useful for the proposed mechanism. Those positions have source/donor hidden differences because they follow the changed values, but transplanting their states alone never changed an accepted answer in this panel. That suggests the working path is concentrated at the literal value fields until a later read into the final query site, rather than spread uniformly across earlier context. **It does not prove absence of information** at those other sites: information can be readable there yet redundant or ineffective under this particular intervention. The measured site is a causal sufficiency location under one donor construction, not a unique storage address.

Likewise, block28 permits both value-field and final-position edits to redirect subsets, but our five sampled blocks do not identify the exact transition block. Strict full-answer scoring also exposes formatting effects: the single block24 value-field failure included the desired word plus extra explanation. The registered score remains45/46; no post hoc acceptance rule was added. First-token donor agreement and full-text correctness are different objects.

## A sharper next intervention, proposed rather than executed

The next mechanistic target is a **mediating attention edge** from a value-field state to the final query state. The original [Transformer Circuits framework](https://transformer-circuits.pub/2021/framework/index.html) distinguishes QK addressing from OV/value transport; [circuit-tracing methods](https://www.transformer-circuits.pub/2025/attribution-graphs/methods.html) require testing candidate routes by interventions in the original model. [Wang et al.'s IOI study](https://arxiv.org/abs/2211.00593) shows task-specific head classes can be causally mapped in GPT-2 small, while leaving transfer to this model/task an empirical question.

A rigorous successor would create new bundles with a delayed or composed query, verify clean competence, and use the working PATH-0002 value-field transplant as the *upstream cause*. It would then, at a fixed set of downstream blocks, revert selected attention-head contributions to their clean-source values **only at the final query position**, asking which reversion blocks the donor answer. The reverse experiment would restore those head contributions on an otherwise source run. Both directions are needed: a head can be sufficient under one context but dispensable when parallel routes compensate. Freeze the head/layer selection on discovery, test on disjoint bundles, and compare equal-norm random heads, full-head restoration, unchanged copy queries, and source/donor first-token numerical controls. Crucially, capture head outputs from the *value-field-patched run* itself, since a clean-donor run can have different upstream states and attention patterns. Without that distinction, the patch could transfer an answer-like state from another computation rather than isolate mediation.

Even a successful mediator would establish a route for explicit binding/copying. To matter for the Voynich objective, the method must eventually distinguish competing **document-generating systems** under hidden mappings, not merely explain how a pretrained model reads a supplied key-value table. Independent manuscript evidence, executable decoding rules, structured nonsemantic controls, and held-out physical pages remain necessary.
