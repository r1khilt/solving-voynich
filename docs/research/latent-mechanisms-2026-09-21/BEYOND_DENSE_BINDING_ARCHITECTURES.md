# Beyond dense scaling: architectures that can actually bind and compose

**Theory memo, 2026-09-23 UTC.** This is a source-based proposal, **not** a new experiment, implementation, TEACH-0003 outcome, or Voynich reading. TEACH-0003 was running when this memo was prepared; no interim scores or model states were inspected. The last audited synthetic result is [TEACH-0002](../../experiments/TEACH-0002-results.md): its two curriculum seeds usually chose a visible key or object but almost never changed that choice when only the queried row changed. Its factorial composed answers responded to remapping the second table, while almost never responding to swapping the first-table assignment. A 0.67M-parameter failure does not establish an architectural impossibility; the [75.6M-parameter TEACH-0003 registration](../../experiments/TEACH-0003.md) tests scale and *auxiliary* row supervision. Its auxiliary heads do not feed the answer path. The unresolved question is which **inference-time computation**, if any, learns reusable query-dependent binding.

## The target computation and what observations cannot identify

In the diagnostic task, two episode-specific tables define $F:n\mapsto k$ and $G:k\mapsto o$; the requested answer is $C(n,F,G)=G(F(n))$. A behavioral model is successful only when it selects the correct row of **both** tables under fresh mappings. On a finite training distribution, however, an arbitrary function of the entire input can mimic $C$ without explicitly representing an intermediate key. Even perfect held-out answers establish an input-output competence over that distribution, not a unique internal algorithm. The [causal-abstraction framework of Geiger et al.](https://proceedings.neurips.cc/paper/2021/file/4f5c422f4d49a5a807eda27434231040-Paper.pdf) and their [interchange-intervention training work](https://proceedings.mlr.press/v162/geiger22a.html) motivate testing whether a proposed high-level variable has the **right counterfactual effects**, rather than merely predicting it from activations. This task's $F,G$ labels are known by construction; none are known for the manuscript.

There are two separate identifiability problems. First, a latent vector $h$ can be changed to $h'=Th$ for invertible $T$ while a following linear readout changes from $W$ to $WT^{-1}$, preserving $Wh$. Neuron coordinates and raw cosine can therefore change without changing the computation; our [similarity memo](SIMILARITY_THEORY.md) develops this gauge issue. Second, if a model emits two exchangeable slots $s_1,s_2$, replacing them with $s_{\pi(1)},s_{\pi(2)}$ and permuting the downstream reader gives the same function. A claim such as “slot 1 is the key” requires an externally fixed slot convention or a permutation-invariant alignment criterion. [Locatello et al. 2019](https://proceedings.mlr.press/v97/locatello19a.html) give a broader warning about unsupervised disentanglement without inductive assumptions. These deductions do not imply that useful functional variables cannot be found; they specify what a neuron or slot label cannot establish on its own.

## Priority 1: a genuinely learnable two-hop key–value memory

The most decisive immediate contrast is a small, explicit memory interface with **learned** addressing. [End-to-End Memory Networks](https://arxiv.org/abs/1503.08895) use differentiable recurrent attention and multiple hops; [Key-Value Memory Networks](https://aclanthology.org/D16-1147/) distinguish address keys from readout values. Their successes concern supervised synthetic QA or document QA with different data and objectives. They motivate a design here, not a prediction of success on Voynich text.

Represent each table as two **row records**, with separate learned token and role encoders. Given query representation $q=E_n(n)$, let a first read be

\[
\alpha_i=\operatorname{softmax}_i\bigl(\beta\langle Q_F(q),K_F(r_i^F)\rangle\bigr),
\quad z=\sum_i\alpha_iV_F(r_i^F),
\]

and a second read be

\[
\gamma_j=\operatorname{softmax}_j\bigl(\beta\langle Q_G(z),K_G(r_j^G)\rangle\bigr),
\quad u=\sum_j\gamma_jV_G(r_j^G),\quad p(o\mid x)=\operatorname{softmax}(W_ou).
\]

All $E,Q,K,V,W_o$ are learned. The equations **hardwire two read stages and row boundaries**, but do not hardwire token equality, the correct row, the intermediate key identity or the answer. That is an explicit inductive bias, not an unstructured discovery of two-hop reasoning. A fixed symbolic interpreter that compares token IDs would instead be labeled an **oracle positive control**, never a learned-model result. A no-pointer-supervision memory variant and a true-pointer-supervision variant should be separate arms. A random-pointer-label arm controls whether any extra supervision/backprop helps regardless of correctness.

Parsing the input into rows is itself a gift. To isolate the addressing bias, give the **same row records, type tags and token embeddings** to a matched dense row-token transformer, not only to the memory model. Also test the original raw-sequence dense model to measure the cost of parsing separately. Distinguish one-read, two-read and answer-only models at matched exposure; match measured forward/backward FLOPs or wall time as closely as feasible for the primary architecture contrast and report residual differences. A one-read model with enough width could still learn direct composition from the entire input, so its failure would not be a theorem about hop count. The clean contrast is whether the two-read model improves **paired query reversal and factorial exactness** beyond the row-parsed dense control, across held-out F and G families and both seeds.

An important harder panel has four rows per table and independently remapped key/object symbols. On two-row episodes, guessing a visible candidate yields about 50% item accuracy; on four rows the trivial candidate rate falls to 25%. Hold out whole family signatures, not just episode seeds, and balance every symbol's marginal frequency and row position. A memory model that passes only two rows, fails four rows, or only works with supervised first-hop labels has a narrower result than general learned binding. Conversely, if end-to-end memory works without pointer labels on new four-row families, that is a stronger qualification than an auxiliary head that reads the right row while the answer path ignores it.

## Priority 2: shared-weight recurrent depth as a different computation budget

A looped model can iterate a hidden working state $H^{t+1}=B_\theta(H^t,X,e_t)$ over the same input, with tied block weights and a learned step embedding $e_t$. [Universal Transformers](https://arxiv.org/abs/1807.03819) introduce recurrent self-attentive computation and report gains on several algorithmic/language tasks; [Adaptive Computation Time](https://arxiv.org/abs/1603.08983) shows a differentiable way to vary step count in an RNN. Those papers do not show that two recurrences implement $F$ then $G$ here. A looped model could spend every step refining a wrong candidate shortcut, and a learned step embedding could effectively prescribe separate stages.

Test $t=1,2,4$ with the **same trained recurrent weights** at evaluation as a computation-depth curve, and train separate prespecified depths if needed to avoid an unfair off-distribution loop count. Compare against an untied dense model with the same number of block applications (FLOPs-matched) and against a width-adjusted model with approximately the same parameter count (parameter-matched). These comparisons answer different questions; a tied model has fewer parameters at a fixed number of passes, while a larger tied model can consume more computation than a tiny dense one. Match input exposure and training schedule in every comparison. Save states and attention writes at **each iteration**, not only each token layer, and test whether the query-specific intermediate becomes readable after one pass and causally useful after the next. Merely observing later-layer changes or improved answer loss is insufficient.

A useful negative result would be: four passes still fail held-out query reversals despite good copy and candidate-membership controls, with no improvement over a compute-matched untied model. A positive result would require exact pair and factorial competence, plus a stable intervention at a designated pass that transfers $F(n)$ across independently remapped $G$ tables. Neither outcome should be generalized to unrestricted recurrent models or natural language without new tasks.

## Priority 3: relational sets; slots only when row identity is genuinely latent

The two table rows form sets whose **order should not matter** to the answer. A relational row encoder can compute $r_i^F=\phi_F(E(n_i),E(k_i))$ and $r_j^G=\phi_G(E(k_j),E(o_j))$, then use query-conditioned attention or pairwise interactions over the two sets. [Deep Sets](https://arxiv.org/abs/1703.06114) and [Set Transformer](https://proceedings.mlr.press/v97/lee19d.html) provide architectures for permutation-invariant/equivariant set processing; [Relation Networks](https://arxiv.org/abs/1706.01427) motivate explicit pair interactions. Their source results are not a license to pool all individual tokens: summing name and key embeddings independently can erase **which name was paired with which key**. The row encoder must bind members before pooling, or expose learned pairwise attention that does so.

Specify two symmetries before modeling. Swapping complete rows within $F$ or $G$ should leave $p(o\mid x)$ unchanged: $f(\pi_FF,\pi_GG,n)=f(F,G,n)$. Swapping only the **values** between rows should generally change the answer. A model that is invariant to both has learned the wrong invariance. For a set architecture, exact or near-exact row-order invariance is an engineering/unit gate; answer correctness under value swaps remains the scientific gate. Give the dense control both randomized row orders and the same row records, otherwise an advantage could be attributed to preprocessing or augmentation. Counterbalance $F$ and $G$ type markers so a model cannot confuse tables.

[Slot Attention](https://arxiv.org/abs/2006.15055) learns exchangeable, competitively updated slots from perceptual features and reports unseen-composition benefits in its studied visual tasks. It is most relevant **after** we remove explicit row boundaries or move to uncertain visual glyph/layout groupings. On the current 14-token grammar, giving it two slots could merely re-derive the already supplied two rows at extra cost. If tried, evaluate slot matching modulo permutations (for example, optimal bipartite matching to known synthetic row labels), check for collapse/empty slots and intervention specificity, and compare to a row-parsed Set Transformer at matched exposure and compute. A visually appealing slot map is not proof of a compositional key.

## An intervention that distinguishes a reusable key from answer injection

After a model passes the **clean** first-hop, direct, composed and copy gates on fresh held-out families, choose a base $x_{0j}=(F_0,G_j,n)$ and a donor $x_{10}=(F_1,G_0,n)$, where $F_0(n)=k_0\neq k_1=F_1(n)$. Choose independently remapped $G_0,G_1,G_2$ so $G_j(k_1)$ differs across $j$. Patch only the proposed post-first-read state $M_1(x_{10})$ into the base model at the same interface, then let its own downstream computation use each **base** $G_j$. A reusable-key route predicts $G_j(k_1)$ for each $j$; a state that simply carries the donor answer $G_0(k_1)$ fails when $j\neq0$. Let $R_j$ be the patched run and $A_j=G_j(k_1)$. A prospective paired estimand is

\[
\Delta_j=\Pr_\theta(Y=A_j\mid R_j)-\Pr_\theta(Y=A_j\mid x_{0j}),
\]

reported alongside the **exact full-answer** fraction, wrong-answer destinations and family-level intervals. The donor should be reused across $j$ so transfer across changed $G$ tables is not secretly a fresh donor-answer patch each time. This is a model-internal counterfactual, not a natural human-language causal effect. [Geiger et al.](https://proceedings.mlr.press/v162/geiger22a.html) give the general interchange-intervention idea; this factorial test across $G$ tables is our proposed task-specific discriminator. The earlier [causal-flow memo](CAUSAL_FLOW_NEXT_TEST.md) develops the related original-model design.

Patch **both directions** of the $F$ swap and test: wrong-row donors, an equal-norm random or independent-family donor, a same-key donor with irrelevant surface differences, a complete-state donor positive control, and an unrelated copy task. On memory models, ablate the $F$ read, the $G$ read and the candidate intermediate **separately**; deleting all attention is too broad because it disables the architecture. On recurrent models, patch pass $t$ while preserving later pass inputs and verify the source/base recomputation numerically. On set/slot models, align row/slot identity by the known episode relation rather than array index, and preserve the slot permutation when grafting. Test necessity (corrupt the proposed route and lose the key-dependent answer) and rescue (restore the correct route), then sufficiency with donor-specific effects. Attention weights alone are weak evidence: [Jain and Wallace](https://aclanthology.org/N19-1357/) demonstrate that very different learned attention distributions can accompany equivalent predictions in their studied NLP models. A pointer head that is only **auxiliary** and does not feed the answer path is not a causal mediator just because its classification accuracy is high.

Interventions can land off the model's training manifold. Pair donors and bases with the same table sizes, token inventory, positions and irrelevant features; include clean/source recomputation checks, and report failures on all attempted items as well as a predeclared both-clean-correct subset. If a full donor state succeeds but a narrow key state fails, the model may use a distributed route; do not relabel the broad patch as a key. If donor answers remain fixed rather than adapting across $G$ tables, the observed effect is compatible with answer injection. A successful patch is not a *unique* circuit: parallel paths can coexist, and correlated components can compensate after ablation.

## A compact preregistration ladder for the next campaign

The numbers below are **candidate gates to freeze in a new registration**, not thresholds retrofitted to any unseen TEACH-0003 outcome. The smallest informative program is a three-way comparison on a new family namespace: row-parsed dense, two-read learned memory, and one-read memory, all at the same input exposure; then compare a tied two-pass model with an untied compute-matched model. Run a four-row and independent-remapping panel only after the two-row numerical/behavior controls pass. The set/slot branch is a later separate test, not an extra component in the same model.

| Stage | Proposed gate and decisive failure |
| --- | --- |
| Numerical/resource | Frozen sources, identical evaluation suites, finite gradients, exact unpatched recomputation, bounded local MPS benchmark and global cap. Stop as **incomplete** on failure; do not infer behavior from partial arms. |
| Clean binding | In **both** seeds, held-out first-hop and direct item accuracy ≥90%, held-out query-reversal pair exact ≥80%, jointly held-out composition ≥85%, each crossed F/G cell ≥85%, four-way factorial exact ≥65%, copy ≥95%. If pairs fail while candidate membership is high, the model still has the TEACH-0002 shortcut. |
| Architecture gain | Two-read memory beats the same-row-record dense and one-read controls by ≥15 percentage points on **both** jointly held-out composition and factorial quartet exact in both seeds. Also report a measured-FLOPs or wall-time-matched comparison; otherwise describe only exposure-matched quality, not compute efficiency. |
| Symmetry/transfer | Reordering complete rows changes no answer above numerical tolerance in a set architecture; swapping row **values** changes correct answers as the oracle predicts. Confirm on new four-row families. Failure shows an insufficient or wrong binding bias. |
| Causal key route | Freeze the mediator site on discovery families. On untouched confirmation families, patched full answers across $G$ tables follow the base $G_j(k_1)$ on ≥80% of both-clean-correct cases, at least 40 points above matched wrong-key/random donors; necessity reduces clean composed accuracy by ≥30 points, rescue restores ≥80% of lost cases, and unrelated copy falls by ≤5 points. If clean competence or positive control fails, report **inconclusive** for mediation. |

Use family-cluster uncertainty because reversals and factorial variants share tables; report exact denominators, two seeds separately, effect signs across families, candidate membership, all negative controls, and cost. These gates are intentionally severe. They should be revised **only before** training or by a newly labeled exploratory study. Do not combine the memory, recurrent and set families into one huge model at the first attempt: a positive result would then not identify which bias mattered.

## Why this still does not decipher the manuscript

The synthetic generator supplies explicit names, keys, table boundaries, task markers, correct row indices and output objects. The Voynich manuscript supplies none of those oracle variables. [Reddy and Knight](https://aclanthology.org/W11-1511/) analyze its structural constraints without a translation; [Lindemann and Bowern](https://arxiv.org/abs/2010.14697) partition comparisons by Currier language, scribal hand and transcription system, illustrating why a single flat token stream is an assumption. [Knight et al. 2006](https://aclanthology.org/P06-2065/) frame unsupervised decipherment using explicit plaintext and cipher-channel models; [Kambhatla et al. 2018](https://aclanthology.org/D18-1102/) evaluate neural-language-model-guided search on specified substitution-cipher tasks, including homophonic ciphers. These controlled tasks and assumptions do not supply a historical channel or semantic anchor for Voynich text, and a learned lookup module supplies neither by itself.

Even if a Voynich-trained predictor develops a state that behaves like a key on **synthetic** tables, its manuscript states may track spelling, local copying, section, image layout or transcription conventions. To promote an architecture into manuscript research, first show method recovery on several *known* linguistic, cipher and nonsemantic generators at corpus-matched size, with generator-family holdout and reversible transcription variants. Then freeze an executable decoder or generator-discrimination rule, its free parameters and independent physical-folio test. A latent concept can be renamed under an observationally equivalent generator, so naming a glyph meaning needs an external anchor that breaks that symmetry. The project's [protocol](../PROTOCOL.md) sets that standard. Until then, a successful memory model would be a useful calibrated instrument, not a decipherment.
