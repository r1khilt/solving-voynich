# Methods review: J-space, predictive state, and causal mechanisms

Date: 2026-09-21. Status: research and proposed experimental design; no new model was trained and no intervention result was generated for this review. The user's “J-space” refers specifically to Anthropic's July 2026 global-workspace work. Generic principal components or a per-example Jacobian SVD would not replicate that method.

The strongest next step is an exact, numerically qualified Jacobian lens on a small model with independently known hidden state, followed by interventions that change that state while preserving the task and nuisance variables. Use manuscript models after this qualification. A sparse dictionary is a candidate coordinate system; a useful causal variable must survive independent tests of what the network subsequently computes.

This recommendation follows the repository's [protocol](../PROTOCOL.md), the existing [mechanisms and identifiability dossier](../world-models-diffusion-2026-09-21/MECHANISMS_AND_IDENTIFIABILITY.md), and [interpretability review](../deep-review-2026-09-21/INTERPRETABILITY.md). It is deliberately stricter than success at predicting the immediate next symbol.

## 1. What the Anthropic result licenses

[Gurnee et al., *Verbalizable Representations Form a Global Workspace in Language Models*](https://transformer-circuits.pub/2026/workspace/index.html) define a lens using an averaged downstream Jacobian and the model's vocabulary readout. Their J-space is a union of cones generated by sparse nonnegative combinations of token directions, typically using 25 directions. It is not one linear subspace. The paper principally examines Claude Sonnet 4.5, with selected other Claude replications; its default Sonnet target omits the final block. It tests reporting, internal computations, generalization, and selective interventions. Some interventions continuously clamp positions across a layer band. These are stronger evidence than a probe alone, but their interpretation must distinguish sustained control from a one-time state edit. Single-token labels, incomplete binding structure, and architecture-dependent behavior remain limitations. The paper does not establish a universal mechanism in small character models. The [July 6 announcement](https://www.anthropic.com/research/global-workspace) and [July 16 arXiv submission](https://arxiv.org/abs/2607.15495) are different publication events.

**Transfer assessment, proposed here:** a small glyph model cannot verbalize “plant,” “root,” or a historical language merely because its hidden states admit token readouts. Its vocabulary directions denote its own symbols. English labels would require an independently validated mapping, a separately trained grounded task, or a different model. Model scale is also a scientific variable: a two-layer network has insufficient layer resolution to test an extended sequence of workspace formation, broadcast, and readout. A four-to-six-layer, width-128 synthetic model is a practical intermediate test, conditional on learning the target behavior.

With post-block sources and a strictly later target, a two-block model provides only one source below its final block. Choosing its penultimate block as target leaves no earlier post-block source. It remains useful for qualifying the estimator, but cannot supply the same layer-band comparison as a deeper model.

## 2. Exact estimator and local implementation contract

### 2.1 Estimator to reproduce

The official [fitting implementation](https://github.com/anthropics/jacobian-lens/blob/main/jlens/fitting.py) computes a prompt mean of source-position means of **summed** downstream derivatives. For prompt \(p\), source post-block state \(h_{\ell,s}\), target post-block state \(z_{q,t}\), and the shared valid-position set \(S_p\), the inspected code corresponds to

\[
\widehat J_{\ell\to q}
=\frac{1}{N}\sum_{p=1}^{N}\frac{1}{|S_p|}
\sum_{s\in S_p}\sum_{\substack{t\in S_p\\t\ge s}}
\frac{\partial z_{q,t}}{\partial h_{\ell,s}}.
\]

The causal architecture supplies the zero derivatives for \(t<s\). The default mask skips the first 16 positions and the final position. One output-coordinate cotangent is applied at every valid target simultaneously. Eight replicated batch elements compute eight coordinate rows per backward call; this changes scheduling and memory, not total derivative work. All requested source layers share that graph. Prompts receive equal weight, rather than weight proportional to length. The code defaults to the final target block; source indices must be strictly earlier. Record the actual target explicitly.

**Consequences derived here:** this is neither the average same-position derivative nor the uniformly normalized average over all causal position pairs. For a positionwise identity map and \(m\) valid positions, the formula above returns \(I\), whereas uniform pair averaging returns \(2I/(m+1)\). Fixed-length scalar changes can disappear under RMS normalization, but variable lengths change relative prompt weights. Therefore an apparently similar visualization does not validate the estimator.

For small local models, preserve this estimator as the reference. Separately name any adaptation: `same_position`, `fixed_lag`, `horizon_restricted`, or `uniform_pairs`. A fixed-lag lens could be scientifically valuable for persistent state, but it answers a different question. Fit each declared estimator on the same calibration prompts for a fair comparison.

The default mask needs at least 18 positions to retain one valid position. Some short synthetic tasks therefore need a declared shorter skip or longer sequences; silently dropping those prompts would change the calibration population. Report exclusions and reject an empty or systematically filtered calibration set.

### 2.2 Differentiable activations

The repository's [native model](../../../src/voynich/model.py) contains extensive hooks, but `ActivationContext` caches `value.detach().clone()`. Those cached tensors cannot be used to differentiate the downstream computation. Ordinary cached-activation analyses can silently look plausible while the intended Jacobian graph is absent.

The official [activation recorder](https://github.com/anthropics/jacobian-lens/blob/main/jlens/hooks.py) instead attaches temporary block-output hooks, retains live tensors, and starts a graph at the earliest requested source. A local adapter should follow that principle:

1. Freeze parameter gradients, enter evaluation mode, and select explicit post-block source and target tensors.
2. Enable gradients on the earliest retained source output without detaching later outputs from it. Preserve the native computation after that source.
3. Use `autograd.grad` against all source tensors, release the graph after the last coordinate batch, and remove temporary hooks even on exceptions.
4. Record the attention implementation. The repository switches from fused attention to explicit attention under its normal activation context; validate numerical agreement before treating those pathways as interchangeable.
5. Exclude padding from both cotangent placement and source reduction. An unpadded single-prompt reference avoids ambiguous masks during qualification.

Do not compute parameter gradients or retain every training graph. For the conditional [communication denoiser](../../../src/voynich/communication/denoiser.py), a slot-to-slot Jacobian must additionally condition on noise level, mask pattern, and slot type. Its bidirectional reconstruction process does not supply the autoregressive future-position interpretation above. Analyze it as a separate model family.

### 2.3 Readout, normalization, and dictionary geometry

The official [lens class](https://github.com/anthropics/jacobian-lens/blob/main/jlens/lens.py) transports a row activation as \(hJ^T\), then calls the model's unembedding function. Its default saved matrix precision is reduced; archive a float32 copy when comparing weak singular values or closely aligned subspaces. The [Hugging Face adapter](https://github.com/anthropics/jacobian-lens/blob/main/jlens/hf.py) applies the final normalization before the language-model head and handles its additional output transformation. A bare multiplication by the head weights is not always the same lens.

For this repository's bias-free head \(U\), final RMSNorm scale \(\Gamma=\operatorname{diag}(\gamma)\), and transported column state \(Jh\), the exact local readout is

\[
\operatorname{logits}_{\mathrm{lens}}(h)
=\frac{U\Gamma Jh}{\sqrt{\|Jh\|_2^2/d+\epsilon}}.
\]

Thus the linear token score direction is \(v_a=J^T\Gamma U_a^T\). Omitting learned \(\gamma\) changes the direction. The common positive denominator preserves token ranking within one example, but affects magnitudes and distributions. Also, \(v_a\) is not the full per-input gradient of a normalized logit: differentiating the denominator adds an input-dependent term. Verify with the actual final-norm/head modules, rather than relying on algebra alone.

The following proposed geometry contract makes ambiguities testable:

- Preserve both raw and unit-normalized token directions. Normalization changes coefficient magnitudes and sparsity selection; it must not be a hidden preprocessing choice.
- Define a token dictionary \(V=[v_1,\ldots,v_{|\mathcal V|}]\). For the claimed cone decomposition, fit \(\min_{a\ge0,\|a\|_0\le k}\|h-Va\|_2^2\), stating the pursuit or optimization approximation and its stopping criterion. A top-\(k\) inner-product list is not this fit.
- A nonnegative sparse reconstruction is generally not an orthogonal projection onto the dictionary's full span. Store reconstruction \(Va\), residual \(h-Va\), and their inner product. Never infer orthogonality just from the word “projection.”
- Token directions can be nearly collinear. Store dictionary rank, Gram spectrum, and pair condition numbers before coordinate-swap experiments.
- For an explicitly chosen two-direction swap, a reproducible linear operation is \(c=V_2^{\dagger}h\), \(h'=h+V_2(\operatorname{swap}(c)-c)\). This preserves the component orthogonal to the pair's span. It generally changes readouts of other, nonorthogonal token directions. Report those changes and the pseudoinverse tolerance.

The paper's prose emphasizes nonnegative cones, while its formal appendix also uses span/projection language. The implementation must declare which mathematical object is being tested; do not silently substitute an SVD subspace for the sparse-cone claim.

### 2.4 Minimum numerical qualification

The official [tests](https://github.com/anthropics/jacobian-lens/blob/main/tests/test_fitting.py) include a small linear-network Jacobian check, dimensional checks, persistence, merging, and invalid configurations. Local attention and temporal aggregation warrant additional tests before interpreting biology, language, or cryptography:

| Check proposed here | Expected result or failure interpretation |
| --- | --- |
| Identity/linear transport | Exact orientation and scale of \(J\), within declared float64 tolerance on CPU. |
| Known temporal map \(z_t=Ah_t+Bh_{t-1}\) | With a contiguous mask of \(m\) positions, \(J=A+(m-1)B/m\). This detects incorrect time reduction. |
| Scalar finite differences | For selected prompt/source/output coordinates, compare central differences to automatic differentiation over several step sizes. Require a convergence region, not agreement at one lucky step. |
| Coordinate batching | Batch widths 1, 2, and 8 agree on the same prompts; duplicated examples must not interact. |
| Hook/no-hook computation | Clean logits agree; installing/removing the recorder leaves model behavior unchanged. |
| CPU/MPS comparison | A small identical batch produces compatible matrices and intervention deltas. Use CPU float64 as a numerical reference, not an assumed production-speed choice. |
| Fresh calibration halves | Separate prompt pools yield stable directions or subspaces where subsequent claims depend on them. |
| Length and prompt order | Equal-length controlled inputs isolate estimator semantics; permutation leaves the mean unchanged within accumulation error. |

A declining update to a running mean is insufficient convergence evidence because the averaging denominator grows mechanically. Use independent-pool agreement, bootstrap uncertainty at the independent episode/folio level, and held-out intervention performance. Tokens from one sequence are not independent replicates.

## 3. Separate the competing objects

| Object | What it measures | Useful local role | What it does not establish |
| --- | --- | --- | --- |
| Neuron response / activation PCA | Coordinate activity / activation variance | Locate task, position, and nuisance variation cheaply | Semantic identity or causal necessity |
| Per-example Jacobian | Local sensitivity around one computation | Finite-difference checks; input-specific paths | Corpus-wide dictionary or large-intervention validity |
| Mean Jacobian lens | Signed average transport to a downstream representation | Exact J-lens replication and vocabulary-linked candidate directions | A recurrent state machine, independent of readout |
| Sensitivity second moment | Directions with consistently large squared derivative | Find effects that cancel in the mean | The Anthropic J-space construction |
| SAE / transcoder | A learned sparse reconstruction / approximation of a component | Candidate distributed features and paths | Unique coordinates or faithful causal decomposition |
| Belief / predictive state | Information sufficient for specified future distributions | Oracle target on a known generator | Unique historical source or cipher |

For a vector output \(f\), use \(C=\mathbb E[J_f^T M J_f]\) with a declared positive-semidefinite output metric \(M\) as the sensitivity baseline. This generalizes the gradient second-moment matrix underlying [active subspaces](https://arxiv.org/pdf/1304.2070). It is not \(\mathbb E[J_f]^T\mathbb E[J_f]\). For \(f(h)=h^2\) under a symmetric scalar distribution, the mean derivative vanishes while the second moment remains positive. Consequently, a weak mean lens cannot rule out important context-dependent computation.

Prefer an output metric over log-probabilities or predictive tests that removes meaningless common-logit shifts; record its scaling. Raw Euclidean logit sensitivity can be dominated by rare-token scales or a head's conditioning. Comparisons must match rank and intervention norm rather than declaring the larger basis superior by construction.

For vocabulary readout comparisons, include an identity-transport logit lens and a regularized affine lens fitted to downstream predictions on the same training pool. Also include a constant mean-state baseline. These can identify gains attributable to coordinate calibration or dominant activation means. Better immediate prediction by a tuned affine lens does not decide whether it exposes the intermediate state that later computations use.

### The local output-span confound is unusually strong

The manuscript model inventory examined here has fewer token types than residual dimensions; compact models have width 128, and the reference configuration has width 192. Alphabet size depends on the dataset and preprocessing. The 112-token training inventory and the 108-unit manuscript export are not interchangeable.

At any layer, \(V=J^T\Gamma U^T\) has rank at most \(\min(d,|\mathcal V|)\). These dictionaries therefore need not be overcomplete, unlike the large-vocabulary setting that motivates many semantic-feature arguments. At a final identity transport, the dictionary lies exactly in the normalized head's output span. A tiny alphabet also makes a fixed sparsity of 25 meaningless as a cross-model capacity comparison.

This is empirically material in the repository: [EXP-0006](../../experiments/EXP-0006-results.md) found late rank-three learned steering and an output-weight-span baseline very close on donor-oracle KL (three-seed means approximately 0.0348 and 0.0363). Early learned steering did not consistently beat shuffled supervision. Those observed evaluation pools are now development evidence. Use fresh pools for the next confirmation, and require progress beyond immediate readout manipulation.

## 4. Belief geometry: use it as an independently specified target

[Shai et al. (2024)](https://arxiv.org/html/2405.15943v2) recover geometry of Bayesian beliefs in transformers trained on known finite-state processes. Their linear probes use oracle posterior beliefs; this is not blind recovery of an unknown generator. Their RRXOR example also illustrates why a final next-token representation can hide distinctions that matter to longer futures. They explicitly do not establish that all successful transformers must encode beliefs linearly. [Shai et al. (2025)](https://arxiv.org/html/2502.01954v1) derive architectural constraints and geometry for a restricted family of small hidden Markov models, including consequences of attention's nonnegative weights. These results motivate carefully matched positive controls, not a universal theory for manuscript text.

[Littman, Sutton, and Singh's predictive-state formulation](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf) represents state using probabilities of future tests. Its finite-state representability result is an existence statement, not an automatic identification algorithm from one unknown corpus. The normalized update is generally a ratio of linear functions, so “linear predictive representation” should not be reported as a linear recurrence without qualification.

**Executable proposal:** retain the repository's exact edge-emitting generator and Bayesian filter as the high-level model. For symbol-transition matrices \(M_a\), belief row vector \(b\), and future string \(w=a_1\cdots a_r\),

\[
P(w\mid b)=bM_{a_1}\cdots M_{a_r}\mathbf 1,
\qquad
b'=\frac{bM_a}{bM_a\mathbf 1}.
\]

Use [the existing generator and continuation scorer](../../../src/voynich/edge_emitting.py), with new held-out seeds, to define three distinguishable claims:

1. **Decodability:** an affine map from activations predicts oracle belief or a fixed vector of future-test probabilities.
2. **Predictive sufficiency:** replacing the full history by that decoded state preserves joint future distributions at declared horizons, including contexts with identical immediate next-symbol marginals.
3. **Causal update:** a state intervention changes subsequent computations according to the oracle update law under unseen continuations.

Use joint tests at horizons 1, 2, 4, and 8, with a predeclared subset or exact enumeration where the alphabet permits. Separate teacher-forced conditional scoring from free-running rollout. Marginal correctness at every individual position does not establish the correct joint distribution: a parity task supplies a simple counterexample.

Compare a belief probe, predictive-test probe, J dictionary, PCA, and sensitivity basis on the same held-out histories. Fit all mappings on training/validation data, then freeze them. Match probe rank and regularization budgets. A nonlinear probe may diagnose a failed linear representation hypothesis, but it cannot rescue a failed preregistered linear result without a separate exploratory label.

The teacher must first achieve the behavior claimed in this test. If it cannot retain a hidden variable across the chosen delay or respond correctly to the later query, an unsuccessful intervention does not test the proposed mechanism. This qualification is specific to the mechanism under investigation, not a theorem that latent parameter information requires high exact-output accuracy.

## 5. Causal abstraction and finite interventions

[Distributed Alignment Search](https://arxiv.org/html/2303.02536v3) learns a distributed alignment between a specified high-level causal model and neural activations using interchange interventions. Its success measure compares the low-level intervention's answer with the high-level counterfactual. The method presupposes a candidate causal graph and counterfactual examples; a good alignment on a finite evaluation distribution is not proof of global equivalence. It is especially suitable here because synthetic generators expose the state and update rules.

Two opposing cautions matter. [Makelov, Lange, and Nanda](https://arxiv.org/html/2311.17030v1) construct misleading subspace interventions, including mixtures of correlated and causally disconnected components. A [subsequent response](https://arxiv.org/html/2401.12631v1) shows that proposed nullspace criteria can also reject legitimate distributed abstractions. Therefore neither steering success nor one nullspace diagnostic is a sufficient verdict. Use a set of counterfactual predictions whose nuisance-preservation and update behavior constrain the explanation.

### Proposed intervention protocol

Construct a factorial task with latent variable \(Z\), nuisance \(N\), independently varied query \(Q\), and output \(Y=g(Z,Q)\). Introduce a delay between evidence about \(Z\) and \(Q\). Hold out combinations of variable value, nuisance, query, and delay, rather than only random examples of familiar templates. In a cipher control, reserve whole keys or permutation families for transfer tests; success on one fixed key can represent memorization.

For matched recipient/donor examples \((Z_r,N,Q)\) and \((Z_d,N,Q)\), compute the oracle answer \(g(Z_d,Q)\). A representation of \(Z\) must support this counterfactual while retaining outputs depending on \(N\). Include a later query unseen during alignment fitting. Use an intermediate value whose token differs from the answer and vary the operation so the intermediate cannot be replaced by one universal answer direction.

At every selected layer, compare the following interventions using identical example pairs:

| Intervention | Purpose |
| --- | --- |
| No-op, self-donor, and same-\(Z\) donor | Numerical correctness and nuisance sensitivity |
| Full eligible residual/prefix replacement | Positive control that the chosen location can transmit the variable at all |
| Natural donor difference restricted to the candidate representation | Sufficiency of the candidate coordinates |
| Candidate ablation with a matched natural or conditional replacement | Necessity under a declared replacement distribution |
| Random subspace, PCA, output span, shuffled-label alignment | Capacity, variance, readout, and fitting controls |
| Equal-norm orthogonal/complement intervention | Specificity, with awareness that geometry does not guarantee causal isolation |
| J reconstruction and residual | Where causal behavior lies under the declared decomposition |
| Learned belief/predictive-state alignment | Oracle-guided ceiling and a competing representation hypothesis |

Report absolute donor-target probability or oracle KL, recipient preservation, unrelated-output degradation, and intervention norm. “Percent of effect recovered” can become unstable if the full-patch effect is tiny; retain its numerator and denominator and predeclare exclusion or undefined cases. Do not select only clean examples after seeing which intervention works.

Test **one-shot edits** separately from **sustained clamping**. One-shot replacement asks whether the subsequent network can use and update the changed state. Reapplying the desired state at every position or layer tests controllability under continued external forcing. Both are useful, but only the former directly addresses persistence after the intervention has ended.

A transformer stores a prefix across positions and layers. Editing only the final residual can fail even if the variable is encoded elsewhere. Conversely, editing the final residual just before the head can succeed without changing any persistent mechanism. Define the intervention support: one position, all eligible prefix positions, a head's values, or a specified collection of cached keys/values. If using fresh full-prefix forwards, state this explicitly; do not call the experiment a cache intervention.

### Transition commutation is the decisive extension

For a learned alignment \(\alpha\), high-level update \(T_a\), and neural continuation update \(F_a\), test

\[
\alpha(F_a(h))\approx T_a(\alpha(h))
\]

on held-out histories, then repeat after a counterfactual state patch. Also test longer compositions \(F_{a_r}\circ\cdots\circ F_{a_1}\). Compare downstream distributions and nuisance variables, not just the decoded coordinate. A decoder can conceal a neural failure by forcing plausible labels onto arbitrary states.

Natural donor activations reduce some out-of-distribution risk, but their mixture with recipient components may still be off the activation manifold. Measure distances to matched natural examples, norms, covariance coordinates, and behavior of unrelated tasks. Treat these as diagnostics, not proofs of manifold membership. Require graded perturbations and natural endpoint checks; a direction valid infinitesimally may fail at a full donor edit.

## 6. Sparse autoencoders and transcoders: a conditional second stage

An SAE can propose coordinates missed by vocabulary directions. A transcoder can propose how one component writes those coordinates. Neither should be used to declare “concept neurons” solely from a few activating snippets.

[Jacobian sparse autoencoders](https://arxiv.org/html/2502.18147v1) jointly reconstruct MLP input/output representations and encourage sparsity of the induced feature-to-feature Jacobian. Their reported Pythia experiments are much larger in data and backbone scale than this corpus, and local derivative sparsity does not guarantee finite-intervention fidelity. A local version should begin with one layer and ordinary sparse dictionaries, adding the Jacobian penalty only if its value can be measured against reconstruction, causal effect, and stability controls.

For the repository's native SwiGLU component, independently derive the correct derivative rather than importing a GELU formula. With \(u=W_u x\), \(g=W_gx\), and \(f(x)=W_d[u\odot\operatorname{SiLU}(g)]\),

\[
J_f(x)=W_d\left[
\operatorname{diag}(\operatorname{SiLU}(g))W_u+
\operatorname{diag}(u\odot\operatorname{SiLU}'(g))W_g
\right].
\]

This expression treats \(x\) as the normalized MLP input. A derivative with respect to the preceding residual additionally includes RMSNorm's derivative. Validate automatic and analytic forms on a small CPU example before optimizing a Jacobian regularizer.

The [circuit-tracing methods paper](https://www.transformer-circuits.pub/2025/attribution-graphs/methods.html) uses replacement models and local approximations, including frozen attention patterns and normalization-related quantities. It tests intervention agreement, and describes failures when approximation errors compound. Its graph therefore cannot be equated to the original model's complete causal computation. [Olah's 2025 toy analysis](https://www.transformer-circuits.pub/2025/faithfulness-toy-model/index.html) further illustrates that sparsity and reconstruction incentives can reward an incorrect explanatory mechanism on repeated data. Both concerns are acute in a small repetitive manuscript corpus.

**Proposed bounded configuration:** width-128 activations; dictionary sizes 256 and 512; two predeclared sparsity settings selected on synthetic validation; three fitting seeds on one frozen backbone. Train on 50,000–200,000 sampled activations from independent synthetic episodes first. Split by episode and future-query family. A random token split of the same episode leaks the generative context. Introduce one additional backbone seed only after the pilot demonstrates a measurable causal signal.

Evaluate:

1. Held-out reconstruction and clean model loss after replacement.
2. Matched original-model finite interventions, recomputing attention and normalization.
3. Agreement of intervention **deltas**, including sign and magnitude across downstream sites, rather than only clean logits.
4. Known-state feature recovery, nuisance entanglement, and feature co-occurrence coverage.
5. Subspace and functional stability across fitting seeds, rather than exact one-to-one neuron names.

[SAEBench](https://arxiv.org/html/2503.09532v1) usefully separates multiple evaluation dimensions, but its off-the-shelf semantic tasks are not this project's task. [Chanin's 2026 audit](https://arxiv.org/html/2605.18229v1) demonstrates reliability problems in several popular metrics and motivates randomized/decoder controls. Include a random dictionary matched in activity level, an encoder-only baseline, and a decoder permutation that destroys the intended encoder-decoder correspondence. A score that survives the last manipulation cannot establish decoder-level causal faithfulness.

[Gerasimov et al. (2026)](https://arxiv.org/html/2606.12138v1) find that unstable SAE features can share reproducible subspaces. Compare principal angles, activation functions on held-out examples, and intervention-response signatures. Stable span with unstable axes supports a distributed representation claim, not a unique feature inventory. Across independently trained backbones, raw neuron coordinates need a separately fitted alignment.

[Nelson, Karaletsos, and Locatello (2026)](https://arxiv.org/pdf/2605.31245) study identifiability under sparse-code assumptions and propose conditioning/encoder changes. Their real-model experiments also caution that improved reconstruction need not improve dictionary identifiability. Treat these assumptions—sufficient feature combinations, conditioning, reconstruction accuracy—as empirical tests. A signed sparse code can be useful, but zero no longer supplies an uncomplicated “feature absent” interpretation.

## 7. Five questions that could change the research direction

These are proposed confirmatory questions. Numeric success margins, sample counts, exclusions, and multiple-comparison handling must be registered before collecting the corresponding final evaluation. Exploratory layer scans may choose a configuration on development data; confirmation needs untouched seeds/examples.

### Q1. Is the estimated lens a stable property of the trained computation?

Require numerical qualification, independent calibration-pool agreement, and convergence of held-out functional measurements. Compare training, validation, and a deliberately shifted prompt distribution without pooling them. If dictionaries rotate strongly with calibration data while predictions remain similar, report a distribution-dependent lens. Do not interpret one top-token display as a universal coordinate system.

### Q2. Does a J direction encode an intermediate that matters beyond the immediate output?

Use contexts with the same immediate next-symbol distribution but different joint futures, plus delayed queries with different functions of the same variable. Compare J-space to the output span at matched rank and perturbation size. A candidate should influence the donor-consistent intermediate result across operations while preserving unrelated outputs. If only the final answer changes, the supported claim is readout control.

### Q3. Does an edited state propagate according to an independently known update law?

Test one-shot state interchange and transition commutation on unseen continuations, then evaluate sustained clamps separately. Require a full-support patch positive control. If full patch succeeds and the proposed coordinates fail, localization or representation is inadequate. If the teacher or full patch fails, the experiment is uninformative about that coordinate hypothesis.

### Q4. What predictive or causal information is systematically absent from the token dictionary?

Compare J reconstruction/residual with oracle belief probes, predictive-test bases, sensitivity second moments, and a small SAE. A reliable effect outside the dictionary is evidence against the dictionary's sufficiency on this task. A weak averaged Jacobian together with strong context-conditioned sensitivity suggests cancellation or conditional computation, rather than no mechanism. Distinguish vocabulary limitations from extraction failure.

### Q5. Which surviving result discriminates manuscript-generating hypotheses?

Freeze the qualified pipeline, then ask whether its measured state, persistence, or update signature distinguishes cipher, copying/editing, templatic generation, and matched statistical controls on held-out folios. Match layout, section, length, token frequency, repetition, and transcription choices as appropriate. A signature shared by all controls is descriptive, even if it is visually striking. A manuscript-specific signature still identifies a computational regularity, not word meanings or a historical authorial process.

## 8. Cost and sequencing on the local machine

The machine is user-reported as an Apple M5 Pro with 64 GB unified memory. No throughput measurement was made for this review. Existing training timings do not predict repeated-backward Jacobian timings; benchmark the actual derivative kernel. No paid API or remote compute is needed for this plan.

| Stage | Proposed bound and computational accounting |
| --- | --- |
| Numerical reference | Width 8–16 linear and tiny attention examples; CPU float64; seconds-to-minutes budget, stopping on discrepancies. |
| Lens pilot | Five representative prompts, width 128, length 64–128; benchmark coordinate batch widths 1/2/8 and peak memory. |
| First exact lens | 128 calibration prompts: 2,048 backward groups at width 128 and dimension batch 8, plus 128 replicated forwards. All selected source layers share each graph. |
| Expanded lens if pilot warrants | 256 prompts at width 192 require 6,144 backward groups with dimension batch 8. Default paper-scale 1,000 prompts is not automatically necessary or locally cheap. |
| Geometry and oracle probes | Small matrices, CPU SVD/eigendecomposition and regularized regression; shared fixed activation sample. |
| Causal pilot | Fixed factorial example grid across a small set of layers and intervention types; batches of clean/donor/patched forwards. Cache immutable clean activations once. |
| Optional SAE/transcoder | One backbone/layer; two dictionary sizes and two sparsities; short pilot followed by a predeclared capped grid only if meaningful causal evaluation exists. |

Use the pilot median seconds per prompt multiplied by planned prompt count, with at least a 1.5 safety factor, to project lens time. Adopt a 45–60 minute cap for the first production lens; reduce prompt count or source task if that cap would be exceeded, and document the resulting statistical limitation. Do not silently replace the exact estimator with random projections and still call it exact. Randomized sketches can be a separately validated approximation.

Memory arithmetic, calculated here:

- Five float32 width-128 transport matrices occupy about 0.31 MiB. Saving the lens is cheap.
- Fifty thousand activations from four width-128 layers occupy about 97.7 MiB in float32; 200,000 occupy about 390.6 MiB, before metadata or additional hook tensors.
- A full position-pair Jacobian for one 128-position, width-128 example contains \(128^4\) floats, approximately 1 GiB **per layer**. Never materialize this tensor for routine fitting.
- A width-128, 512-feature untied encoder/decoder has roughly 131,000 weights, excluding biases. The activation cache and model graphs dominate its parameter memory. A regularizer that differentiates through Jacobians can substantially increase graph memory despite the small parameter count.

Keep clean activations detached on CPU, sparse fitting batches bounded, and one retained lens graph at a time. Accumulate lens sums in float32 or float64 on CPU and archive float32 matrices. A 64 GB capacity is not permission to occupy all unified memory; target a comfortably smaller measured peak and leave headroom for the operating system and concurrent work.

Suggested order within the wider hours-long investigation: numerical qualification → teacher competence → one exact lens → causal delayed-state test → manuscript transfer or an additional sparse-method diagnostic, chosen by the actual unresolved question. Do not run every method merely because it fits on the machine. If the teacher fails, spend the next bounded block on task design or training adequacy; if the teacher succeeds but patch controls fail, fix intervention support before fitting a more flexible extractor.

## 9. Prior application and evidence boundaries

A targeted search for Voynich applications of Jacobian lenses, SAEs, and causal abstraction did not locate a validated J-space decipherment. This is a search observation, not an exhaustive absence claim. [Volpini's 2024 first-person report](https://wordlift.io/blog/en/unraveling-the-mystery-of-the-voynich-manuscript/) describes an attempted SAE comparison of Voynich and Italian and reports uninformative features. It provides insufficient controlled evidence for either a successful semantic alignment or a general failure of SAEs. Its illustrative nearest-neighbor/t-SNE claims should not serve as ground truth.

In cryptanalysis, [Saxena and Lauter's 2026 workshop paper](https://openreview.net/pdf/ec4dc54d4f2f4abecd2ab9b36bdf3c90d655f712.pdf) reports latent fixed-secret recovery in an LWE setup despite near-zero exact prediction accuracy. Only the primary abstract and indexed introduction were accessible here; the full PDF was blocked by a browser-verification page. This is a lead for subsequent reading, not a reproduced result or an architectural justification for this project. It reinforces the distinction between recovering a fixed parameter and recovering an online, transferable state-update mechanism.

Even a perfect synthetic recovery establishes competence only for the assumed generator, observation model, and available interventions. Predictive equivalence can leave multiple hidden generators observationally indistinguishable. Manuscript data supplies neither oracle hidden states nor unrestricted interventions on its historical production. Mechanical interpretation of a trained predictor can reveal how **that predictor** compresses the corpus; a claim about the manuscript's actual mechanism requires independent discriminating evidence.
