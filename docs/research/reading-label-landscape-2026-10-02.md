run a new chain, improve a neural model, infer a historical language or decode the manuscript.

## Structural obstructions and an exact dictionary ceiling

The prior memo derives an own necessary-and-sufficient permutation-orbit criterion:
corresponding record source lengths, per-position emitted unit lengths and the cross-record
letter-equality pattern must agree. Necessity is invariance under label renaming; sufficiency
constructs an injective used-row map, then extends it to unused rows. Literal equality of
the ciphertext and boundaries forces the corresponding units to agree. The new helper
checks that criterion only after scoring seals. It does not guide candidates.

For code u, let n_old(u) be its multiplicity among the candidate's bound rows and n_gold(u)
its multiplicity among Gold's used rows. Any label permutation can match at most

    Σ_u min(n_old(u), n_gold(u))

of Gold's used bindings. For dictionary matches alone, that bound is attainable by matching
entries with the same code and assigning all remaining entries arbitrarily. It need not
be attainable simultaneously with Gold's source text: wrong boundaries or repeated-letter
partitions can obstruct that even with a perfect dictionary ceiling. Source-length
discrepancy also supplies a lower bound on edit operations that no label move removes.
These are fixed-orbit diagnostics, not global decipherment impossibility or information
theoretic limits on all future methods.
